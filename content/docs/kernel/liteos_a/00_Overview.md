# 项目概览

## 项目定位

**LiteOS Cortex-A** 是 OpenHarmony 的新一代内核，基于华为 LiteOS 内核发展而来，专为 IoT 和智能设备设计。

### 核心定位
- **轻量级**: 小尺寸、低功耗、高性能
- **POSIX 兼容**: 提供完整的 POSIX API 支持
- **统一生态**: 为开发者提供统一开放的生态系统

### 适用场景
- 智能家居设备
- 可穿戴设备
- IoT 网关
- 智能摄像头（如 Hi3516D V300 开发板）

## 运行环境

| 项目 | 说明 |
|------|------|
| **CPU 架构** | ARM Cortex-A (32位/64位) |
| **编程语言** | C / C++ |
| **目标芯片** | Hi3516D V300 (默认) |
| **默认文件系统** | FAT |
| **C 库** | musl / newlib |

## 核心能力

### 1. 任务管理
- 多任务/多线程支持
- 优先级调度
- 时间片轮转
- 任务同步与通信

### 2. 内存管理
- 静态/动态内存分配
- 虚拟内存管理
- 内存保护

### 3. 进程管理
- 多进程支持
- 进程间隔离
- 用户/内核态分离

### 4. 文件系统
- VFS 虚拟文件系统
- FAT / JFFS2 / NFS / RAMFS / ProcFS

### 5. 网络栈
- 基于 lwIP 的 TCP/IP 协议栈

### 6. 设备驱动
- HDF (Hardware Driver Foundation) 驱动框架
- 字符设备驱动

## 系统架构

```
+------------------------+
|    User Space          |
|  +------------------+  |
|  | Applications     |  |
|  | Shell Commands   |  |
|  +------------------+  |
+------------------------+
         ↑↓ (syscall)
+------------------------+
|    Kernel Space        |
|  +------------------+  |
|  | Process/Task     |  |
|  | Memory Mgmt      |  |
|  | IPC              |  |
|  | File System      |  |
|  | Network Stack    |  |
|  | Device Drivers   |  |
|  +------------------+  |
+------------------------+
         ↑↓
+------------------------+
|    Hardware            |
|  CPU/Memory/Devices   |
+------------------------+
```

## 关键特性

| 特性 | 说明 |
|------|------|
| **SMP 支持** | 对称多处理器支持 |
| **容器支持** | 进程/用户/网络/挂载命名空间 |
| **动态加载** | ELF 动态加载能力 |
| **vDSO** | 虚拟动态共享对象 |
| **性能追踪** | ftrace / perf 支持 |
| **电源管理** | 软件电源管理 |
| **日志系统** | hilog 日志框架 |
