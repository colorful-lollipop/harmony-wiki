## 核心组件

### 1. 任务管理架构

#### 任务状态机

### 2. 调度器架构

#### 调度策略

| 策略 | 说明 | 启用条件 |
|------|------|----------|
| **优先级抢占** | 高优先级任务就绪时立即抢占 | 始终启用 |
| **时间片轮转** | 同优先级任务按时间片轮转 | 可配置 |
| **优先级继承** | 解决优先级反转问题 | 二元信号量 |

#### 调度点

1. **任务创建/删除后** - 可能改变就绪表
2. **任务延时/挂起后** - 任务让出 CPU
3. **信号量释放** - 唤醒等待任务
4. **中断返回** - 检查是否需要切换

### 3. IPC 架构

UniProton 提供四种 IPC 机制，用于任务间同步与通信：

```
┌─────────────────────────────────────────────────────────┐
│                    IPC 机制分类                          │
├─────────────────┬─────────────────┬─────────────────────┤
│   同步机制      │    通信机制     │    读写分离         │
├─────────────────┼─────────────────┼─────────────────────┤
│  • 二元信号量    │  • 消息队列     │  • 读写锁           │
│  • 计数信号量    │  • 事件标志     │                     │
│  • 互斥锁       │                 │                     │
└─────────────────┴─────────────────┴─────────────────────┘
```

#### 信号量工作流程

```

       │    ┌─────────────┐      │
       │    │  SemCount=1 │      │
       │    └──────┬──────┘      │
       │           │             │
       │           ▼             │
       │    ┌─────────────┐     │
       │    │  SemPend()  │     │
       │    │  SemCount=0 │     │
       │    └──────┬──────┘     │
       │           │             │
       │           │             ▼
       │           │      ┌─────────────┐
       │           │      │  Pend()     │
       │           │      │  阻塞等待    │
       │           │      └──────┬──────┘
       │           │             │
       │           ▼             │
       │    ┌─────────────┐      │
       │    │  SemPost()  │◄─────┘
       │    │  SemCount=1 │      唤醒
```

#### PID 编码

```c
/* 证据: src/include/uapi/prt_task.h */
#define OS_TSK_TCB_INDEX_BITS ((4 - OS_TSK_CORE_BYTES_IN_PID) * 8)
#define GET_HANDLE(pid)       ((pid) & ((1U << OS_TSK_TCB_INDEX_BITS) - 1))
#define GET_COREID(pid)      ((U8)((pid) >> OS_TSK_TCB_INDEX_BITS))
```

- 低位: TCB 索引 (0-255)
- 高位: 核 ID

## 线程模型

UniProton 是**单线程模型**的操作系统内核：

- **无用户态/内核态分离**: 所有代码运行在特权模式
- **单地址空间**: 所有任务共享内存空间
- **任务即线程**: 任务是最小调度单位
