## 3. 数据流

### 3.1 典型调用链

#### A. TEE 会话建立

```
用户态 TEE Client
      │
      ▼
ioctl(TC_NS_CLIENT_IOCTL_SES_OPEN_REQ)
      │
      ▼
tzdriver: tc_client_ioctl()
      │
      ├──▶ session_manager: tc_ns_open_session()
      │           │
      │           └──▶ smc_smp: tc_ns_smc()
      │                       │
      │                       ▼
      │               SMC 指令发送到 TEE
      │
      ▼
返回会话 ID
```

#### B. 代码签名验证

```
应用调用 mmap(PROT_EXEC)
      │
      ▼
xpm_mmap_check()
      │
      ├──▶ code_sign: 验证签名
      │           │
      │           └──▶ ELF 头解析
      │                       │
      │                       └──▶ 证书链验证
      │
      ▼
返回成功/失败
```

### 3.2 内存安全数据流

```
/proc/[pid]/maps 读取请求
        │
        ▼
hideaddr_header_prefix()
        │
        ├──▶ is_anon_exec() ──▶ VM_EXEC 检查
        │
        ├──▶ SELinux AVC 权限检查
        │
        └──▶ 返回隐藏地址 (start=0, end=0)
```

## 4. 线程模型

### 4.1 内核模块线程特性

| 模块 | 线程模型 | 说明 |
|------|----------|------|
| tzdriver | 多线程 + 工作队列 | SMC 命令异步处理 |
| qos_auth | 中断上下文 | 快速路径，禁用睡眠 |
| memory_security | 中断/LiteHCK hooks | 挂载点回调 |
| pac | 异常上下文 | 任务切换时签名 |

### 4.2 同步机制

| 机制 | 使用场景 |
|------|----------|
| Mutex | 会话列表保护 |
| Spinlock | 快速路径、短临界区 |
| RCU | 只读数据结构保护 |
| Atomic | 引用计数 |

## 5. 关键时序

### 5.1 SMC 命令时序

```
时间轴
  │
  │  用户态发起请求
  │      │
  │      ▼
  │  ┌──────────────────────────────┐
  │  │  tc_ns_client_open()       │  打开设备
  │  └──────────┬─────────────────┘
  │             │
  │             ▼
  │  ┌──────────────────────────────┐
  │  │  occupy_free_smc_entry()    │  分配 SMC 槽位
  │  └──────────┬─────────────────┘
  │             │
  │             ▼
  │  ┌──────────────────────────────┐
  │  │  smp_smc_send()             │  发送 SMC
  │  └──────────┬─────────────────┘
  │             │
  │             ▼ (等待 TEE 响应)
  │  ┌──────────────────────────────┐
  │  │  copy_smc_out_entry()       │  读取响应
  │  └──────────┬─────────────────┘
  │             │
  │             ▼
  │  返回结果给用户态
```

### 5.2 指针认证时序

```
任务切换 (context switch)
        │
        ▼
switch_to()
        │
        ├──▶ sign_thread_context()
        │           │
        │           └──▶ PACIASP (签名 SP)
        │           └──▶ PACIASP (签名 LR)
        │           └──▶ PACGA (哈希链)
        │
        └──▶ auth_thread_context()
                    │
                    └──▶ AUTIASP (验证 SP)
                    └──▶ AUTIASP (验证 LR)
                    └──▶ PACGA (验证哈希)
```

## 6. 依赖关系

### 6.1 模块间依赖

```
无依赖（独立模块）
├── ucollection              # 基础数据结构
│
├── 依赖 SELinux
├── memory_security          # SELinux AVC
├── code_sign                # SELinux 类定义
├── xpm                      # SELinux 标签
├── container_escape_detection  # SELinux 权限
│
├── 依赖 kernel_linux_5.10
├── newip                    # 网络协议栈
├── tzdriver                 # TEE 驱动
├── pac                      # ARM64 指令
│
└── 相互依赖
    └── code_sign ──▶ xpm   # 代码签名 → 执行权限
```
