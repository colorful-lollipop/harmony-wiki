## 2. 已识别风险

### 2.1 高风险项

#### A. TZDriver SMC 命令注入

| 属性 | 值 |
|------|-----|
| **风险等级** | 高 |
| **攻击面** | IOCTL 接口 |
| **证据** | `tc_client_driver.c` 公共 IOCTL 处理 |

**触发条件**:
```
1. 用户态进程调用 ioctl(TC_NS_CLIENT_IOCTL_SEND_CMD_REQ)
2. 构造恶意的命令缓冲区
3. 传递未验证的参数到 TEE
```

**潜在影响**:
- TEE 侧代码执行
- 敏感数据泄露
- 提权攻击

**修复建议**:
- 实施严格的参数边界检查
- 命令缓冲区完整性校验
- 白名单化允许的命令

#### B. 内存安全模块 TOCTOU 竞态

| 属性 | 值 |
|------|-----|
| **风险等级** | 中 |
| **攻击面** | /proc 接口 |
| **证据** | `hideaddr_header_prefix()` |

**触发条件**:
```
1. 进程 A 读取 /proc/[pid]/maps
2. 内核验证进程类型和权限
3. 进程 A 的地址空间被修改
4. 验证结果与实际不一致
```

**潜在影响**:
- KASLR 泄露
- 信息收集用于后续攻击

**修复建议**:
- 使用 seccomp 或其他隔离机制
- RCU 保护读取操作

---

### 2.2 中风险项

#### C. JIT_MEMORY 内存耗尽

| 属性 | 值 |
|------|-----|
| **风险等级** | 中 |
| **攻击面** | 内存分配 |
| **证据** | `jit_space_list.c` 无配额限制 |

**触发条件**:
```
1. 恶意应用大量调用 mmap(MAP_JIT)
2. 每个 JIT 区域分配 struct jit_space_node
3. 内核内存耗尽
```

**潜在影响**:
- 拒绝服务 (DoS)
- 系统不稳定

**修复建议**:
- 添加每个进程的 JIT 区域数量限制
- 使用 kmemcg 配额控制

#### D. RPMB 竞争条件

| 属性 | 值 |
|------|-----|
| **风险等级** | 中 |
| **攻击面** | 设备操作 |
| **证据** | `agent_rpmb/core/agent_rpmb.c` 锁管理 |

**触发条件**:
```
1. 多进程同时访问 RPMB
2. 计数器锁竞争
3. 超时检测窗口期
```

**潜在影响**:
- RPMB 写入顺序错误
- 数据不一致

**修复建议**:
- 增强锁机制
- 完善超时处理

---

### 2.3 低风险项

#### E. PAC Cookie 预测

| 属性 | 值 |
|------|-----|
| **风险等级** | 低 |
| **攻击面** | 用户/内核接口 |
| **证据** | `jit_memory.c` cookie 参数 |

**触发条件**:
```
1. 用户空间可预测 cookie 值
2. 暴力猜测 cookie
```

**潜在影响**:
- JIT 区域劫持

**修复建议**:
- 内核生成随机 cookie
- 拒绝用户空间传递的 cookie

#### F. 死代码

| 属性 | 值 |
|------|-----|
| **风险等级** | 低 |
| **攻击面** | 代码质量 |
| **证据** | `jit_space_list.c:47-48` 未使用变量 |

**潜在影响**:
- 维护负担
- 潜在的逻辑错误

**修复建议**:
- 移除死代码
- 增强代码审查
