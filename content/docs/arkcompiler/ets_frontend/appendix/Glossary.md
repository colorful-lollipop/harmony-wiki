# 术语表

## A

### ABC
**Ark ByteCode** - ARK 运行时执行的字节码文件格式。

### AOT
**Ahead-of-Time** - 提前编译，在运行前将源代码编译为字节码。

## B

### Binder
符号绑定器，负责解析符号引用、管理作用域和收集声明。

### Bytecode
字节码，一种中间代码格式，由虚拟机解释执行。

## C

### Checker
类型检查器，负责类型推断和类型兼容性验证。

## D

### Driver
编译驱动，协调各编译阶段。

## E

### ETS
**Enhanced TypeScript** - OpenHarmony 应用开发语言，是 TypeScript 的超集。

## F

### Frontend
编译器前端，负责词法分析、语法解析和语义分析。

## I

### IR
**Intermediate Representation** - 中间表示，源代码和字节码之间的抽象语法结构。

## L

### Lexer
词法分析器，将源代码转换为 Token 序列。

## M

### Merge ABC
ABC 文件合并工具，将多个字节码文件合并为一个。

## N

### N-API
**Node.js API** - Native ↔ JavaScript 互操作接口。

## P

### Parser
语法解析器，将 Token 序列转换为抽象语法树 (AST)。

### Panda Runtime
ARK 运行时引擎，执行字节码的虚拟机。

## R

### Runtime Core
运行时核心库，提供基础运行时能力。
