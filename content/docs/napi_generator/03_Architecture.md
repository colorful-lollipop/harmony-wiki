## 数据流

### 1. dts2cpp 数据流

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                          dts2cpp 数据流                                       │
└─────────────────────────────────────────────────────────────────────────────┘

  1. 解析阶段
  ┌─────────────────┐      ┌─────────────────┐      ┌─────────────────┐
  │  .d.ts 文件     │ ───▶ │  analyze.js     │ ───▶ │  structOfTs     │
  │  (TS 声明)      │      │  (清理+解析)    │      │  (结构化数据)   │
  └─────────────────┘      └─────────────────┘      └─────────────────┘
        │                                                  │
        │ structOfTs 结构:                                 │
        │ {                                               │
        │   namespace: string,                            │
        │   interfaces: [...],                            │
        │   functions: [{                                 │
        │     name, type, params, returnType             │
        │   }],                                           │
        │   enums: [...],                                 │
        │   ...                                           │
        │ }                                               │
        │                                                  │
        ▼                                                  ▼
  ┌─────────────────────────────────────────────────────────────────────────┐
  │  2. 生成阶段                                                             │
  │  ┌─────────────────┐      ┌─────────────────┐      ┌─────────────────┐  │
  │  │  generate.js    │ ───▶ │  *_middle.h    │      │  N-API 类型     │  │
  │  │  (代码模板)     │      │  *_middle.cpp  │      │  映射           │  │
  │  └─────────────────┘      └─────────────────┘      └─────────────────┘  │
  │                               │                                         │
  │  类型映射:                     ▼                                         │
  │  ┌──────────────┐     ┌─────────────────┐                               │
  │  │ string       │ ───▶│ napi_create_    │                               │
  │  │              │     │ string_utf8     │                               │
  │  ├──────────────┤     └─────────────────┘                               │
  │  │ number       │ ───▶│ napi_create_int32│                              │
  │  │ (配置 uint32)│     │ (或其他数值类型) │                              │
  │  ├──────────────┤     └─────────────────┘                               │
  │  │ boolean      │ ───▶│ napi_create_    │                               │
  │  │              │     │ boolean         │                               │
  │  └──────────────┘     └─────────────────┘                               │
  └─────────────────────────────────────────────────────────────────────────┘
```

## 线程模型

### 1. N-API 异步工作线程模型

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                      N-API 异步工作线程模型                                   │
└─────────────────────────────────────────────────────────────────────────────┘

  JS 调用端                              Native 执行端
       │                                      │
       │ napi_create_async_work()             │
       │─────────────────────────────────────▶│
       │                                      │ 创建异步工作
       │                                      │ (工作队列)
       │                                      ▼
       │                              ┌───────────────┐
       │                              │ Worker 线程   │
       │                              │ (独立线程)    │
       │                              └───────────────┘
       │                                      │
       │                                      │ 执行业务逻辑
       │                                      │ (耗时操作)
       │                                      ▼
       │                              ┌───────────────┐
       │                              │ napi_         │
       │                              │ delete_async_work
       │◀─────────────────────────────────────│
       │                                      │
       │ napi_queue_async_work()              │
       │ (回到 JS 事件循环)                    │
       ▼                                      ▼

  关键 API:
  - napi_create_async_work(env, execute, complete, data, &work)
  - napi_queue_async_work(env, work)
  - napi_delete_async_work(env, work)
```

### 2. h2sa IPC 线程模型

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                      SA IPC 线程模型                                          │
└─────────────────────────────────────────────────────────────────────────────┘

  客户端进程                                    服务端进程
       │                                              │
       │ SendRequest()                                 │
       │─────────────────────────────────────────────▶│
       │                                              │ Binder 驱动
       │                                              │ (内核中转)
       │                                              ▼
       │                                      ┌───────────────┐
       │                                      │ Binder 线程池 │
       │                                      │ (IPC 接收)    │
       │                                      └───────────────┘
       │                                              │
       │                                              │ OnRemoteRequest()
       │                                              ▼
       │                                      ┌───────────────┐
       │                                      │ 业务线程      │
       │                                      │ (处理请求)    │
       │                                      └───────────────┘
       │                                              │
       │                                              │ 序列化响应
       │                                              ▼
       │◀─────────────────────────────────────────────│
       │                                              │
       │ MessageParcel::ReadInt32()                   │
       │ (解析返回值)                                  │
       ▼                                              ▼

  关键类:
  - IRemoteProxy: 客户端代理，SendRequest() 发送请求
  - IRemoteStub: 服务端存根，OnRemoteRequest() 接收请求
  - MessageParcel: 数据序列化/反序列化
```
