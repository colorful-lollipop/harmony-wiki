## 新人阅读顺序

建议首次阅读按以下顺序：

1. **[首页](index.md)** ⭐ 必读
   - 理解仓库定位和核心作用
   - 了解配置文件的层级关系

2. **[项目概览](01_Overview.md)** ⭐ 必读
   - 掌握项目边界和核心能力
   - 理解关键概念（子系统、部件、Feature）

3. **[目录结构](02_Structure.md)** ⭐ 必读
   - 熟悉三类目录（base/inherit/products）
   - 了解文件命名规范

4. **[配置继承](03_Inheritance.md)** ⭐ 必读
   - 理解配置合并机制
   - 掌握 Feature 重载规则

5. **[产品配置](04_Products.md)** 📖 按需阅读
   - 根据感兴趣的产品类型阅读
   - 了解不同设备的部件差异

6. **[安全风险](05_Security.md)** 📖 建议阅读
   - 了解配置相关风险

7. **[常见问题](06_FAQ.md)** 📖 参考
   - 遇到问题时查阅
