## 更新说明

### 文档语言

本文档体系默认使用简体中文编写。如需英文版本，可参考根目录下的 `README.en.md`。

### 文档格式

所有文档遵循以下规范：
- 简体中文内容
- 中文标点符号（，。：；？！""）
- 一致的标题层级
- 证据引用的标准格式

### 证据引用标准

文档中涉及的关键结论均标注了证据来源，格式如下：

**证据来源**：`文件路径:行号`

```
示例：
**证据来源**：`README.md:1-6`
> 引用内容
```
