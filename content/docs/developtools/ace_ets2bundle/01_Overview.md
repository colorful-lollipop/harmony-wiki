# 项目概览

## 项目定位

**developtools_ets2bundle** 是 OpenHarmony 系统的核心编译器组件，负责将 **ETS (Extended TypeScript/ArkTS)** 声明式 UI 代码编译为可在 Ark 运行时执行的字节码。

### 核心能力

| 能力 | 描述 | 关键文件 |
|------|------|----------|
| **语法编译** | ETS 语法 → ABC 字节码 | `compiler/src/gen_abc_plugin.ts` |
| **类型检查** | 编译时类型验证 | `compiler/src/ets_checker.ts` |
| **UI 转换** | 声明式 UI → 运行时调用 | `compiler/src/process_ui_syntax.ts` |
| **插件扩展** | ArkUI 插件系统 | `arkui-plugins/` |
| **Native 互操作** | JS/Native 桥接 | `koala-wrapper/` |

## 关键概念

### ETS (Extended TypeScript)

ETS 是 OpenHarmony 的首选应用开发语言，提供：

- **声明式 UI**: 类似 SwiftUI/Flutter 的组件化开发
- **类型安全**: 编译时类型检查
- **跨平台**: 统一的代码基础

### ABC (Ark Bytecode)

Ark 编译器的字节码格式：

- `.abc` 文件: 编译产物
- 类似于 Java bytecode
- 由 Ark Runtime 解释执行

### 组件 (Component)

ArkUI 的基本构建单元：

```typescript
@Component
struct MyComponent {
  @State name: string = 'Hello'

  build() {
    Text(this.name)
  }
}
```
