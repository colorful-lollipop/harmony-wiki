# 架构说明

## 系统架构概览

Ace ETS2Bundle 采用分层架构设计，从上到下分为四个主要层次：

```
┌─────────────────────────────────────────────────────────────────────────┐
│                         应用开发层                                       │
│  ┌─────────────────────────────────────────────────────────────────┐   │
│  │              ETS/ArkTS 源码 (.ets 文件)                          │   │
│  │  @Component @Entry @Preview @State @Prop @Link ...             │   │
│  └─────────────────────────────────────────────────────────────────┘   │
├─────────────────────────────────────────────────────────────────────────┤
│                        编译器处理层                                     │
│  ┌─────────────────┐  ┌─────────────────┐  ┌─────────────────────────┐ │
│  │  语法解析        │  │  类型检查        │  │  语法转换/代码生成      │ │
│  │  TypeScript     │  │  ets_checker    │  │  process_*.ts          │ │
│  │  Parser         │  │  Linter         │  │  gen_abc_plugin        │ │
│  └─────────────────┘  └─────────────────┘  └─────────────────────────┘ │
│                                                                      │
│  ┌─────────────────┐  ┌─────────────────┐  ┌─────────────────────────┐ │
│  │  ArkUI 插件      │  │  Fast Build     │  │  系统 API 检查          │ │
│  │  ui-plugins     │  │  Rollup 插件    │  │  system_api            │ │
│  └─────────────────┘  └─────────────────┘  └─────────────────────────┘ │
├─────────────────────────────────────────────────────────────────────────┤
│                        字节码生成层                                     │
│  ┌─────────────────────────────────────────────────────────────────┐   │
│  │               es2abc (Native 可执行文件)                          │   │
│  │          .ets → TypeScript AST → ABC 字节码                      │   │
│  └─────────────────────────────────────────────────────────────────┘   │
├─────────────────────────────────────────────────────────────────────────┤
│                        运行时支撑层                                     │
│  ┌─────────────────┐  ┌─────────────────┐  ┌─────────────────────────┐ │
│  │  Koala N-API    │  │  Ark Runtime    │  │  OpenHarmony 系统      │ │
│  │  Addon (.node)  │  │  ABC 解释执行   │  │  基础能力              │ │
│  └─────────────────┘  └─────────────────┘  └─────────────────────────┘ │
└─────────────────────────────────────────────────────────────────────────┘
```

## 编译器核心架构

### 编译流程

```
ETS 源码 (.ets)
      ↓
┌─────────────────────────────────────────────────────────────────────┐
│  1. 项目配置初始化 (main.js)                                          │
│     - 读取 module.json / manifest.json                               │
│     - 初始化项目配置 projectConfig                                   │
│     - 加载系统模块路径                                               │
└─────────────────────────────────────────────────────────────────────┘
      ↓
┌─────────────────────────────────────────────────────────────────────┐
│  2. 语法解析 (TypeScript Parser)                                      │
│     - 生成 AST (Abstract Syntax Tree)                               │
│     - 支持 ES Module 语法解析                                        │
└─────────────────────────────────────────────────────────────────────┘
      ↓
┌─────────────────────────────────────────────────────────────────────┐
│  3. UI 语法转换 (process_ui_syntax.ts)                               │
│     - @Component 等装饰器处理                                        │
│     - build() 方法转换                                               │
│     - 状态装饰器 (@State, @Prop, @Link) 转换                        │
│     - ForEach / If / LazyForEach 循环转换                            │
└─────────────────────────────────────────────────────────────────────┘
      ↓
┌─────────────────────────────────────────────────────────────────────┐
│  4. 类型检查 (ets_checker.ts)                                         │
│     - ArkTS 类型规则验证                                             │
│     - 静态语法检查                                                   │
│     - API 可用性检查                                                 │
└─────────────────────────────────────────────────────────────────────┘
      ↓
┌─────────────────────────────────────────────────────────────────────┐
│  5. ABC 字节码生成                                                    │
│     - 调用 es2abc 工具 (child_process)                               │
│     - 生成 .abc 字节码文件                                           │
│     - 支持 AOT 编译 ( ark_aot_compiler)                              │
└─────────────────────────────────────────────────────────────────────┘
```

### 核心模块关系

```
┌─────────────────────────────────────────────────────────────────────────┐
│                              main.js                                     │
│                         (项目初始化入口)                                  │
└──────────────────────────────────┬────────────────────────────────────────┘
                                   │
┌──────────────────────────────────┼────────────────────────────────────────┐
│ 预处理阶段                        │                                        │
│ ┌────────────────┐  ┌───────────┐│                                        │
│ │ pre_process.ts │→ │process_* ││                                        │
│ │ 预处理入口     │  │ 语法转换  ││                                        │
│ └────────────────┘  └───────────┘│                                        │
└──────────────────────────────────┼────────────────────────────────────────┘
                                   │
┌──────────────────────────────────┼────────────────────────────────────────┐
│ 类型检查阶段                      │                                        │
│ ┌────────────────┐  ┌───────────┐│                                        │
│ │ ets_checker.ts │→ │do_arkTS_ ││                                        │
│ │ 类型服务       │  │ linter   ││                                        │
│ └────────────────┘  └───────────┘│                                        │
└──────────────────────────────────┼────────────────────────────────────────┘
                                   │
┌──────────────────────────────────┼────────────────────────────────────────┐
│ 代码生成阶段                      │                                        │
│ ┌────────────────┐  ┌───────────┐│                                        │
│ │ gen_abc.ts     │→ │es2abc    ││                                        │
│ │ ABC 生成       │  │Native工具 ││                                        │
│ └────────────────┘  └───────────┘│                                        │
└──────────────────────────────────┴────────────────────────────────────────┘
```

## ArkUI 插件系统架构

### 插件类型

| 插件类型 | 入口函数 | 职责 |
|---------|---------|------|
| UI 插件 | `uiTransform()` | 声明式 UI 语法转换 |
| 语法检查插件 | `uiSyntaxLinterTransform()` | 编译时语法验证 |
| 互操作插件 | `interopTransform()` | JS/TS 互操作支持 |
| Memo 优化插件 | `unmemoizeTransform()` | 编译优化 |

### 插件注册机制

```
┌─────────────────────────────────────────────────────────────────────────┐
│                           plugin-context.ts                             │
│  interface Plugins {                                                     │
│    name: string;                                                       │
│    afterNew?: PluginHandler;       // 新建后                            │
│    parsed?: PluginHandler;         // 解析后                            │
│    scopeInited?: PluginHandler;   // 作用域初始化后                      │
│    checked?: PluginHandler;       // 类型检查后                          │
│    lowered?: PluginHandler;       // 降级后                             │
│    asmGenerated?: PluginHandler;  // 汇编生成后                         │
│    binGenerated?: PluginHandler;  // 二进制生成后                        │
│    clean?: PluginHandler;         // 清理                               │
│  }                                                                         │
└─────────────────────────────────────────────────────────────────────────┘
```

### AST 遍历机制

```
┌─────────────────────────────────────────────────────────────────────────┐
│                         program-visitor.ts                              │
│                    (程序级 AST 遍历协调器)                                │
└──────────────────────────────────┬────────────────────────────────────────┘
                                   │
            ┌──────────────────────┼──────────────────────┐
            │                      │                      │
┌───────────▼───────────┐ ┌───────▼─────────┐ ┌─────────▼────────────┐
│  AbstractVisitor      │ │ComponentTransformer│ │PropertyTranslator │
│  (所有转换器基类)      │ │(组件转换)        │ │(属性翻译)          │
│                       │ │                  │ │                    │
│ - visitor(node)       │ │                  │ │                    │
│ - visitEachChild()   │ │                  │ │                    │
└───────────────────────┘ └──────────────────┘ └────────────────────┘
```

## Koala Native 模块架构

### 架构分层

```
┌─────────────────────────────────────────────────────────────────────────┐
│                         arkui-plugins (TypeScript)                       │
│              动态 require('./es2panda.node')                             │
└──────────────────────────────────┬────────────────────────────────────────┘
                                   │ N-API 调用
┌──────────────────────────────────▼────────────────────────────────────────┐
│                    koalaui/interop (N-API 胶水层)                       │
│  convertors-napi.h/cc - JS ↔ Native 类型转换                           │
│  KOALA_INTEROP_X 宏 - 自动注册 Native 函数                             │
└──────────────────────────────────┬────────────────────────────────────────┘
                                   │
┌──────────────────────────────────▼────────────────────────────────────────┐
│                    koala-wrapper/native (Native 实现)                    │
│  common.cc - 上下文管理、库加载                                         │
│  bridges.cc - 手动桥接函数                                              │
│  generated/bridges.cc - 自动生成的桥接函数                              │
└──────────────────────────────────┬────────────────────────────────────────┘
                                   │ 动态加载
┌──────────────────────────────────▼────────────────────────────────────────┐
│                     libes2panda_public.so/dll                           │
│                     (es2panda 编译器核心库)                              │
└─────────────────────────────────────────────────────────────────────────┘
```

### N-API 模块导出

```cpp
// 模块注册 (convertors-napi.cc:389)
NAPI_MODULE(INTEROP_LIBRARY_NAME, InitModule)
// 实际模块名: es2panda
// 命名空间: NativeModule

// JS 调用示例:
// NativeModule._CreateConfig(argc, argv)
// NativeModule._DestroyContext(contextPtr)
```

## 线程模型

### 编译线程模型

```
主线程 (Node.js)
    │
    ├──► Worker 进程 (cluster.fork)
    │        │
    │        └──► es2abc 子进程 (child_process.spawn)
    │                 │
    │                 └──► ABC 字节码生成
    │
    ├──► Worker 进程
    │        └──► 并行模块编译
    │
    └──► Worker 进程
             └──► 并行模块编译
```

### Fast Build 并行编译

```typescript
// manage_workers.ts
// 使用 cluster 模块创建多个 Worker
// 每个 Worker 负责一个模块的 ABC 生成
// 支持多核 CPU 并行编译
```

## 数据流

### 编译数据流

```
源文件 (.ets)
    │
    ├─► AST 生成 (TypeScript Parser)
    │         │
    │         └──► 语法树 (ts.SourceFile)
    │
    ├─► UI 语法转换 (process_ui_syntax.ts)
    │         │
    │         └──► 转换后 AST
    │
    ├─► 类型检查 (ets_checker.ts)
    │         │
    │         ├──► 错误/警告报告
    │         └──► 类型验证通过
    │
    └─► 字节码生成 (gen_abc.ts)
              │
              ├──► 子进程调用 es2abc
              ├──► 中间表示 (IR)
              └──► ABC 字节码 (.abc)
```
