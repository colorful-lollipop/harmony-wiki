## 文档贡献

### 如何更新本文档

1. **更新 API 文档**: 修改 `03_NAPI_Reference.md`，确保 API 签名与源码一致
2. **更新架构**: 修改 `01_Architecture.md` 或 `02_Plugin_System.md`
3. **新增章节**: 在 `wiki/` 目录创建新文件，并在本 `SUMMARY.md` 中添加链接
4. **修复错误**: 直接编辑对应文件或提交 Issue

### 文档规范

- 所有关键结论必须可追溯到代码证据（路径+符号）
- N-API 文档必须包含完整的参数校验说明
- 安全文档必须包含证据、触发条件、影响范围、修复建议
- 术语使用需与 OpenHarmony 官方保持一致
