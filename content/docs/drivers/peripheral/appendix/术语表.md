# 术语表

本文档汇总 OpenHarmony peripheral 驱动开发中涉及的核心术语和缩写，方便新人快速查阅。

## A-C

| 术语 | 全称 | 解释 |
|-----|------|------|
| **Binder** | - | Android/OpenHarmony 的 IPC 机制，用于进程间通信 |
| **DAL** | Driver Abstraction Layer | 驱动抽象层 |
| **DDK** | Device Driver Kit | 设备驱动开发套件，本仓库 `usb/ddk/` 目录 |
| **DRM** | Digital Rights Management | 数字版权管理；也指 Direct Rendering Manager（显示子系统） |
| **DAC** | Discretionary Access Control | 自主访问控制 |

## D-F

| 术语 | 全称 | 解释 |
|-----|------|------|
| **fb0** | framebuffer 0 | 帧缓冲设备节点，通常位于 `/dev/graphics/fb0` |
| **fuzzer** | - | 模糊测试工具/代码，用于发现安全漏洞 |
| **GID** | Group ID | 用户组标识符 |

## H-L

| 术语 | 全称 | 解释 |
|-----|------|------|
| **HAL** | Hardware Abstraction Layer | 硬件抽象层，屏蔽硬件差异 |
| **HDF** | Hardware Driver Framework | 硬件驱动框架，OpenHarmony 的驱动基础设施 |
| **HDI** | Hardware Driver Interface | 硬件驱动接口，定义上层服务与驱动通信的标准 |
| **IPC** | Inter-Process Communication | 进程间通信 |
| **IRemoteBroker** | - | HDF 中的远程对象基类，用于 IPC 调用 |

## M-P

| 术语 | 全称 | 解释 |
|-----|------|------|
| **MessageParcel** | - | HDF 中的消息序列化/反序列化工具 |
| **MTP** | Media Transfer Protocol | 媒体传输协议，USB 设备类之一 |
| **N-API** | Native API | 原生 API，通常指 C/C++ 接口 |
| **OEM** | Original Equipment Manufacturer | 原始设备制造商 |
| **OHOS** | OpenHarmony OS | 开源鸿蒙操作系统 |

## R-S

| 术语 | 全称 | 解释 |
|-----|------|------|
| **RPC** | Remote Procedure Call | 远程过程调用 |
| **SA** | System Ability | 系统能力，OpenHarmony 的系统服务抽象 |
| **Stub** | - | 服务端存根，处理 IPC 请求 |
| **Proxy** | - | 客户端代理，发起 IPC 调用 |

## T-V

| 术语 | 全称 | 解释 |
|-----|------|------|
| **TOCTOU** | Time-of-Check-Time-of-Use | 检查-使用时间差漏洞 |
| **UID** | User ID | 用户标识符 |
| **VDI** | Virtual Driver Interface | 虚拟驱动接口 |

## W-Z

| 术语 | 全称 | 解释 |
|-----|------|------|
| **V4L2** | Video4Linux 2 | Linux 视频设备驱动框架 |
| **z.so** | - | OpenHarmony 的动态库后缀 |

---

## 模块相关术语

### Audio 模块

| 术语 | 解释 |
|-----|------|
| **ADM** | Audio Device Manager，音频设备管理器 |
| **Renderer** | 音频渲染器，负责音频播放 |
| **Capturer** | 音频捕获器，负责录音 |
| **Audio Scene** | 音频场景，如通话、媒体播放 |

### Camera 模块

| 术语 | 解释 |
|-----|------|
| **Pipeline** | 相机数据处理流水线 |
| **Stream** | 相机数据流（预览、拍照、录像） |
| **HDI** | Camera Host Driver Interface |
| **V4L2** | Video4Linux 2，Linux 视频驱动接口 |

### Display 模块

| 术语 | 解释 |
|-----|------|
| **Composer** | 显示合成器，合成多个显示层 |
| **Gralloc** | Graphics Memory Allocator，图形内存分配器 |
| **Buffer** | 显示缓冲区 |
| **Layer** | 显示层 |

### USB 模块

| 术语 | 解释 |
|-----|------|
| **DDK** | USB Device Driver Kit |
| **PnP** | Plug and Play，即插即用 |
| **SCSI** | Small Computer System Interface |
| **ACM** | Abstract Control Model，USB 串口类 |

### Sensor 模块

| 术语 | 解释 |
|-----|------|
| **Sensor** | 传感器设备 |
| **Data Callback** | 传感器数据回调 |
| **Option** | 传感器配置选项（精度、频率） |

---

## 文件与目录术语

| 路径模式 | 含义 |
|---------|------|
| `interfaces/` | HDI 接口定义目录 |
| `hdi_service*/` | HDI 服务实现目录 |
| `hal/` | 硬件抽象层实现 |
| `common/` | 公共组件/工具 |
| `chipset/` | 芯片相关代码 |
| `utils/` | 工具类代码 |
| `test/` | 测试代码目录 |
