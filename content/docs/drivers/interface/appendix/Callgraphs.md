# 关键调用链

## 概述

本文档描述 HDI 接口的关键调用链路，从客户端调用到驱动实现的完整流程。

---

## Audio 调用链路

### 场景：播放音频

```
┌─────────────────────────────────────────────────────────────────┐
│                        应用层                                      │
│  AudioPlayer::Play()                                            │
└─────────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────────┐
│                      Framework 层                                 │
│  audio_renderer->Start()                                        │
│      ↓                                                          │
│  获取 IAudioManager Proxy                                        │
└─────────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────────┐
│                    HDI 客户端代理层                               │
│  IAudioManager::Get()  →  获取 sptr<IAudioManager>             │
│      ↓                                                          │
│  manager->LoadAdapter()  →  IPC 调用                            │
│      ↓                                                          │
│  获取 IAudioAdapter Proxy                                        │
└─────────────────────────────────────────────────────────────────┘
                              ↓ IPC (binder/ipc)
┌─────────────────────────────────────────────────────────────────┐
│                    HDI 服务端存根层                               │
│  AudioManagerStub::LoadAdapter()  →  参数反序列化                 │
│      ↓                                                          │
│  调用实际服务实现                                                  │
└─────────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────────┐
│                    驱动实现层 (drivers_peripheral)                │
│  AudioAdapterService::LoadAdapter()                             │
│      ↓                                                          │
│  加载音频驱动模块                                                  │
│      ↓                                                          │
│  返回 AudioRender/Capture 实例                                    │
└─────────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────────┐
│                    硬件抽象层                                      │
│  ALSA/DirectSound 驱动                                           │
└─────────────────────────────────────────────────────────────────┘
```

### 关键代码路径

| 层级 | 文件 | 说明 |
|-----|------|------|
| 接口定义 | `audio/v1_0/IAudioManager.idl` | 定义 HDI 接口 |
| 代理生成 | `libaudio_client_*.so` | 客户端 IPC 代理 |
| 存根生成 | `libaudio_stub_*.so` | 服务端 IPC 存根 |
| 驱动实现 | `drivers_peripheral/audio/` | 音频驱动实现 |

## Sensor 调用链路

### 场景：注册传感器数据回调

```
┌─────────────────────────────────────────────────────────────────┐
│                        应用层                                      │
│  SensorManager::Register(sensorId, callback)                    │
└─────────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────────┐
│                      Framework 层                                 │
│  封装 HDI 调用                                                   │
└─────────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────────┐
│                    HDI 客户端代理层                               │
│  ISensorInterface::Register()                                    │
└─────────────────────────────────────────────────────────────────┘
                              ↓ IPC
┌─────────────────────────────────────────────────────────────────┐
│                    HDI 服务端存根层                               │
│  SensorInterfaceStub::Register()                                 │
│      ↓                                                          │
│  保存回调对象引用                                                 │
└─────────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────────┐
│                    驱动实现层                                     │
│  SensorDriver::Enable(sensorId)                                  │
│      ↓                                                          │
│  配置硬件采样参数                                                 │
│      ↓                                                          │
│  启动中断/轮询                                                   │
└─────────────────────────────────────────────────────────────────┘
                              ↓ 中断/事件
┌─────────────────────────────────────────────────────────────────┐
│                    硬件层                                        │
│  传感器硬件产生数据中断                                           │
└─────────────────────────────────────────────────────────────────┘
                              ↑
┌─────────────────────────────────────────────────────────────────┐
│                    驱动实现层                                     │
│  中断处理函数 → 读取传感器数据                                    │
│      ↓                                                          │
│  通过回调通知上层                                                 │
│  ISensorCallback::OnDataEvent()  →  IPC 调用                    │
└─────────────────────────────────────────────────────────────────┘
                              ↓ IPC
┌─────────────────────────────────────────────────────────────────┐
│                    HDI 客户端代理层                               │
│  SensorCallbackProxy::OnDataEvent()                             │
└─────────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────────┐
│                      Framework 层                                 │
│  回调给应用注册的 listener                                        │
└─────────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────────┐
│                        应用层                                      │
│  SensorDataListener::OnData()                                   │
└─────────────────────────────────────────────────────────────────┘
```

### 关键接口

**证据**: `sensor/v3_0/ISensorInterface.idl:53-175`

```idl
interface ISensorInterface {
    Enable([in] DeviceSensorInfo deviceSensorInfo);
    Register([in] int groupId, [in] ISensorCallback callbackObj);
    // ...
};

[callback] interface ISensorCallback {
    OnDataEvent([in] struct HdfSensorEvents event);
};
```

```

│                        应用层                                      │
│  CameraKit::CreateCamera()                                       │
│  camera->Capture()                                               │
└─────────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────────┐
│                      Framework 层                                 │
│  CameraHostProxy::OpenCamera()                                   │
│  StreamOperatorProxy::Capture()                                  │
└─────────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────────┐
│                    HDI 客户端代理层                               │
│  ICameraHost::OpenCamera()                                      │
│  IStreamOperator::Capture()                                      │
└─────────────────────────────────────────────────────────────────┘
                              ↓ IPC
┌─────────────────────────────────────────────────────────────────┐
│                    HDI 服务端存根层                               │
│  CameraHostStub::OpenCamera()                                    │
│  StreamOperatorStub::Capture()                                  │
└─────────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────────┐
│                    驱动实现层                                     │
│  CameraService::OpenDevice()                                    │
│  CameraDriver::StartCapture()                                   │
└─────────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────────┐
│                    硬件层                                        │
│  Camera Sensor + ISP                                             │
└─────────────────────────────────────────────────────────────────┘
                              ↑ 数据流
┌─────────────────────────────────────────────────────────────────┐
│                    驱动实现层                                     │
│  接收图像数据 → BufferHandle 传递                                │
│      ↓                                                          │
│  IStreamOperatorCallback::OnCaptureEnded()  →  上报完成         │
└─────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────┐
│                      Framework 层                                 │
│  回调给应用层                                                     │
└─────────────────────────────────────────────────────────────────┘
```

**证据**: `camera/v1_5/ICameraHost.idl`


## 调用模式总结

### 同步调用模式

```
Client → Proxy → IPC → Stub → Service → 返回
```

适用于：简单查询、配置操作

### 异步回调模式

```
Client → Register Callback
    ↓
Service → 事件触发 → Stub → Proxy → Callback → Client
```

适用于：传感器数据、事件通知

### 直通模式 (Passthrough)

```
Client → Stub → Service (同进程)
```

适用于：延迟敏感操作、无需进程隔离
