## 2. 外部输入清单

### 2.1 文件系统输入

| 接口 | 文件 | 行号 | 输入类型 | 风险 |
|------|------|------|----------|------|
| `LoadStringFromFile` | `file_ex.cpp` | 100 | 文件路径 | 路径遍历 |
| `SaveStringToFile` | `file_ex.cpp` | ~120 | 文件路径 + 内容 | 路径遍历 |
| `GetDirFiles` | `directory_ex.cpp` | 200 | 目录路径 | 符号链接循环 |
| `CreateDir` | `directory_ex.cpp` | ~150 | 目录路径 | 路径遍历 |
| `MappedFile::Open` | `mapped_file.cpp` | ~50 | 文件路径 | 资源耗尽 |

**输入验证状态**:
- ❌ 无路径规范化（如 `realpath`）
- ✅ 使用 `open()` 系统调用
- ❌ 无符号链接防护（`O_NOFOLLOW`）
- ✅ 使用 `unique_fd` RAII 管理

---

### 2.2 Parcel 数据输入

| 接口 | 文件 | 行号 | 输入类型 | 风险 |
|------|------|------|----------|------|
| `Parcel::ParseFrom` | `parcel.cpp` | ~450 | 原始数据指针+大小 | 恶意数据 |
| `Parcel::WriteBuffer` | `parcel.cpp` | ~380 | 字节缓冲区 | 缓冲区溢出 |
| `Parcel::ReadBuffer` | `parcel.cpp` | ~510 | 长度参数 | 越界读取 |
| `Parcel::WriteString` | `parcel.cpp` | ~350 | 字符串 | 长度伪造 |
| `Parcel::ReadParcelable` | `parcel.cpp` | ~650 | 对象偏移 | 对象注入 |

**输入验证状态**:
- ✅ 容量检查（`EnsureWritableCapacity`）
- ✅ 对象偏移验证（`ValidateReadData`）
- ✅ 长度上限检查（`INT32_MAX`）
- ✅ 整数溢出检测（编译期）

## 5. 潜在攻击路径

### 5.1 Parcel 数据伪造攻击

```
攻击者                   Parcel                  受害者
   │                       │                        │
   │ 构造恶意 Parcel       │                        │
   │──────────────────────▶│                        │
   │                       │                        │
   │                       │  WriteObject()         │
   │                       │───────────────────────▶│
   │                       │                        │
   │                       │  读取伪造的对象偏移    │
   │                       │◀───────────────────────│
   │                       │                        │
   │                       │  尝试访问无效地址      │
   │                       │───────────────────────▶│
   │                       │                        │
   │                       │  崩溃/信息泄露        │
   │                       │◀───────────────────────│
```

**缓解措施**:
- `ValidateReadData` 验证对象偏移
- `PARCEL_OBJECT_CHECK` 宏启用对象检查
- 整数溢出检测防止大小伪造

### 5.2 路径遍历攻击

```
攻击者                   c_utils                 文件系统
   │                       │                        │
   │ LoadStringFromFile()  │                        │
   │("../../../etc/passwd")│                        │
   │──────────────────────▶│                        │
   │                       │                        │
   │                       │  open("../../../etc/   │
   │                       │       passwd")        │
   │                       │───────────────────────▶│
   │                       │                        │
   │                       │  读取敏感文件          │
   │                       │◀───────────────────────│
   │                       │                        │
   │ 敏感文件内容          │                        │
   │◀──────────────────────│                        │
```

**缓解措施**:
- 调用方需进行路径规范化
- 使用 `O_NOFOLLOW` 防止符号链接跳转
- 最小权限原则

### 5.3 共享内存越界访问

```
攻击者                   Ashmem                  共享内存
   │                       │                        │
   │ WriteData(buf,        │                        │
   │  offset=0,            │                        │
   │  size=INVALID)        │                        │
   │──────────────────────▶│                        │
   │                       │                        │
   │                       │  CheckValid()          │
   │                       │  边界检查              │
   │                       ├───────────────────────▶│
   │                       │                        │
   │                       │  检查失败              │
   │                       │◀───────────────────────│
   │                       │                        │
   │ 返回错误              │                        │
   │◀──────────────────────│                        │
```

**缓解措施**:
- `CheckValid` 进行严格边界检查
- 偏移+大小溢出检测
- 大小非负验证

## 7. 安全测试建议

### 7.1 模糊测试目标

| 目标 | 接口 | 变异策略 |
|------|------|----------|
| Parcel | `ParseFrom`, `WriteBuffer` | 随机字节、畸形对象偏移 |
| Ashmem | `WriteData`, `ReadData` | 边界值、负数、超大值 |
| 文件操作 | `LoadStringFromFile` | 畸形路径、长路径、特殊字符 |
| 字符串 | `UTF8ToUTF16` | 非法 UTF-8 序列 |

### 7.2 渗透测试检查项

- [ ] Parcel 对象偏移伪造
- [ ] 路径遍历（`../`, 符号链接）
- [ ] 超大文件映射
- [ ] 字符串长度伪造
- [ ] 并发条件下的竞态条件
- [ ] 整数溢出（大小计算）
