# c_utils Wiki

## 简介

本文档是 OpenHarmony **c_utils** 部件的工程 Wiki，旨在帮助开发者快速理解和使用这个 C++ 公共基础类库。

## 覆盖范围

本文档涵盖以下内容：

- **项目概览**: 定位、边界、核心能力、运行环境
- **目录结构**: 模块职责与组织方式
- **架构说明**: 组件关系、数据流、线程模型
- **对外 API**: C++ 接口使用指南
- **内部架构**: 模块设计、依赖关系
- **构建系统**: GN Targets、编译产物、安装路径
- **安全风险**: 攻击面分析与修复建议
- **问题排查**: 常见问题与定位方法

## 未覆盖范围

- 测试代码（`test/` 目录）
- 详细 API 文档（参考 `docs/` 目录官方文档）
- 具体业务场景使用示例

## 更新方式

本文档基于代码生成，建议随代码版本同步更新：

1. 代码变更后，检查相关 Wiki 页面
2. 更新接口定义、调用链、依赖关系
3. 验证安全分析是否仍然有效
4. 更新 `NOTES.md` 中的事实记录
