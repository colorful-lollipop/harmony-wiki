## 4. 关键时序图

### 4.1 NAPI 模块注册与调用时序

```mermaid
sequenceDiagram
    participant App as ArkTS 应用
    participant JS as JS 引擎
    participant NR as NAPI Runtime
    participant NC as 原生代码

    Note over NC: 模块加载时
    NC->>NC: NAPI_MODULE(myaddon, Init)
    NC->>NR: napi_module_register()
    NR->>JS: 注册模块

    Note over App: 运行时调用
    App->>JS: import myaddon from 'libmyaddon.so'
    JS->>NR: 查找已注册模块
    NR->>NC: Init(env, exports)
    NC->>NR: napi_define_properties()
    NR->>JS: 绑定函数到 JS 对象
    JS->>App: 返回模块对象

    App->>JS: myaddon.nativeFunction()
    JS->>NR: 调用原生函数
    NR->>NC: nativeFunction(env, info)
    NC->>NC: 执行业务逻辑
    NC->>NR: 返回结果
    NR->>JS: 转换结果
    JS->>App: 返回 JS 值
```

### 4.2 IPC 调用时序

```mermaid
sequenceDiagram
    participant Client as 客户端进程
    participant Proxy as IPC Proxy
    participant Kernel as Binder 驱动
    participant Stub as IPC Stub
    participant Service as 服务端进程

    Client->>Client: OH_IPCSkeleton_GetSelfTokenId()
    
    Client->>Proxy: 调用接口
    Proxy->>Kernel: 序列化数据 + Token
    Kernel->>Stub: 传递调用
    
    Stub->>Service: OH_IPCSkeleton_GetCallingTokenId()
    Note right of Service: 服务端校验调用者身份
    Service->>Service: 权限检查
    Service->>Stub: 返回结果
    
    Stub->>Kernel: 序列化响应
    Kernel->>Proxy: 返回响应
    Proxy->>Client: 返回结果
```
