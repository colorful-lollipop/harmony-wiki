## 1. N-API 模块加载调用链

```
应用启动
    │
    ▼
┌─────────────────────────────────────────┐
│ 1. 加载 NAPI 动态库                      │
│    dlopen("libmyaddon.so")              │
└─────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────┐
│ 2. 执行初始化函数（构造函数）             │
│    _register_myaddon()                  │
│    └── NAPI_C_CTOR 宏展开                │
└─────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────┐
│ 3. 注册模块到 NAPI 运行时                │
│    napi_module_register(&_module)      │
└─────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────┐
│ 4. JS 导入模块                           │
│    import myaddon from 'libmyaddon.so'  │
└─────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────┐
│ 5. 调用模块初始化函数                     │
│    Init(env, exports)                   │
│    └── napi_define_properties()         │
└─────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────┐
│ 6. 返回模块对象给 JS                     │
└─────────────────────────────────────────┘
```

**关键代码**:
```c
// third_party/node/src/node_api.h:64-98
#define NAPI_MODULE_X(modname, regfunc, priv, flags)                  \
  EXTERN_C_START                                                      \
    static napi_module _module =                                      \
    {                                                                 \
      NAPI_MODULE_VERSION, flags, __FILE__, regfunc, #modname, priv, {0}, \
    };                                                                \
    NAPI_C_CTOR(_register_ ## modname) {                              \
      napi_module_register(&_module);                                \
    }                                                                 \
  EXTERN_C_END
```

```
客户端进程
    │
    ▼
┌─────────────────────────────────────────┐

│    OH_IPCRemoteProxy *proxy = ...       │
└─────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────┐
│ 2. 构造请求数据                           │
│    OH_IPCParcel *data = OH_IPCParcel_Create();  │
│    OH_IPCParcel_WriteInterfaceToken(data, token);│
│    OH_IPCParcel_WriteInt32(data, param);        │
└─────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────┐
│ 3. 发送 IPC 请求                          │
│    OH_IPCRemoteProxy_SendRequest(proxy, code, data, reply, option); │
└─────────────────────────────────────────┘
    │
    ▼
Binder 驱动
    │
    ▼
服务端进程
    │
    ▼
┌─────────────────────────────────────────┐
│ 4. 接收请求                               │
│    OnRemoteRequest(code, data, reply)   │
└─────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────┐
│ 5. 身份校验                               │

    │

    ▼
```
