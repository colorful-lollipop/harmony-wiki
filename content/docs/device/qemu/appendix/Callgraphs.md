# 关键调用链

## VirtIO 块设备调用链

### 读操作调用链

```
┌─────────────────────────────────────────────────────────────────┐
│                    VirtIO Block Read Call Chain                  │
├─────────────────────────────────────────────────────────────────┤
│                                                                  │
│  User Space                                                     │
│  ┌───────────────────────────────────────────────────────────┐   │
│  │ [read(fd, buf, size)]                                    │   │
│  └───────────────────────────────────────────────────────────┘   │
│                              │                                   │
│                              ▼                                   │
│  VFS Layer                                                       │
│  ┌───────────────────────────────────────────────────────────┐   │
│  │ [vfs_read()] → [block_read()]                           │   │
│  └───────────────────────────────────────────────────────────┘   │
│                              │                                   │
│                              ▼                                   │
│  Block I/O Subsystem                                              │
│  ┌───────────────────────────────────────────────────────────┐   │
│  │ [bio_submit()] → [virtio_blk_request()]                 │   │
│  └───────────────────────────────────────────────────────────┘   │
│                              │                                   │
│                              ▼                                   │
│  VirtIO Driver Layer (drivers/virtio/virtblock.c)              │
│  ┌───────────────────────────────────────────────────────────┐   │
│  │ [VirtBlkRequest()] → [VirtQueueAddDesc()]                │   │
│  │                                                         │   │
│  │ [VirtQueueKick()] → [Notify QEMU via MMIO]              │   │
│  └───────────────────────────────────────────────────────────┘   │
│                              │                                   │
│                              ▼                                   │
│  VirtIO Transport (drivers/virtio/virtmmio.c)                   │
│  ┌───────────────────────────────────────────────────────────┐   │
│  │ [VirtIoMmioWrite()] → [Update Available Ring]           │   │
│  │                                                         │   │
│  │ [Interrupt raised to QEMU]                              │   │
│  └───────────────────────────────────────────────────────────┘   │
│                              │                                   │
│                              ▼                                   │
│  QEMU Emulation                                                  │
│  ┌───────────────────────────────────────────────────────────┐   │
│  │ [Handle VirtIO Request] → [Read from host file]         │   │
│  │                                                         │   │
│  │ [Write to Used Ring] → [Raise IRQ]                      │   │
│  └───────────────────────────────────────────────────────────┘   │
│                              │                                   │
│                              ▼                                   │
│  Interrupt Handling (return path)                                │
│  ┌───────────────────────────────────────────────────────────┐   │
│  │ [GIC/PLIC IRQ] → [LiteOS IRQ Handler]                   │   │
│  │                                                         │   │
│  │ [VirtIoIsr()] → [VirtQueueInterrupt()]                  │   │
│  │                                                         │   │
│  │ [Complete I/O] → [Wake waiting task]                   │   │
│  └───────────────────────────────────────────────────────────┘   │
│                              │                                   │
│                              ▼                                   │
│  Driver Completion                                                │
│  ┌───────────────────────────────────────────────────────────┐   │
│  │ [VirtBlkComplete()] → [Return to Block Subsystem]       │   │
│  └───────────────────────────────────────────────────────────┘   │
│                                                                  │
└─────────────────────────────────────────────────────────────────┘
```

### 关键代码路径

| 阶段 | 文件 | 函数 | 说明 |
|------|------|------|------|
| **IO 提交** | `virtblock.c` | `VirtBlkRequest()` | 解析请求，添加到描述符 |
| **设备通知** | `virtmmio.c` | `VirtIoMmioWrite()` | 写 MMIO 触发设备 |
| **中断处理** | `virtmmio.c` | `VirtIoIsr()` | 处理设备中断 |
| **完成通知** | `virtblock.c` | `VirtBlkComplete()` | 完成请求处理 |

**证据位置**:
- `drivers/virtio/BUILD.gn:32-37` (源文件列表)
- `drivers/virtio/virtblock.c` (核心实现)

## VirtIO 网络设备调用链

### 发送操作调用链

```
┌─────────────────────────────────────────────────────────────────┐
│                    VirtIO Net Send Call Chain                    │
├─────────────────────────────────────────────────────────────────┤
│                                                                  │
│  Network Stack (LWIP)                                           │
│  ┌───────────────────────────────────────────────────────────┐   │
│  │ [tcp_output()] / [udp_send()]                             │   │
│  └───────────────────────────────────────────────────────────┘   │
│                              │                                   │
│                              ▼                                   │
│  VirtIO Net Driver (drivers/virtio/virtnet.c)                   │
│  ┌───────────────────────────────────────────────────────────┐   │
│  │ [VirtNetStartXmit()] → [NetBuf to Descriptor]            │   │
│  │                                                         │   │
│  │ [VirtQueueAddDesc()] → [Setup TX descriptors]            │   │
│  │                                                         │   │
│  │ [VirtQueueKick()] → [Notify QEMU]                       │   │
│  └───────────────────────────────────────────────────────────┘   │
│                              │                                   │
│                              ▼                                   │
│  QEMU VirtIO Backend                                             │
│  ┌───────────────────────────────────────────────────────────┐   │
│  │ [Process TX descriptors] → [Write to TAP device]         │   │
│  │                                                         │   │
│  │ [Update Used Ring] → [Raise IRQ]                         │   │
│  └───────────────────────────────────────────────────────────┘   │
│                                                                  │
└─────────────────────────────────────────────────────────────────┘
```

## UART 驱动调用链

### 发送操作

```
┌─────────────────────────────────────────────────────────────────┐
│                    UART Send Call Chain                          │
├─────────────────────────────────────────────────────────────────┤
│                                                                  │
│  User Space                                                     │
│  ┌───────────────────────────────────────────────────────────┐   │
│  │ [write(fd, buf, count)] → [/dev/ttyS0]                   │   │
│  └───────────────────────────────────────────────────────────┘   │
│                              │                                   │
│                              ▼                                   │
│  VFS Layer                                                       │
│  ┌───────────────────────────────────────────────────────────┐   │
│  │ [tty_write()] → [uart_write()]                           │   │
│  └───────────────────────────────────────────────────────────┘   │
│                              │                                   │
│                              ▼                                   │
│  UART Driver (drivers/uart/uart_pl011.c)                         │
│  ┌───────────────────────────────────────────────────────────┐   │
│  │ [UartWrite()] → [Write to TX FIFO]                       │   │
│  │                                                         │   │
│  │ [Enable TX interrupt]                                    │   │
│  └───────────────────────────────────────────────────────────┘   │
│                              │                                   │
│                              ▼                                   │
│  Hardware (QEMU PL011)                                           │
│  ┌───────────────────────────────────────────────────────────┐   │
│  │ [Transmit data] → [TX interrupt when complete]           │   │
│  └───────────────────────────────────────────────────────────┘   │
│                                                                  │
└─────────────────────────────────────────────────────────────────┘
```

### 接收操作

```
┌─────────────────────────────────────────────────────────────────┐
│                    UART Receive Call Chain                       │
├─────────────────────────────────────────────────────────────────┤
│                                                                  │
│  Hardware (QEMU PL011)                                           │
│  ┌───────────────────────────────────────────────────────────┐   │
│  │ [RX interrupt] → [Read from RX FIFO]                     │   │
│  └───────────────────────────────────────────────────────────┘   │
│                              │                                   │
│                              ▼                                   │
│  UART Driver (drivers/uart/uart.c)                                │
│  ┌───────────────────────────────────────────────────────────┐   │
│  │ [UartIsr()] → [Read character from FIFO]                 │   │
│  │                                                         │   │
│  │ [UartReadCb()] → [Deliver to TTY layer]                 │   │
│  │                                                         │   │
│  │ [Wake waiting read task]                                │   │
│  └───────────────────────────────────────────────────────────┘   │
│                                                                  │
└─────────────────────────────────────────────────────────────────┘
```

**关键代码路径**:

| 阶段 | 文件 | 函数 | 说明 |
|------|------|------|------|
| **TX** | `uart_pl011.c` | `UartWrite()` | 写 TX FIFO |
| **TX 中断** | `uart.c` | `UartTxInt()` | TX 完成中断 |
| **RX 中断** | `uart.c` | `UartRxInt()` | RX 到达中断 |
| **ISR** | `uart.c` | `UartIsr()` | 中断入口 |

**证据位置**:
- `drivers/uart/BUILD.gn:27-33` (源文件列表)
- `drivers/uart/uart.c` (UART 核心)
- `drivers/uart/uart_pl011.c` (PL011 实现)
