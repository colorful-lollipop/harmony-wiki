# 架构说明

## 文档信息

- **目的**: 说明 Rockchip OpenHarmony 仓库的系统架构、组件关系和数据流
- **适用范围**: 所有芯片平台
- **关键结论**: 采用分层架构，通过 HDI/VDI 接口实现硬件抽象

## 数据流

### 显示数据流

```mermaid
sequenceDiagram
    participant App as 应用
    participant FW as 框架层
    participant HDI as Display HDI
    participant VDI as Rockchip VDI
    participant DRM as DRM Driver
    participant HW as 显示硬件

    App->>FW: 请求显示缓冲区
    FW->>HDI: AllocateBuffer()
    HDI->>VDI: CreateDisplayBufferVdi()
    VDI->>DRM: drm_alloc_buffer()
    DRM->>HW: 分配物理内存
    HW-->>DRM: Buffer Handle
    DRM-->>VDI: Buffer FD
    VDI-->>HDI: Buffer Handle
    HDI-->>FW: Buffer
    FW-->>App: Buffer

    App->>FW: 提交显示帧
    FW->>HDI: SetLayerBuffer()
    HDI->>VDI: 调用 VDI 接口
    VDI->>DRM: drmModeAtomicCommit()
    DRM->>HW: 显示帧
```

### 视频编解码数据流

```mermaid
sequenceDiagram
    participant App as 多媒体应用
    participant FW as 框架层
    participant HDI as Codec HDI
    participant VDI as MPP VDI
    participant MPP as MPP Library
    participant DRV as MPP Driver
    participant HW as VPU 硬件

    App->>FW: 创建编解码器
    FW->>HDI: CreateComponent()
    HDI->>VDI: hdiMppCreate()
    VDI->>MPP: mpp_create()
    MPP->>DRV: ioctl(MPP_CREATE)
    DRV->>HW: 初始化 VPU

    App->>FW: 发送数据包
    FW->>HDI: EmptyThisBuffer()
    HDI->>VDI: hdiMppDecode()
    VDI->>MPP: mpp_task_submit()
    MPP->>DRV: ioctl(MPP_TASK)
    DRV->>HW: 硬件解码

    HW-->>DRV: 解码完成中断
    DRV-->>MPP: 返回结果
    MPP-->>VDI: 回调通知
    VDI-->>HDI: FillThisBuffer()
    HDI-->>FW: 返回解码帧
    FW-->>App: 显示帧
```

## 关键时序

### 显示初始化时序

```mermaid
sequenceDiagram
    participant S as System
    participant VDI as VDI Impl
    participant HS as HdiSession
    participant HD as HdiDisplay
    participant DRM as DRM Driver

    S->>VDI: CreateComposerVdi()
    VDI->>HS: HdiSession::GetInstance()
    HS->>DRM: drmOpen()
    DRM-->>HS: drmFd
    HS->>DRM: drmModeGetResources()
    DRM-->>HS: connector/crtc/plane 列表
    
    loop 每个 Connector
        HS->>HD: new HdiDisplay()
        HD->>HD: 创建 HdiComposer
        HD->>HD: 创建 HdiLayer
    end
    
    HS-->>VDI: 初始化完成
    VDI-->>S: 返回 VDI 实例
```

### 热插拔检测时序

```mermaid
sequenceDiagram
    participant NL as Netlink Monitor
    participant HS as HdiSession
    participant CB as HotPlugCallback
    participant App as 应用层

    NL->>NL: 监听 uevent
    NL->>NL: 检测到 HDMI 插拔
    NL->>HS: 通知显示变化
    HS->>HS: 更新显示状态
    HS->>CB: 调用热插拔回调
    CB->>App: 通知显示事件
    App->>App: 调整显示配置
```
