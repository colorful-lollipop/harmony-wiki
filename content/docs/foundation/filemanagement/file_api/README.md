# OpenHarmony File API Wiki

## 1. 简介

本文档是 OpenHarmony **filemanagement_file_api** 仓库的工程 Wiki，提供从代码级视角的完整项目理解。File API 是 OpenHarmony 文件管理子系统的核心 N-API 封装层，为应用提供文件 I/O、目录管理、文件系统状态查询等能力。

### 1.1 核心价值

| 价值维度 | 描述 |
|----------|------|
| **能力抽象** | 将底层系统调用封装为易用的 JS API |
| **安全隔离** | 基于 URI 的沙箱机制确保应用只能访问授权文件 |
| **多语言支持** | 提供 JS、C、CJ、Rust、Native 五种编程接口 |
| **高性能** | 支持异步 I/O（hyperaio）和优化读取 |
