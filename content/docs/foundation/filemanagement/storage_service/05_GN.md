# GN 构建文档

> 本文档描述 storage_service 的 GN 构建配置，包括关键 targets、构建选项和依赖关系。

## 构建入口

### 根构建配置

| 文件 | 说明 |
|------|------|
| `bundle.json` | 组件配置，声明 features、deps |
| `storage_service_aafwk.gni` | 特性条件编译配置 |
| `.gitee/` | 构件配置 |

**证据来源**：`bundle.json`、`storage_service_aafwk.gni`

### 关键 BUILD.gn 文件

| 路径 | 说明 |

```gn
// 用户加密管理
if (user_crypto_manager || user_crypto_migrate_key) {
  defines += [ "USER_CRYPTO_MANAGER" ]
  deps += [ "crypto:libsdcrypto" ]
  external_deps += [ "huks:hukssdk" ]
}

// 用户文件共享
if (user_file_sharing) {
  defines += [ "USER_FILE_SHARING" ]
}

// 外部存储管理
if (external_storage_manager) {
  defines += [ "EXTERNAL_STORAGE_MANAGER" ]
  deps += [ "disk", "volume", "netlink" ]
}

// DFS 服务
if (dfs_service) {
  defines += [ "DFS_SERVICE" ]
  external_deps += [ "dfs_service:distributed_file_daemon_kit_inner" ]
}

// MTP 设备
if (support_open_source_mtp_device) {
  defines += [ "SUPPORT_OPEN_SOURCE_MTP_DEVICE" ]
}

// SELinux
if (use_librestocon) {
  defines += [ "USE_LIBRESTORECON" ]
}

// 屏幕锁管理
if (enable_screenlock_manager) {
  defines += [ "ENABLE_SCREENLOCK_MANAGER" ]
}
```
