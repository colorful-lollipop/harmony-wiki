2. **架构变更**: 更新 `02_架构说明.md`，包括组件图和数据流
3. **构建变更**: 更新 `05_GN构建系统.md`，包括 Targets 和 Feature Flags
4. **安全变更**: 更新 `06_安全风险评审.md`，添加新发现的风险点
