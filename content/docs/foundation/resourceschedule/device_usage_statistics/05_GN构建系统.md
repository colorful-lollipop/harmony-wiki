# GN 构建系统

## 目的

本文档描述 device_usage_statistics 组件的 GN 构建系统，包括 Targets 列表、依赖关系、编译产物和 Feature Flags。

## 适用范围

- BUILD.gn 和 .gni 文件（不包含 test/ 目录）
- 所有编译 Targets 及其依赖
- Feature Flags 和条件编译选项

## Feature Flags

### GNI 中定义的变量

| 变量名 | 默认值 | 说明 |
|--------|--------|------|
| `device_usage_statistics_part_name` | `"device_usage_statistics"` | 部件名称 |

### 条件编译宏（C++）

| 宏定义 | 触发条件 | 影响代码 |
|--------|----------|----------|
| `OS_ACCOUNT_PART_ENABLED` | `os_account_part_enabled == true` | 添加 `os_account:os_account_innerkits` 依赖 |
| `BGTASKMGR_ENABLE` | `bgtaskmgr_enable == true` | 添加 `background_task_mgr:bgtaskmgr_innerkits` 依赖 |
| `DEVICE_USAGES_STATISTICS_POWERMANGER_ENABLE` | `device_usage_statistics_with_powermgr_power_manager_enable == true` | 添加 `power_manager:powermgr_client` 依赖 |
| `DEVICE_USAGE_UNIT_TEST` | `usagestatservice_static`, `usagestatsinner_static` | 单元测试模式编译 |
| `DEVICE_USAGES_STATISTICS_TEST_ENABLE` | `use_libfuzzer == true` | Fuzz 测试模式 |

- BUILD.gn:283-296: 条件编译定义
