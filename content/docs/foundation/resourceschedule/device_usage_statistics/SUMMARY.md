# Device Usage Statistics Wiki - 导航

本文档库提供 device_usage_statistics 组件的完整工程文档，帮助开发者快速理解项目架构、API 接口、构建系统和安全机制。

## 双路线阅读导航

### 路线一：新人学习路线

**目标**: 快速理解项目是什么、能做什么、怎么用、架构如何组织

**推荐顺序**:

1. **[00_项目概览.md](00_项目概览.md)** ⭐ - 5分钟了解项目定位、边界、核心能力
2. **[01_目录结构与模块职责.md](01_目录结构与模块职责.md)** ⭐ - 10分钟理解代码组织和模块划分
3. **[02_架构说明.md](02_架构说明.md)** ⭐ - 20分钟深入了解组件架构、数据流和线程模型
4. **[03_N-API接口文档.md](03_N-API接口文档.md)** - 30分钟学习对外 JS API 使用
5. **[05_GN构建系统.md](05_GN构建系统.md)** - 15分钟掌握构建系统和编译产物
6. **[04_内部API与模块接口.md](04_内部API与模块接口.md)** - 可选，了解内部模块接口
7. **[07_常见问题FAQ.md](07_常见问题FAQ.md)** - 查阅构建、运行、调试问题

**预计总时间**: 约 1.5 小时

---

### 路线二：安全研究路线

**目标**: 快速识别攻击面、信任边界、潜在漏洞点和利用路径

**推荐顺序**:

1. **[00_项目概览.md](00_项目概览.md)** - 快速浏览项目定位和对外暴露面（重点看「运行环境」和「组件边界」）
2. **[06_安全风险评审.md](06_安全风险评审.md)** ⭐⭐⭐ - **核心文档**，包含：
   - 攻击面分析（外部输入清单、敏感操作清单）
   - 8个已识别的安全风险点（含代码路径）
   - 信任边界图
3. **[02_架构说明.md](02_架构说明.md)** - 查看数据流图，识别信任边界跨越点
4. **[04_内部API与模块接口.md](04_内部API与模块接口.md)** - 检查内部接口权限控制
5. **[03_N-API接口文档.md](03_N-API接口文档.md)** - 检查 JS API 参数校验
6. **[01_目录结构与模块职责.md](01_目录结构与模块职责.md)** - 定位关键代码文件

**预计总时间**: 约 2 小时
