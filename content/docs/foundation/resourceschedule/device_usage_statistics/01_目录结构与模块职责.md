## 模块职责说明

### 1. frameworks/ - N-API 层

**职责**: 实现 JavaScript/C++ 接口绑定，对外提供 N-API

**子模块**:

| 子模块 | 文件 | 职责 |
|--------|------|------|
| 主模块注册 | usage_statistics_init.cpp | 注册新版 NAPI 模块（16个方法） |
| 旧版模块注册 | bundle_state_init.cpp | 注册旧版 NAPI 模块（6个方法） |
| 查询 API | bundle_state_query_napi.cpp | 实现查询类 API（queryBundleEvents 等） |
| 旧版查询 API | bundle_state_query.cpp | 实现旧版查询 API（兼容接口） |
| 分组 API | bundle_active_app_group_napi.cpp | 实现应用分组 API |
| 观察者 API | app_group_observer_napi.cpp | 实现分组变更观察者 |
| 通用工具 | bundle_state_common.cpp | 提供 Promise/Callback 处理、错误处理 |

**关键证据**:
- frameworks/src/usage_statistics_init.cpp:33-62: 导出 16 个 JS 方法
- frameworks/src/bundle_state_init.cpp:46-50: 导出 6 个旧版 JS 方法

## 模块依赖关系

### 依赖方向

```
N-API 层 (frameworks/)
    ↓
内部接口层 (interfaces/innerkits/)
    ↓
服务层 (services/)
    ├── common/ (核心逻辑、数据库、事件上报)
    ├── packagegroup/ (应用分组)
    └── packageusage/ (使用统计)
    ↓
工具库 (utils/)
```

### 跨层依赖

**N-API 层依赖**:
- interfaces/innerkits/ - BundleActiveClient
- services/common/ - 数据结构

**内部接口层依赖**:
- IDL 生成的 IPC 代码
- services/common/ - 数据结构

**服务层依赖**:
- utils/ - 日志和工具
- 外部组件 - safwk, ipc, relational_store, ability_runtime 等
