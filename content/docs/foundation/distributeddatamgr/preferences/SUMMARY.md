## 完整文档列表

### 核心文档

#### 1. [概览](./00_Overview.md)

**内容**：
- 模块定位与核心能力
- 运行环境与约束
- 与其他模块的关系
- 快速开始示例

**适合**：所有需要了解模块概况的开发者

#### 2. [架构设计](./01_Architecture.md)

**内容**：
- 系统架构图
- 组件职责说明
- 数据流向
- 线程模型
- 时序图

**适合**：需要理解内部实现的开发者

#### 3. [API 参考](./02_API_Reference.md)

**内容**：
- JS API 完整清单（含参数、返回值）
- NDK API 完整清单
- Inner API（C++）完整清单
- 错误码汇总

**适合**：需要使用 API 进行开发的开发者

#### 4. [构建配置](./03_Build.md)

**内容**：
- GN Targets 列表
- 编译产物说明
- 依赖关系
- 平台差异

**适合**：需要编译模块或理解构建流程的开发者

#### 5. [安全评审](./04_Security_Review.md)

**内容**：
- 攻击面分析
- 信任边界
- 风险清单
- 修复建议

**适合**：安全审计和架构评审

#### 6. [故障排查](./05_Troubleshooting.md)

**内容**：
- 常见问题汇总
- 错误码速查
- 调试方法
- 日志分析

**适合**：遇到问题需要定位的开发者
