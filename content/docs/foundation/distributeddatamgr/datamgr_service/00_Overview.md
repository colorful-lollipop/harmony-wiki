# 概览

**Distributed Data Service (DDS)** - OpenHarmony 分布式数据管理服务

---

## 1. 项目定位

### 1.1 核心职责

DDS 提供**跨设备数据存储与同步**能力，使应用能够在不同设备间共享和同步数据。

### 1.2 数据隔离模型

```
(user, app, database) 三元组 → 唯一确定一个数据库
```

| 维度 | 说明 |
|-----|------|
| **User** | 用户身份，跨用户数据隔离 |
| **App** | 应用标识，跨应用数据隔离 |
| **Database** | 数据库实例，逻辑数据分组 |

### 1.3 与客户端关系

> **重要**: 本仓库为**服务端实现**，客户端（JS API）在独立仓库。

```
┌──────────────────┐     IPC      ┌──────────────────────┐
│   应用进程        │ ──────────→  │  distributeddata    │
│   (JS API 调用)   │              │  (SA ID: 1301)       │
└──────────────────┘              └──────────────────────┘
```

**客户端仓库**:
- `distributeddatamgr_kv_store` - KV 数据库 JS API
- `distributeddatamgr_relational_store` - 关系数据库 JS API
- 其他数据管理组件

---

## 2. 核心能力

### 2.1 五种核心能力

| 能力 | 说明 | 对应模块 |
|-----|------|---------|
| **KV/RDB 跨设备同步** | 自动数据同步和一致性保证 | `kvdb`, `rdb` |
| **分布式对象持久化** | 完整生命周期管理 | `object` |
| **跨应用数据静默共享** | 无需启动提供方进程 | `data_share` |
| **设备-云同步** | 数据库数据同步到云端 | `cloud` |
| **UDMF 统一数据管理** | 系统级数据标准 | `udmf`, `utd` |

### 2.2 支持的数据模型

| 类型 | 限制 | 说明 |
|-----|------|-----|
| **KV (键值)** | Key ≤ 1KB, Value ≤ 4MB | 单 KV store |
| **KV (设备)** | Key ≤ 896B, Value ≤ 4MB | 设备隔离 |
| **RDB (关系)** | SQLite 扩展 | 支持谓词查询 |

### 2.3 性能约束

| API | 限制 |
|-----|------|
| KvStore | 1000 次/秒, 10000 次/分钟 |
| KvManager | 50 次/秒, 500 次/分钟 |
| 数据库数量 | 每应用最多 16 个 |

---

## 3. 关键概念

### 3.1 一致性模型

DDS 仅支持**最终一致性**，不支持强一致性。

| 类型 | 说明 |
|-----|------|
| **强一致性** | 立即同步到所有设备（不支持） |
| **最终一致性** | 设备上线或数据变更时同步 |

**原因**: 移动设备不总是在线，无中心节点。

### 3.2 同步模式

| 模式 | 说明 |
|-----|------|
| **PULL** | 从远程设备拉取数据 |
| **PUSH** | 向远程设备推送数据 |
| **PULL_PUSH** | 先拉取再推送 |
| **自动同步** | 设备上线或数据变更时自动触发 |

### 3.3 冲突解决

- **策略**: 后提交的修改生效
- **限制**: 不支持自定义冲突解决策略

## 4. 系统集成

### 4.1 依赖的系统服务

| 服务 | 用途 |
|-----|------|
| **SAMGR** | SystemAbility 管理 |
| **IPC** | 进程间通信 |
| **SoftBus** | 设备间通信 |
| **DeviceManager** | 设备管理 |
| **Account** | 用户账户 |
| **DFX/Hiview** | 性能监控 |
| **Huks** | 密钥管理 |

### 4.2 权限要求

| 权限 | 用途 | 必选 |
|-----|------|-----|
| `ohos.permission.DISTRIBUTED_DATASYNC` | 分布式数据同步 | 是 |
| `ohos.permission.CLOUDDATA_CONFIG` | 云数据配置 | 云功能 |
