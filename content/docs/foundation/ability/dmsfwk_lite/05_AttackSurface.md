# 攻击面分析

> dmsfwk_lite 分布式调度模块的攻击面识别与信任边界分析，为安全研究员提供攻击入口清单。

## 一、攻击面概览

dmsfwk_lite 作为跨设备通信的系统服务，暴露了多个外部输入点。攻击者可通过这些入口尝试利用系统漏洞。

## 二、外部输入清单

### 2.1 IPC 接口输入（高风险）

| 输入类型 | 输入源 | 输入格式 | 处理位置 | 风险等级 |
|---------|-------|---------|---------|---------|
| **StartRemoteAbility 调用** | 上层应用/框架 | Want + CallerInfo | `source/dmslite_famgr.c:85` | 高 |
| **SAMgr 消息** | SAMgr 服务 | Request 结构 | `source/dmslite_feature.c:73` | 中 |
| **Feature 初始化** | SAMgr 服务 | Feature 结构 | `source/dmslite_feature.c:59` | 低 |

**详细分析**：

#### 输入点 1：StartRemoteAbility 参数

| 字段 | 类型 | 说明 | 验证方式 |
|-----|------|------|---------|
| `want` | `Want*` | 启动意图结构 | 空指针检查 |
| `want->element` | `ElementName*` | 目标设备与应用信息 | 空指针检查 |
| `want->element->deviceId` | `char*` | 设备标识符 | 后续 DSoftBus 处理 |
| `want->element->bundleName` | `char*` | 包名 | 无长度校验 |
| `want->element->abilityName` | `char*` | Ability 名 | 无长度校验 |
| `want->data` | `void*` | 携带数据 | 最大长度校验 |
| `want->dataLength` | `int32_t` | 数据长度 | 最大值 1024 |
| `callerInfo` | `CallerInfo*` | 调用者信息 | 空指针检查 |
| `callerInfo->uid` | `int32_t` | 用户 ID | 无校验 |
| `callerInfo->bundleName` | `char*` | 包名 | 无长度校验 |

**证据来源**：`source/dmslite_famgr.c:88-90`

```cpp
if (want == NULL || want->element == NULL || callerInfo == NULL) {
    return DMS_EC_INVALID_PARAMETER;
}
```

### 2.3 TLV 消息解析输入（高风险）

| 输入类型 | 输入源 | 输入格式 | 处理位置 | 风险等级 |
|---------|-------|---------|---------|---------|

| **数值字段** | TLV 消息 | 变长整数 | `source/dmslite_parser.c:49-78` | 中 |

**详细分析**：

#### 输入点 3：TlvBytesToNode 解析

| 风险项 | 说明 | 代码证据 |
|-------|------|---------|
| **节点类型溢出** | 节点类型字段为 `uint8_t`，值可能超出预期范围 | `include/dmslite_tlv_common.h:33` |
| **长度字段过大** | 长度字段可能超过缓冲区限制 | `source/dmslite_parser.c:69-72` |

## 五、边界跨越点详解

### 边界跨越点 1：StartRemoteAbility IPC 调用

| 属性 | 说明 |
|------|------|
| **跨越方向** | 应用层 → dmsfwk_lite 服务 |
| **输入数据** | Want、CallerInfo |
| **验证机制** | 空指针检查 |
| **信任假设** | 调用者身份已由框架验证 |

**攻击向量**：
1. 构造畸形 Want 结构触发空指针解引用
2. 传递超长字符串导致缓冲区问题
3. 利用 CallerInfo 伪造身份

---

### 边界跨越点 2：TLV 消息解析

| 属性 | 说明 |
|------|------|
| **跨越方向** | DSoftBus → dmsfwk_lite 解析模块 |
| **输入数据** | TLV 字节流 |
| **验证机制** | 类型检查、长度校验、顺序检查 |
| **信任假设** | DSoftBus 已完成设备认证 |

**攻击向量**：
1. 构造畸形 TLV 消息触发解析错误
2. 发送超大长度字段触发整数溢出
3. 发送乱序节点绕过顺序检查

---

### 边界跨越点 3：下游服务调用

| 属性 | 说明 |
|------|------|
| **跨越方向** | dmsfwk_lite → 下游系统服务 |
| **调用数据** | BundleName、AbilityName |
| **验证机制** | 签名校验 |
| **信任假设** | 下游服务已验证调用者权限 |

**攻击向量**：
1. 利用已验证身份调用敏感服务
2. 启动未授权的 Ability
3. 读取敏感应用信息

## 六、风险等级评估

| 输入点 | 风险类型 | 利用难度 | 影响范围 | 风险等级 |
|-------|---------|---------|---------|---------|
| StartRemoteAbility | 参数注入 | 低 | 远程代码执行 | **高** |
| TLV 解析 | 整数溢出 | 中 | 内存破坏 | **高** |
| TLV 解析 | 拒绝服务 | 低 | 服务不可用 | **中** |
| 文件读取 | 路径遍历 | 高 | 信息泄露 | **中** |
| DSoftBus 消息 | 中间人 | 高 | 身份伪造 | **低** |
