## IPC 通信机制

### 架构说明

## 线程模型

### 主线程（Main Thread）

- **UI 主线程**：运行 Ability 的 UI 逻辑，处理用户交互
- **AMS 主线程**：运行 AbilityManagerService 的事件处理

### 线程池（Thread Pool）

- **IPC 处理线程**：处理跨进程通信请求
- **业务处理线程**：处理耗时的 Ability 操作

### 生命周期线程

```
┌─────────────────────────────────────────────────────────────────┐
│                        UI 线程                                   │
│  • Ability.onCreate()                                           │
│  • Ability.onForeground()                                       │
│  • Ability.onBackground()                                       │
│  • Ability.onDestroy()                                          │
│  • UI 渲染和用户交互事件处理                                      │
└─────────────────────────────────────────────────────────────────┘
                              │
                              │ 生命周期状态转换
                              ▼
┌─────────────────────────────────────────────────────────────────┐
│                      AMS 主线程                                  │
│  • 接收 IPC 请求（StartAbility, ConnectAbility 等）             │
│  • 调度生命周期状态转换                                          │
│  • 管理 Ability 记录（AbilityRecord）                            │
└─────────────────────────────────────────────────────────────────┘
                              │
                              │ IPC 通信
                              ▼
┌─────────────────────────────────────────────────────────────────┐
│                      Binder 线程池                               │
│  • 接收来自客户端的 IPC 调用                                      │
│  • 将请求分发到 AMS 主线程处理                                    │
└─────────────────────────────────────────────────────────────────┘
```
