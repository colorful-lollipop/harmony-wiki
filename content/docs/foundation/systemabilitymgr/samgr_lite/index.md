# samgr_lite 概览

## 项目定位

**samgr_lite** 是 OpenHarmony 系统中提供轻量级服务导向架构（SOA）开发框架的核心组件。

### 核心能力

| 能力 | 描述 | 支持平台 |
|------|------|----------|
| **服务注册与发现** | 管理服务的注册、注销和查询 | M-core / A-core |
| **进程内通信 (IPC)** | 同一进程内服务间消息传递 | M-core / A-core |
| **跨进程通信 (RPC)** | 不同进程间服务调用 | A-core (可选 M-core) |
| **事件广播** | 发布/订阅模式的事件通知 | M-core / A-core |
| **系统能力管理** | 系统能力 (System Capability) 的注册与查询 | M-core / A-core |

### 硬件平台支持

```
┌─────────────────────────────────────────────────────────┐
│                    samgr_lite                            │
├─────────────────────┬───────────────────────────────────┤
│      M-core         │              A-core              │

```

## 核心概念

### 服务 (Service)
- 系统的基本功能单元
- 拥有独立的生命周期
- 可以包含多个 Feature（子功能）

### Feature（功能）
- Service 的子功能模块
- 可以独立发布 API
- 共享 Service 的线程资源

### IUnknown（接口基类）
- 所有对外 API 的基础接口
- 支持 QueryInterface 接口查询
- 支持 AddRef/Release 引用计数

### Identity（身份标识）
- 唯一标识 Service 或 Feature
- 包含 serviceId、featureId、queueId
- 用于消息路由

## 快速开始

### 包含头文件

```c
#include "samgr_lite.h"      // Samgr 核心 API
#include "iunknown.h"        // 接口基类
#include "service.h"         // 服务定义
#include "feature.h"         // 功能定义
#include "message.h"         // 消息通信
```

### 初始化（不同平台）

**M-core**:
```c
OHOS_SystemInit();  // 在系统启动时调用
```

**A-core**:
```c
SAMGR_Bootstrap();  // 在 main 函数中调用
```
