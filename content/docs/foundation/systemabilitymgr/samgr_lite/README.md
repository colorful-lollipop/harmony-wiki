# samgr_lite Wiki

## 概述

本文档是 **samgr_lite**（轻量型系统服务管理部件）的工程 Wiki，旨在帮助开发者快速理解项目架构、API 使用、构建配置以及安全考量。

**samgr_lite** 是 OpenHarmony 系统服务管理子系统中的轻量级组件，为资源受限设备提供统一的服务导向架构（SOA）开发框架。

## 覆盖范围

本文档涵盖以下内容：

| 分类 | 内容 |
|------|------|
| **项目概览** | 定位、边界、核心能力、运行环境 |
| **目录结构** | 模块职责、代码组织方式 |
| **架构说明** | 组件图、数据流、线程模型、关键时序 |
| **对外 API** | N-API 接口清单、参数、返回值、调用示例 |
| **内部架构** | 模块接口、依赖方向、生命周期 |
| **构建配置** | GN targets、编译产物、运行时加载关系 |
| **安全评审** | 攻击面、信任边界、风险点与修复建议 |
| **常见问题** | 构建/运行/调试问题定位 |

## 未覆盖范围

- 测试代码相关文档（test/、tests/ 等目录）

- 具体业务服务的实现示例（参见 README.md 中的开发指南）
- 其他 OpenHarmony 子系统的文档
