# 项目概览

本文档概述划词服务子系统的项目定位、核心能力、运行环境约束以及关键概念说明。

## 1. 项目定位

### 1.1 系统定位

划词服务子系统是 OpenHarmony 基础服务层的重要组成部分，属于 `foundation/systemabilitymgr` 子系统。该子系统为应用开发者提供全局文本选择能力，使应用能够：

- 在全局范围内捕获用户选中的文本内容
- 基于捕获的文本实现业务逻辑（翻译、摘要、智能扩写等）
- 创建和管理划词面板，灵活呈现处理结果

**证据来源**: `README.md:1-10`

```
/foundation/systemabilitymgr/
└── selectionfwk/           # 划词服务子系统
    ├── common/             # 公共代码
    ├── frameworks/        # 接口实现
    ├── service/           # 核心服务
    ├── interfaces/        # 接口定义
    └── ...
```

### 1.2 能力边界

| 能力 | 描述 | 限制 |
|-----|------|------|
| 文本捕获 | 全局获取用户选中文本 | 仅支持纯文本，最大 6000 字节 |
| 面板管理 | 创建、显示、移动、隐藏面板 | 支持自定义 UI |
| 事件监听 | 监听划词完成事件 | 需先订阅 |
| 应用切换 | 划词应用切换 | 支持用户配置 |

**证据来源**: `README.md:40-48`

## 2. 核心能力

### 2.1 三大核心模块

```
┌─────────────────────────────────────────────────────────────────┐
│                      划词服务子系统                              │
├─────────────────┬─────────────────┬─────────────────────────────┤
│  划词内容管理    │  划词事件处理   │     划词配置管理              │
├─────────────────┼─────────────────┼─────────────────────────────┤
│ • 剪贴板数据获取 │ • 多模输入监听  | • 划词触发方式配置           │
│ • 纯文本校验     │ • 键鼠事件处理  | • 划词应用切换配置           │
│ • 空白字符过滤   │ • 状态机流转    | • 划词服务开关配置           │
│ • 内容长度限制   │ • 双击/三击识别 | • 用户级配置持久化           │
└─────────────────┴─────────────────┴─────────────────────────────┘
```

**证据来源**: `README.md:11-15` + `figures/selectionfwk-architecture.png`

### 2.2 划词内容管理

**职责**: 校验并过滤用户划词内容

| 功能 | 描述 |
|-----|------|
| 剪贴板获取 | 从 Pasteboard 服务获取选中文本 |
| 纯文本校验 | 确保内容为纯文本类型 |
| 空白过滤 | 过滤划词内容中的空白字符 |
| 长度限制 | 最大支持 6000 字节 |

### 2.3 划词事件处理

**职责**: 处理多模输入事件，识别划词操作

| 事件类型 | 识别逻辑 |
|---------|---------|
| 双击 | 快速连续两次点击 |
| 三击 | 快速连续三次点击 |
| 单击滑动 | 点击并拖动 |

**证据来源**: `service/src/selection_input_monitor.cpp`

### 2.4 划词配置管理

**职责**: 管理划词服务的配置项

| 配置项 | 存储方式 | 用途 |
|-------|---------|------|
| 划词开关 | 系统参数 (sys.selection.switch) | 全局开关 |
| 划词应用 | Relational Store | 当前划词应用 |
| 触发方式 | 数据库 | 双击/三击配置 |

**证据来源**: `sa_profile/8500.json` + `service/src/*_config_repository.cpp`

## 3. 运行环境

### 3.1 支持设备

| 设备类型 | 支持状态 | 说明 |
|---------|---------|------|
| PC | ✅ 支持 | 外接键盘和鼠标的设备 |
| 2in1 | ✅ 支持 | 支持键盘鼠标的 2 合 1 设备 |

## 4. 约束与限制

### 4.1 功能约束

| 约束项 | 说明 |
|-------|------|
| 文本类型 | 仅支持获取文本类型内容 |
| 长度限制 | 最大 6000 字节 |
| 屏幕范围 | 支持在扩展屏上使用 |
| 跨设备 | 不支持跨设备使用 |

**证据来源**: `README.md:44-46`

### 4.2 应用兼容性

**注意**: 对于不支持复制或只能在当前应用内复制粘贴的被划词应用，划词功能会失效。

**建议**: 开发者在开发划词应用时配置相应的黑名单或白名单。

**证据来源**: `README.md:48`

### 4.3 安全约束

| 约束 | 说明 |
|-----|------|
| 权限要求 | 需要使用系统能力 SystemCapability.SelectionInput.Selection |
| 应用签名 | 划词应用需通过系统签名校验 |
| 进程隔离 | 划词服务运行在独立进程 (selection_service) |

## 5. 关键概念

### 5.1 划词扩展 (Selection Extension)

划词扩展是实现划词功能的应用扩展，基于 `SelectionExtensionAbility` 框架开发。

| 概念 | 说明 |
|-----|------|
| SelectionExtensionAbility | 划词扩展的基类 |
| SelectionExtensionContext | 划词扩展的上下文环境 |
| SelectionManager | 划词管理器，提供核心 API |

### 5.2 划词面板 (Selection Panel)

划词面板是呈现划词处理结果的 UI 组件。

| 概念 | 说明 |
|-----|------|
| Panel | 面板对象 |
| PanelInfo | 面板配置信息 |
| PanelType | 面板类型 (ABC/CUSTOM) |

### 5.3 选中文本信息 (SelectionInfo)

描述用户划词区域和内容的信息。

| 字段 | 说明 |
|-----|------|
| selectionType | 选择类型 |
| startDisplayX/Y | 选中区域起始屏幕坐标 |
| endDisplayX/Y | 选中区域结束屏幕坐标 |
| windowId | 窗口 ID |
| bundleName | 应用 Bundle 名称 |

**证据来源**: `common/selection_data_inner.h:29-117`

### 5.4 系统能力 (SA)

划词服务以系统能力 (System Ability) 形式运行。

| 属性 | 值 |
|-----|------|
| SA ID | 8500 |
| 进程名 | selection_service |
| 启动模式 | 懒加载 (run-on-create: false) |
| 自动重启 | 支持 (auto-restart: true) |

**证据来源**: `sa_profile/8500.json`
