# safwk_lite Wiki 文档

## 文档概述

本文档是 OpenHarmony **Lite System Ability Framework (safwk_lite)** 组件的工程 Wiki，旨在帮助开发者快速理解项目定位、架构设计、编译构建及安全考量。

## 覆盖范围

| 章节 | 内容 |
|------|------|
| 项目定位 | 系统能力框架的核心职责与定位 |
| 目录结构 | 源码目录组织与模块职责 |
| 架构设计 | 进程模型、Samgr 集成、时序流程 |
| GN 构建 | BUILD.gn targets、编译产物、依赖关系 |
| 安全评审 | 攻击面分析、信任边界、风险点识别 |
| 故障排查 | 常见构建/运行问题与定位路径 |

## 不覆盖范围

- 测试相关内容（test/, unittest/, *_test.* 等）
- N-API 暴露（此项目为纯 C 框架，无 JS API）
- 其他子系统的内部实现细节

## 维护方式

本文档随代码变更同步更新。建议在修改以下内容时同步更新 Wiki：

1. 修改 `BUILD.gn` 或构建配置
2. 修改 `src/main.c` 入口逻辑
3. 新增 feature 开关
4. 新增依赖组件
