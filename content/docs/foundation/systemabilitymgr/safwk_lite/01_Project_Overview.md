# 项目概览

## 项目定位

**safwk_lite** (Lite System Ability Framework) 是 OpenHarmony 系统能力框架的轻量级实现版本，主要服务于 **小型设备 (small system)**。

### 核心职责

1. **提供基础进程模板**：为系统服务提供统一的进程入口
2. **服务注册与发布**：通过 Samgr 管理并发布系统能力
3. **进程生命周期管理**：维持服务进程持续运行

### 适用场景

| 系统类型 | 内核 | 典型设备 |
|---------|------|---------|
| 小型设备 | LiteOS-A / Linux | 智能家居、IoT 设备 |

### 核心能力

- 轻量级服务进程框架
- Samgr 集成
- 条件化编译（feature flags）

## 与其他组件的关系

```
用户态应用
    ↓ IPC 调用
系统能力 (SA) Provider
    ↓ 通过 Samgr 发布
┌─────────────────────────────────┐
│      safwk_lite (foundation)    │  ← 服务进程容器
│  ┌───────────────────────────┐  │
│  │ abilityms (能力管理)      │  │
│  │ bundlems (包管理)         │  │
│  │ dtbschedmgr (分布式调度)   │  │
│  │ ...                       │  │
│  └───────────────────────────┘  │
└─────────────────────────────────┘
    ↑ Samgr Lite
系统能力管理框架 (samgr_lite)
```

## 关键特性

| 特性 | 说明 |
|------|------|
| 进程隔离 | 每个系统能力运行在独立进程中 |
| 延迟加载 | 按需启动系统能力 |
| 统一入口 | 弱符号 `OHOS_SystemInit()` 机制 |
