# 00_Overview - Cast+ Stream 项目概览

> 本文档提供 Cast+ Stream 模块的整体概览，包括核心概念、运行环境和关键术语。

---

## 1. 项目简介

**Cast+ Stream** 是 OpenHarmony CastEngine 的核心子模块，负责实现媒体资源的投射到对端设备，并支持双端的播控。

### 1.1 功能定位

| 功能 | 说明 |
|------|------|
| **镜像投屏 (Mirror Cast)** | 将设备屏幕实时投射到对端设备显示 |
| **流媒体投屏 (Stream Cast)** | 将本地或在线媒体文件投射到对端播放 |
| **双端播控** | 支持源端和接收端双向控制播放状态 |
| **多协议支持** | RTSP 协议用于会话控制，SoftBus/TCP 用于数据传输 |

### 1.2 技术特点

- **纯原生实现**: C++ 静态库，无 N-API 层
- **IPC 通信**: 基于 OpenHarmony IPC 机制（Stub/Proxy 模式）
- **状态机驱动**: 会话生命周期由状态机管理
- **加密传输**: 支持 AES-128-CTR/GCM 加密
- **多通道架构**: 独立的控制通道、音视频通道、文件通道

## 2. 核心概念

### 2.1 角色定义

```
┌─────────────────────────────────────────────────────────────┐
│                      投屏会话架构                            │
├─────────────────────────────────────────────────────────────┤
│                                                              │
│   ┌──────────────────┐         ┌──────────────────┐         │
│   │    Source        │         │      Sink        │         │
│   │   (源端)         │◄───────►│    (接收端)       │         │
│   │                  │  RTSP   │                  │         │
│   │  - 发送媒体数据   │  协议   │  - 接收媒体数据   │         │
│   │  - 控制播放状态   │         │  - 渲染显示      │         │
│   │  - 发起投屏请求   │         │  - 响应控制命令   │         │
│   └──────────────────┘         └──────────────────┘         │
│                                                              │
│   典型场景:                                                   │
│   - Source: 手机/平板 (发送方)                                │
│   - Sink: 电视/显示器 (接收方)                                │
│                                                              │
└─────────────────────────────────────────────────────────────┘
```

| 角色 | 职责 | 典型设备 |
|------|------|----------|
| **Source** | 发送媒体数据，控制播放状态，发起投屏请求 | 手机、平板、PC |
| **Sink** | 接收媒体数据，渲染显示，响应控制命令 | 电视、显示器、音箱 |

### 2.2 投屏模式

#### 镜像模式 (Mirror Cast)
```
┌─────────────────────────────────────────────────────────────┐
│                      镜像投屏模式                            │
├─────────────────────────────────────────────────────────────┤
│                                                              │
│   Source 屏幕内容 ──► 编码 ──► 网络传输 ──► 解码 ──► Sink 显示  │
│                                                              │
│   特点:                                                       │
│   - 实时传输屏幕帧                                            │
│   - 支持音频同步采集                                          │
│   - 支持反向控制（Sink 控制 Source）                          │
│   - 低延迟要求                                                │
│                                                              │
└─────────────────────────────────────────────────────────────┘
```

#### 流媒体模式 (Stream Cast)
```
┌─────────────────────────────────────────────────────────────┐
│                     流媒体投屏模式                           │
├─────────────────────────────────────────────────────────────┤
│                                                              │
│   媒体文件/URL ──► 读取 ──► 网络传输 ──► 接收 ──► Sink 播放    │
│                                                              │
│   特点:                                                       │
│   - 支持本地文件投射                                          │
│   - 支持在线媒体 URL                                          │
│   - 播放控制在 Sink 端执行                                    │
│   - 支持播放列表                                              │
│                                                              │
└─────────────────────────────────────────────────────────────┘
```

## 4. 关键术语

### 4.1 协议术语

| 术语 | 说明 |
|------|------|
| **RTSP** | Real Time Streaming Protocol，实时流协议，用于会话控制和参数协商 |
| **SoftBus** | OpenHarmony 分布式软总线，提供设备间通信能力 |
| **VTP** | Virtual Transport Protocol，虚拟传输协议，复用 TCP 实现 |
| **UIBC** | User Input Back Channel，用户输入回传通道 |

### 4.2 会话术语

| 术语 | 说明 |
|------|------|
| **Session** | 投屏会话，表示一次完整的投屏连接生命周期 |
| **Channel** | 通道，用于特定类型数据的传输（如视频、音频、控制） |
| **ModuleType** | 模块类型，标识通道用途（VIDEO/AUDIO/RTSP/CONTROL 等） |
| **EndType** | 端类型，标识是 Source 端还是 Sink 端 |

### 4.3 播放术语

| 术语 | 说明 |
|------|------|
| **Mirror** | 镜像投屏，实时传输屏幕内容 |
| **Stream** | 流媒体投屏，传输媒体文件内容 |
| **Player** | 播放器，负责媒体解码和渲染 |
| **DataSource** | 数据源，提供媒体数据读取接口 |

### 4.4 状态术语

| 术语 | 说明 |
|------|------|
| **DISCONNECTED** | 未连接状态 |
| **CONNECTING** | 连接中状态 |
| **CONNECTED** | 已连接状态 |
| **PLAYING** | 播放中状态 |
| **PAUSED** | 暂停状态 |
