### 1.2 模块职责

| 模块 | 职责 | 关键类 |
|------|------|--------|
| **CastSessionImpl** | 会话生命周期管理、状态机、设备管理 | `CastSessionImpl`, `StateMachine` |
| **ChannelManager** | 通道创建、连接管理、传输抽象 | `ChannelManager`, `Connection` |
| **RtspController** | RTSP 协议处理、参数协商 | `RtspController`, `RtspChannelManager` |
| **StreamManager** | 流媒体会话管理 | `CastStreamManagerClient`, `CastStreamManagerServer` |
| **StreamPlayer** | 播放器控制、状态同步 | `CastStreamPlayer`, `CastStreamPlayerManager` |
| **MirrorPlayer** | 镜像播放、屏幕采集 | `MirrorPlayerImpl` |
| **Utils** | 加密、状态机、消息队列 | `EncryptDecrypt`, `StateMachine`, `Handler` |

### 3.2 线程安全机制

| 组件 | 线程安全机制 | 关键锁 |
|------|-------------|--------|
| **CastSessionImpl** | 状态机串行处理 | `mutex_` |
| **ChannelManager** | 连接映射保护 | `connectionMapMutex_` |
| **Permission** | PID 列表保护 | `pidLock_` |
| **StreamPlayer** | 播放器状态保护 | `playerMutex_` |
| **LocalDataSource** | 缓存保护 | `cacheMutex_` |

### 3.3 消息队列机制

```cpp
// 消息处理流程
Message ──► Handler::SendMessage() ──► MessageQueue ──► HandlerThread ──► State::HandleMessage()
```

| 消息类型 | 处理线程 | 优先级 |
|----------|----------|--------|
| 状态转换消息 | Handler Thread | High |
| 控制命令消息 | Handler Thread | High |
| 数据接收消息 | Channel Thread | Normal |
| 定时器消息 | Handler Thread | Low |
