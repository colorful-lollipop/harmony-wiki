# 项目概览

## 什么是分布式音频

分布式音频是 OpenHarmony **分布式硬件子系统**的核心组件之一，实现多设备间音频外设的跨设备协同使用。

### 核心能力

```
┌─────────────────────────────────────────────────────────────────┐
│                      分布式音频场景                               │
├─────────────────────────────────────────────────────────────────┤
│                                                                  │
│   ┌──────────────┐                     ┌──────────────┐        │
│   │   设备 A      │                     │   设备 B      │        │
│   │   (Source)   │◄───── 音频流 ───────►│   (Sink)     │        │
│   │              │      控制指令        │              │        │
│   │  • 麦克风    │                     │  • 扬声器    │        │
│   │  • 音频数据  │                     │  • 播放音频  │        │
│   └──────────────┘                     └──────────────┘        │
│                                                                  │
│   场景 1: 设备 A 使用设备 B 的扬声器播放音频                       │
│   场景 2: 设备 A 使用设备 B 的麦克风进行录音                       │
└─────────────────────────────────────────────────────────────────┘
```

### 关键概念

| 概念 | 说明 |
|------|------|
| **Source（主控端）** | 分布式音频控制端设备，向被控端发送指令，实现在被控端设备上音频播放和录制 |
| **Sink（被控端）** | 分布式音频被控制端设备，接收指令使本地音频外设为主控端所用 |
| **分布式硬件框架** | 提供设备发现、认证、管理的底层框架 |
| **软总线** | 设备间通信的底层传输通道 |

## 核心特性

### 1. 透明使用

应用通过标准音频框架接口使用分布式音频，无需感知设备位置：

```cpp
// 应用代码示例（无需修改）
audioRenderer = AudioRenderer::Create(rendererOptions);
audioRenderer->Start();  // 自动路由到分布式扬声器
```

### 2. 动态设备管理

- **设备上线**: 组网后自动发现对端音频设备
- **设备使用**: 像使用本地设备一样使用远端设备
- **设备下线**: 断开后自动清理分布式音频资源

### 3. 音频传输

- **编码传输**: Source 端编码后发送到 Sink 端解码播放
- **控制同步**: 音量、焦点、媒体键事件实时同步
- **低延迟**: 优化的传输路径和缓冲区管理

## 接口类型

### 无 N-API 接口

**重要**: 分布式音频**不直接提供 N-API（JS/TS）接口**。

应用通过以下方式间接使用：
- **音频框架** (`@ohos.multimedia.audio`) - 推荐方式
- **分布式硬件框架** - 系统级调用

### IPC 接口（Inner API）

| 接口 | SA ID | 说明 |
|------|-------|------|
| `IDAudioSource` | 4805 | Source 端控制接口（注册/注销硬件、配置参数） |
| `IDAudioSink` | 4806 | Sink 端控制接口（订阅/取消订阅硬件） |

## 运行环境

### 系统要求

- **操作系统**: OpenHarmony 标准系统（standard）
- **组网环境**: 设备在同一局域网
- **安全要求**: 设备间建立可信关系

### 依赖组件

