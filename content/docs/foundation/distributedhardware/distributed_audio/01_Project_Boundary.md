# 项目定位与边界

## 项目定位

### 在 OpenHarmony 中的位置

```
┌─────────────────────────────────────────────────────────────────┐
│                     OpenHarmony 系统架构                         │
├─────────────────────────────────────────────────────────────────┤
│  应用层                                                          │
├─────────────────────────────────────────────────────────────────┤
│  应用框架层  │  音频框架 (audio_framework)                        │
├─────────────────────────────────────────────────────────────────┤
│  系统服务层  │  分布式硬件子系统                                  │
│             │  ├── 分布式硬件框架 (distributed_hardware_fwk)      │
│             │  ├── 分布式音频 ★ (distributed_audio)              │
│             │  ├── 分布式相机 (distributed_camera)               │
│             │  └── 分布式屏幕 (distributed_screen)               │
├─────────────────────────────────────────────────────────────────┤
│  内核层      │  HDF / 软总线 / IPC                              │
└─────────────────────────────────────────────────────────────────┘
```

### 核心职责

**本项目负责**：
1. ✅ 分布式音频设备的虚拟化抽象
2. ✅ 跨设备音频流的编码/传输/解码
3. ✅ 音频控制指令（音量、焦点、媒体键）的同步
4. ✅ 与 HDF 驱动层交互注册虚拟音频设备
5. ✅ 与分布式硬件框架集成

**本项目不负责**：
1. ❌ 应用层音频接口（由音频框架提供）
2. ❌ 设备发现和认证（由分布式硬件框架提供）
3. ❌ 底层网络传输（由软总线提供）
4. ❌ 音频驱动实现（由 HDF 驱动提供）

## 核心能力

### 1. 设备抽象能力

| 能力 | 说明 | 代码位置 |
|------|------|----------|
| 虚拟扬声器 | 将远端扬声器抽象为本地音频设备 | `services/audiomanager/managersource/include/dspeaker_dev.h` |
| 虚拟麦克风 | 将远端麦克风抽象为本地音频设备 | `services/audiomanager/managersource/include/dmic_dev.h` |
| 设备生命周期 | 管理设备的启用/禁用/释放 | `services/audiomanager/managersource/include/daudio_source_dev.h` |

### 2. 音频传输能力

| 能力 | 说明 | 代码位置 |
|------|------|----------|
| 音频编码 | 发送前对音频数据进行编码 | `services/audiotransport/senderengine/` |
| 音频解码 | 接收后对音频数据进行解码 | `services/audiotransport/receiverengine/` |
| 传输控制 | 控制通道的建立和维护 | `services/audiotransport/audioctrltransport/` |
| 抖动缓冲 | Sink 端抖动缓冲区管理 | `services/audioclient/spkclient/` |

### 3. 控制能力

| 能力 | 说明 | 代码位置 |
|------|------|----------|
| 音量同步 | 主控端调节 Sink 端音量 | `services/audiocontrol/` |
| 焦点管理 | 音频焦点的跨设备同步 | `services/audiomanager/` |
| 媒体键事件 | 播放/暂停/下一曲等事件同步 | `services/audiocontrol/` |

## 运行环境

### 硬件要求

| 资源 | 要求 | 说明 |
|------|------|------|
| ROM | 2000KB | 代码段大小 |
| RAM | 6MB | 运行时内存占用 |
| 网络 | WiFi/蓝牙 | 设备间组网必需 |

### 软件要求

```yaml
操作系统: OpenHarmony Standard System
组网要求: 
  - 设备在同一局域网
  - 设备间建立可信关系
依赖服务:
  - 分布式硬件框架 (必须)
  - 软总线 (必须)
  - 音频框架 (必须)
  - HDF 驱动 (必须)
权限要求:
  - ohos.permission.DISTRIBUTED_DATASYNC
  - ohos.permission.MICROPHONE
```

## 关键概念

### 分布式音频角色

```
┌─────────────────────────────────────────────────────────────────┐
│                        分布式音频组网                             │
├─────────────────────────────────────────────────────────────────┤
│                                                                  │
│   ┌──────────────────┐           ┌──────────────────┐          │
│   │    设备 A         │           │    设备 B         │          │
│   │  ┌────────────┐  │           │  ┌────────────┐  │          │
│   │  │ Source SA  │  │           │  │  Sink SA   │  │          │
│   │  │  (4805)    │◄─┼────IP─────┼─►│  (4806)    │  │          │
│   │  └────────────┘  │           │  └────────────┘  │          │
│   │        │         │           │        │         │          │
│   │        ▼         │           │        ▼         │          │
│   │  ┌────────────┐  │           │  ┌────────────┐  │          │
│   │  │ 虚拟扬声器  │  │           │  │ 真实扬声器  │  │          │
│   │  │ 虚拟麦克风  │  │           │  │ 真实麦克风  │  │          │
│   │  └────────────┘  │           │  └────────────┘  │          │
│   │        │         │           │        ▲         │          │
│   │        │         │           │        │         │          │
│   │   音频框架       │           │    音频框架       │          │
│   │   应用          │           │                 │          │
│   └──────────────────┘           └──────────────────┘          │
│                                                                  │
│   Source 角色: 控制端，发起音频请求                                │
│   Sink 角色: 被控端，提供音频外设                                 │
└─────────────────────────────────────────────────────────────────┘
```

### 数据流向

**播放流程（Source → Sink）**:
```
应用 → 音频框架 → 虚拟扬声器(DSpeakerDev) → 编码 → 软总线 → 解码 → 真实扬声器
```

**录音流程（Sink → Source）**:
```
真实麦克风 → 编码 → 软总线 → 解码 → 虚拟麦克风(DMicDev) → 音频框架 → 应用
```

## 接口边界

### 对外接口（北向）

| 接口 | 类型 | 说明 |
|------|------|------|
| `IDAudioSource` | IPC | 分布式硬件框架调用（注册/注销硬件） |
| `IDAudioSink` | IPC | 分布式硬件框架调用（订阅硬件变更） |
| HDF 回调 | HDI | HDF 驱动层调用（数据读写通知） |

### 对内接口（南向）

| 接口 | 类型 | 说明 |
|------|------|------|
| 音频框架 | Native | 调用 AudioRenderer/AudioCapturer |
| 软总线 | Native | 调用 AV 传输引擎 |
| HDF 服务 | HDI | 调用 IDAudioManager |
