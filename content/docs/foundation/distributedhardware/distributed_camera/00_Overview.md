# 分布式相机部件 (Distributed Camera)

## 项目概述

| 属性 | 值 |
|------|-----|
| **组件名** | distributed_camera |
| **子系统** | distributedhardware |
| **版本** | 3.1 |
| **许可证** | Apache License 2.0 |
| **语言** | C++ |
| **架构** | 双 SA (Source + Sink) |

## 核心能力

分布式相机是 OpenHarmony 分布式硬件子系统的核心部件，提供**多设备相机协同使用能力**：

- **主控端 (Source)**：控制端，使用被控端摄像头进行预览、拍照、录像
- **被控端 (Sink)**：被控制端，使用本地摄像头为主控端提供图像数据
- **跨设备传输**：通过软总线 (SoftBus) 连接主被控端
- **数据处理**：编解码、色彩空间转换、分辨率缩放、帧率调整

## 关键概念

### 主控端 (Source)
控制端，通过调用分布式相机能力，使用被控端的摄像头进行预览、拍照、录像等功能。

### 被控端 (Sink)
被控制端，通过分布式相机接收主控端的命令，使用本地摄像头为主控端提供图像数据。

### Metadata (元数据)
用于控制相机各种属性的参数集合。

## 模块组成

| 模块 | 职责 |
|------|------|
| `common/` | 公共工具：日志、事件、工具类 |
| `interfaces/inner_kits/native_cpp/camera_source/` | Source SDK (IPC 接口) |
| `interfaces/inner_kits/native_cpp/camera_sink/` | Sink SDK (IPC 接口) |
| `services/cameraservice/sourceservice/` | Source SA 服务实现 |
| `services/cameraservice/sinkservice/` | Sink SA 服务实现 |
| `services/channel/` | 软总线通道模块 |
| `services/data_process/` | 数据处理流水线 |

## 重要声明

### N-API 状态

**本仓库无 N-API 接口**，为纯 Native C++ 系统服务层组件。

应用层通过 `@ohos.distributedHardware` 上层 API 间接使用分布式相机能力，N-API 封装在 `distributed_hardware_fwk` 或其他框架组件中实现。

### 系统能力 ID

| SA | ID | 进程 | 说明 |
|----|-----|------|------|
| DistributedCameraSource | 4803 | dcamera | 源端服务，分享本地相机 |
| DistributedCameraSink | 4804 | dcamera | 被控端服务，访问远程相机 |
