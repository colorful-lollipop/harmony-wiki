## 核心组件

### 1. AccessManager (硬件接入管理)

**职责**: 监听设备上下线事件，触发硬件使能/去使能流程

**证据**: `README_zh.md:11-12`
```markdown
**硬件接入管理(AccessManager)**：硬件接入管理模块对接设备管理（DeviceManger）子系统，
用于处理设备的上下线事件响应。
```

**关键接口**:
```cpp
// 设备上线回调
void OnDeviceOnline(const DmDeviceInfo &deviceInfo);

// 设备下线回调
void OnDeviceOffline(const DmDeviceInfo &deviceInfo);
```

---

### 2. ResourceManager (硬件资源管理)

**职责**: 存储和管理设备硬件信息

**证据**: `README_zh.md:13-14`
```markdown
**硬件资源管理(ResourceManager)**：对接分布式数据服务，用于存储信任体系内，
本机和周边设备同步过来的设备硬件信息。
```

**关键能力**:
- 设备硬件信息持久化
- 跨设备信息同步
- 硬件能力查询

---

### 3. ComponentManager (部件管理)

**职责**: 管理分布式硬件部件的生命周期

**证据**: `README_zh.md:15-16`
```markdown
**分布式硬件部件管理(ComponentManager)**：对接各分布式硬件实例化的部件，
实现对分布式硬件的动态加载和使能/去使能等操作。
```

**关键接口**:
```cpp
// 使能分布式硬件
DHStatus EnableSink(const std::string &networkId, const std::string &dhId);

// 去使能分布式硬件
DHStatus DisableSink(const std::string &networkId, const std::string &dhId);
```

---

### 4. ComponentLoader (部件加载)

**职责**: 动态加载部件驱动

**证据**: `README_zh.md:19-20`
```markdown
**部件加载管理(ComponentLoader)**：用于解析部件配置文件，按需加载部件驱动的实现so，
获取驱动外部接口函数句柄以及实现版本，供其他业务使用。
```

---

### 5. VersionManager (版本管理)

**职责**: 管理版本兼容性

**证据**: `README_zh.md:21-22`
```markdown
**版本管理(VersionManager)**：用于管理超级终端内，各个设备的分布式硬件平台和
分布式硬件部件的版本号，供分布式硬件业务各个部件业务使用。
```

---

### 6. LocalHardwareManager (本地硬件管理)

**职责**: 感知本地硬件状态

**证据**: `README_zh.md:17-18`
```markdown
**本地硬件信息管理(LocalHardwareManager)**：用于采集本地硬件信息，并通过
ResourceManager进行硬件信息的持久化存储；同时，通过对接硬件驱动，
用于感知本地硬件的插拔等操作，感知是否新增或移除可用硬件，
将动态变化的硬件设备也纳入分布式硬件管理。
```

#### **2. 设备组网上线**

## 线程模型

### 服务主线程

- SA 生命周期运行在主线程
- 接收 IPC 请求并分发
- 任务调度和控制逻辑

### 任务执行线程

- `TaskExecutor` 管理任务执行
- 支持异步执行长时间操作
- 避免阻塞 IPC 响应

### 传输线程

- AV 传输使用独立线程
- 音视频数据异步传输
- 低延迟处理优化
