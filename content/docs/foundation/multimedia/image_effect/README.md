# ImageEffect Wiki 文档

## 文档概述

本文档为 OpenHarmony 多媒体子系统 ImageEffect 模块的工程 Wiki，旨在帮助开发者快速理解项目架构、核心能力、编译构建以及安全风险。

## 覆盖范围

| 分类 | 内容 |
|------|------|
| **项目定位** | ImageEffect 模块边界、核心能力、运行环境 |
| **目录结构** | 源代码目录归类与模块职责（不含测试） |
| **架构说明** | 组件图、数据流、线程模型、关键时序 |
| **对外 API** | N-API 接口清单、参数校验、错误码 |
| **内部 API** | 模块接口、依赖方向、稳定性标注 |
| **编译构建** | GN Targets、依赖关系、编译产物 |
| **安全评审** | 攻击面、信任边界、风险点与修复建议 |

## 未覆盖范围

- **测试相关内容**：test/、unittest/、fuzz/ 等目录不计入文档范围
- **第三方库内部实现**：仅描述依赖关系，不深入源码
- **运行时配置细节**：动态参数调优指南（待补充）

## 文档更新方式

### 何时需要更新文档

当发生以下变更时，需要同步更新 Wiki：

1. 新增或删除 N-API 接口
2. 修改模块职责或依赖关系
3. 变更编译产物或构建配置
4. 新增安全检查或修复安全漏洞

### 更新流程

1. 在 `wiki/_work/NOTES.md` 中记录变更事实（路径、符号、代码片段）
2. 修改对应的 Wiki 文件
3. 更新 `SUMMARY.md` 中的链接（若新增页面）
4. 运行一致性检查（Phase 7）

### 责任人

- **模块负责人**：负责 N-API 和架构变更
- **安全评审**：负责安全风险更新
