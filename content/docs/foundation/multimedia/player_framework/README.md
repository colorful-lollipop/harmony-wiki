# OpenHarmony Player Framework Wiki

## 文档概述

本文档为 OpenHarmony `multimedia/player_framework` 子系统的工程 Wiki，旨在帮助开发者快速理解项目架构、API 使用、构建流程和安全注意事项。

## 覆盖范围

### 已覆盖内容
- 项目定位与核心能力
- 目录结构与模块职责
- N-API 对外接口清单
- GN 构建目标与编译产物
- 架构设计与数据流
- 安全风险分析

### 未覆盖内容
- 详细 API 使用示例（见各模块 N-API 文档）
- 运行时配置参数
- 性能调优指南

## 更新方式

本文档基于代码仓库自动生成。如需更新：

1. **修改代码后**：文档会自动反映代码变更
2. **手动更新**：直接编辑对应的 `.md` 文件
3. **添加新模块**：在 `SUMMARY.md` 中添加导航，并在相应位置创建文档
