# 数据流与线程模型

## 数据流概述

### 播放流程

```
┌─────────────┐     ┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│   数据源     │────▶│   解复用     │────▶│   解码器     │────▶│   渲染器     │
│ (File/URL)  │     │ (Demuxer)   │     │ (Decoder)   │     │ (Renderer)  │
└─────────────┘     └─────────────┘     └─────────────┘     └─────────────┘
```

## IPC 通信

### 跨进程数据传递

- **Parcel 序列化**: 使用 `MessageParcel` 跨进程传递数据
- **回调注册**: `IRemoteObject` 用于事件回调
- **死亡通知**: `DeathRecipient` 处理服务端异常终止

### 代码示例

```cpp
// 服务端注册
sptr<IRemoteObject> listenerObj = data.ReadRemoteObject();
auto listenerProxy = iface_cast<IPlayerListener>(listenerObj);

// 客户端获取
sptr<IRemoteObject> object = listenerStub_->AsObject();
```

## 线程安全

### 同步机制

- **互斥锁**: `std::mutex` 保护共享资源
- **条件变量**: `std::condition_variable` 线程同步
- **原子操作**: `std::atomic` 状态标记

### 注意事项

1. N-API 回调必须在 JS 线程执行
2. 服务端处理不能阻塞 IPC 线程
3. 跨线程访问需加锁保护
