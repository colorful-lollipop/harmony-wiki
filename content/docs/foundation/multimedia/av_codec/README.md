## 文档更新方式

### 触发条件

当以下代码变更发生时，建议同步更新 Wiki：

| 变更类型 | 触发条件 | 负责人 |
|---------|---------|--------|
| 接口变更 | `interfaces/kits/c/*.h` 修改 | 接口作者 |
| 架构变更 | 服务层重构、IPC 路由变化 | 架构师 |
| 构建变更 | BUILD.gn 新增 target、依赖变化 | 构建维护者 |
| 安全问题 | 新增鉴权、数据流变更 | 安全负责人 |

### 更新流程

1. 在 `wiki/_work/NOTES.md` 中记录变更事实（路径+符号）
2. 更新对应章节，提供代码证据（路径+行号）
3. 执行 `一致性检查`（见下方）
4. 提交时附带 Wiki 更新 commit

### 一致性检查清单

- [ ] SUMMARY.md 链接存在且无死链
- [ ] API 清单与头文件一致（含行号引用）
- [ ] GN target 名称与 BUILD.gn 匹配
- [ ] 安全评审覆盖新攻击面
- [ ] 术语统一（首次出现的缩写提供全称）
