# 关键调用链 (Callgraphs)

## 概述

本文档描述 arkui_cangjie_wrapper 的关键调用链，从用户代码入口到核心逻辑的完整路径。

---

## 组件渲染调用链

### 入口: @Component + build()

```
用户代码
    │
    v
┌─────────────────┐
│  @Component     │  组件声明
│  build() 函数   │  UI 描述
└────────┬────────┘
         │
         v
┌─────────────────┐     ┌─────────────────┐
│  Cangjie 编译   │────>│  组件树构建     │
│  前端解析       │     │  (ACE 引擎)     │
└─────────────────┘     └────────┬────────┘
                                 │
                                 v
                       ┌─────────────────┐
                       │  状态初始化     │
                       │  @State/@Prop   │
                       └────────┬────────┘
                                │
                                v
                       ┌─────────────────┐
                       │  属性绑定       │
                       │  .xxx() 方法   │
                       └────────┬────────┘
                                │
                                v
                       ┌─────────────────┐
                       │  渲染指令生成   │
                       └────────┬────────┘
                                │
                                v
                       ┌─────────────────┐
                       │  引擎渲染       │
                       │  (GPU/CPU)     │
                       └─────────────────┘
```

### 代码证据

| 步骤 | 证据位置 |
|------|----------|
| @Component 解析 | `ohos/arkui/component/*/*.cj` |
| build() 编译 | `ace_engine:cj_frontend_ohos` |
| 组件树构建 | `ohos/arkui/component/common/` |

## 状态更新调用链

### @State 更新触发重绘

```
用户操作 (onClick)
        │
        v
┌─────────────────┐
│  事件回调       │
│  () => {...}   │
└────────┬────────┘
         │
         v
┌─────────────────┐
│  状态赋值       │
│  this.count++   │
└────────┬────────┘
         │
         v
┌─────────────────┐
│  ObservableProperty│
│  (setValue)     │
└────────┬────────┘
         │
         v
┌─────────────────┐
│  SubscriberMgr │
│  (通知观察者)   │
└────────┬────────┘
         │
         v
┌─────────────────┐
│  组件重建       │
│  rebuild()     │
└────────┬────────┘
         │
         v
┌─────────────────┐
│  增量渲染       │
│  (ace_engine)  │
└─────────────────┘
```

### 代码证据

| 步骤 | 证据位置 |
|------|----------|
| ObservableProperty | `ohos/arkui/state_management/observed_property.cj` |
| SubscriberManager | `ohos/arkui/state_management/subscriber_manager.cj` |
| rebuild | `ohos/arkui/state_management/view_stack_processor.cj` |

### pushUrl()

```
router.pushUrl({ url: "pages/Detail" })
        │
        v
┌─────────────────┐
│  Cangjie API   │
│  (cj_router)   │
└────────┬────────┘
         │
         v
┌─────────────────┐
│  FFI 调用       │
│  (cangjie_ark_interop)│
└────────┬────────┘
         │
         v
┌─────────────────┐
│  Router 模块    │
│  (ace_engine)  │
└────────┬────────┘
         │
         v
┌─────────────────┐
│  页面栈管理     │
│  push 操作     │
└────────┬────────┘
         │
         v
┌─────────────────┐
│  页面切换动画   │
└────────┬────────┘
         │
         v
┌─────────────────┐
│  新页面渲染     │
└─────────────────┘
```

### 代码证据

| 步骤 | 证据位置 |
|------|----------|
| Cangjie API | `ohos/arkui/ui_context/cj_router.cj` |
| FFI 调用 | `cangjie_ark_interop` |
| 页面栈 | `ace_engine` |

## 组件交互调用链

### 父子组件 @Link 双向绑定

```
┌─────────────────────────────────────────────────────────────┐
│                        Parent                              │
│  ┌─────────────────┐     @Link      ┌─────────────────┐ │
│  │  @State count  │ <────────────> │    Child        │ │
│  │                │               │  @Link count    │ │
│  └────────┬────────┘               └────────┬────────┘ │
└───────────┼──────────────────────────────────┼───────────┘
            │                                  │
            │ 1. 状态变化                      │ 4. 同步
            v                                  v
┌─────────────────┐                 ┌─────────────────┐
│  Setter 调用    │                 │  Getter 读取    │
│  (Observable)  │ ──────────────> │  (最新值)       │
└────────┬────────┘                 └─────────────────┘
         │
         v
┌─────────────────┐
│  Notify Change │
│  (Subscriber)  │
└────────┬────────┘
         │
         v
┌─────────────────┐
│  Parent Rebuild │  双方都重建
└────────┬────────┘
         │
         v
┌─────────────────┐
│  Child Rebuild  │
└─────────────────┘
```
