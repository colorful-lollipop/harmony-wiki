# 01_Overview - 项目概览

## 项目定位

**advanced_ui_component** 是 OpenHarmony ArkUI 生态系统中的高级 UI 组件库，专注于为原子化服务场景提供高效、统一的 UI 组合解决方案。

### 核心价值

| 价值 | 说明 |
|------|------|
| **接口封闭** | 对外提供简洁的 ArkTS API，内部实现细节对开发者透明 |
| **风格一致** | 所有组件遵循统一的 UI 设计语言和交互模式 |
| **开箱即用** | 组件经过充分测试，可直接集成到应用中 |
| **高效组合** | 组件间低耦合，可灵活组合满足复杂场景 |

---

## 核心能力

### 1. 原子化服务 UI 组件

提供完整的原子化服务场景 UI 解决方案：

- **导航组件** (AtomServiceNavigation) - 提供统一的导航体验
- **搜索组件** (AtomServiceSearch) - 集成搜索功能的 UI
- **标签页组件** (AtomServiceTabs) - 多标签内容切换
- **Web 组件** (AtomServiceWeb) - 安全的 Web 内容渲染

### 2. 启动体验组件

提供专业的应用启动页支持：

- **全屏启动组件** (FullScreenLaunchComponent)
- **半屏启动组件** (HalfScreenLaunchComponent)
- **内部全屏启动组件** (InnerFullScreenLaunchComponent)

### 3. 弹窗与导航

提供常用的弹窗和导航工具：

- **插屏弹窗** (InterstitialDialogAction)
- **导航路径助手** (NavPushPathHelper)
- **自定义应用栏** (CustomAppBar)

## 技术特点

### ArkTS + N-API 混合架构

```
┌────────────────────────────────────────┐
│           ArkTS 组件层 (.ets)           │
│   UI 定义、状态管理、声明式构建         │
└────────────────┬───────────────────────┘
                 │ 编译
                 ▼
┌────────────────────────────────────────┐
│            ABC 字节码                  │
│   ArkTS 编译产物，运行时代码            │
└────────────────┬───────────────────────┘
                 │ 嵌入
                 ▼
┌────────────────────────────────────────┐
│          N-API 绑定层 (.cpp)            │
│   模块注册、ABC 导出、系统 API 调用     │
└────────────────────────────────────────┘
                 │
                 ▼
┌────────────────────────────────────────┐
│           OpenHarmony 系统              │
│   AbilityKit, BundleMgr, WindowMgr     │
└────────────────────────────────────────┘
```

### 组件分类

| 分类 | 组件 | 说明 |
|------|------|------|
| **纯 ArkTS** | 大多数组件 | 只包含 .ets UI 定义，ABC 字节码导出 |
| **N-API 功能** | AtomServiceWeb, NavPushPathHelper, AtomServiceMenuBar | 导出实际 JS API，调用系统能力 |

## 使用场景

### 原子化服务开发

```
典型场景:
1. 用户通过服务中心发现应用
2. 应用以原子化形式启动
3. 提供沉浸式的 UI 体验
4. 快速响应用户操作
```

**推荐组件组合**:
```typescript
// 原子化服务典型布局
import { AtomicServiceNavigation } from '@ohos/atomicService';
import { AtomicServiceTabs } from '@ohos/atomicService';
import { AtomicServiceWeb } from '@ohos/atomicService';
```

### 应用启动页

```
典型场景:
1. 应用冷启动展示
2. 品牌宣传
3. 加载初始化数据
4. 过渡到主界面
```

**推荐组件**:
- FullScreenLaunchComponent (全屏)
- HalfScreenLaunchComponent (半屏)

### 弹窗交互

```
典型场景:
1. 广告插屏
2. 功能引导
3. 重要信息提示
4. 用户操作确认
```

**推荐组件**:
- InterstitialDialogAction
