# 关键调用链

## 概述

本文档描述 graphic_2d 中的关键调用链，从入口到核心逻辑的完整路径。

---

## 渲染管线调用链

### JS → 渲染服务完整路径

```
┌─────────────────────────────────────────────────────────────────────────────────────────┐
│ Application (ArkUI)                                                                   │
└─────────────────────────────────┬───────────────────────────────────────────────────────┘
                                  │
                                  ▼ JS/ArkTS API 调用
┌─────────────────────────────────────────────────────────────────────────────────────────┐
│ RSNode/RSAnimation/RSModifier API                                                        │
│ 文件: rosen/modules/render_service_client/core/ui/rs_node.h                             │
└─────────────────────────────────┬───────────────────────────────────────────────────────┘
                                  │
                                  ▼ 属性修改 / 动画启动
┌─────────────────────────────────────────────────────────────────────────────────────────┐
│ RSTransactionHandler                                                                   │
│ 文件: rosen/modules/render_service_client/core/transaction/rs_transaction_handler.cpp    │
└─────────────────────────────────┬───────────────────────────────────────────────────────┘
                                  │
                                  ▼ RSTransactionData 创建
┌─────────────────────────────────────────────────────────────────────────────────────────┐
│ RSIClientToServiceConnection::CommitTransaction()                                        │
│ 文件: rs_iclient_to_service_connection.h (150+ 方法)                                    │
└─────────────────────────────────────────────────────────────────────────────────────────┘
                                  │
                                  ▼ IPC Marshalling
┌─────────────────────────────────────────────────────────────────────────────────────────┐
│ RSClientToServiceConnectionProxy                                                         │
│ 文件: rosen/modules/render_service_base/src/platform/ohos/                               │
└─────────────────────────────────┬───────────────────────────────────────────────────────┘
                                  │
                                  ▼ IPC 传输 (ipc_core)
┌─────────────────────────────────────────────────────────────────────────────────────────┐
│ RSRenderServiceStub (服务端存根)                                                         │
│ 文件: rs_render_service_stub.h                                                          │
└─────────────────────────────────┬───────────────────────────────────────────────────────┘
                                  │
                                  ▼ RecvRSTransactionData
┌─────────────────────────────────────────────────────────────────────────────────────────┐
│ RSMainThread (主线程)                                                                   │
│ 文件: render_service/core/pipeline/main_thread/rs_main_thread.h                          │
│                                                                                         │
│ 职责:                                                                                  │
│ 1. 解析事务数据                                                                         │
│ 2. 更新渲染节点树                                                                       │
│ 3. 执行 Prepare() 阶段 (Visitor)                                                        │
│ 4. 计算脏区域                                                                           │
│ 5. 生成 Drawable                                                                        │
└─────────────────────────────────────────────────────────────────────────────────────────┘
                                  │
                                  ▼ RSRenderThreadParams 同步
┌─────────────────────────────────────────────────────────────────────────────────────────┐
│ RSUniRenderThread (渲染线程)                                                             │
│ 文件: render_service/core/pipeline/render_thread/rs_uni_render_thread.h                 │
│                                                                                         │
│ 职责:                                                                                  │
│ 1. GPU 渲染执行                                                                        │
│ 2. Drawable 执行 (OnDraw)                                                              │
│ 3. RenderEngine 操作                                                                   │
│ 4. 内存管理                                                                            │
└─────────────────────────────────────────────────────────────────────────────────────────┘
                                  │
                                  ▼ Layer Buffer 提交
┌─────────────────────────────────────────────────────────────────────────────────────────┐
│ HWC / Hardware Composer                                                                 │
│ 文件: render_service/core/pipeline/hwc/                                                 │
│                                                                                         │
│ 职责:                                                                                  │
│ 1. 硬件合成                                                                            │
│ 2. 显示 buffer 提交                                                                    │
└─────────────────────────────────────────────────────────────────────────────────────────┘
                                  │
                                  ▼
┌─────────────────────────────────────────────────────────────────────────────────────────┐
│ Display / Screen                                                                       │
└─────────────────────────────────────────────────────────────────────────────────────────┘
```

## IPC 接口调用链

### CreateConnection 流程

```
┌─────────────────────────────────────────────────────────────────────────────────────────┐
│ 客户端: RSTransactionHandler::CreateConnection()                                      │
└─────────────────────────────────┬───────────────────────────────────────────────────────┘
                                  │
                                  ▼ IPC Proxy 调用
┌─────────────────────────────────────────────────────────────────────────────────────────┐
│ RSRenderServiceProxy::CreateConnection()                                               │
│ 文件: rs_render_service_proxy.cpp                                                       │
│                                                                                         │
│ 参数:                                                                                   │
│ - token: RSIConnectionToken                                                            │
│ 返回: RSIClientToServiceConnection, RSIClientToRenderConnection                       │
└─────────────────────────────────────────────────────────────────────────────────────────┘
                                  │
                                  ▼ MessageParcel 序列化
┌─────────────────────────────────────────────────────────────────────────────────────────┐
│ IPC 传输层                                                                              │
│ - Transaction code: CREATE_CONNECTION (0)                                              │
│ - Data: token descriptor                                                              │
└─────────────────────────────────────────────────────────────────────────────────────────┘
                                  │
                                  ▼
┌─────────────────────────────────────────────────────────────────────────────────────────┐
│ RSRenderServiceStub::OnRemoteRequest()                                                 │
│ 文件: rs_render_service_stub.cpp                                                       │
│                                                                                         │
│ 处理:                                                                                   │
│ 1. 解析 transaction code                                                               │
│ 2. 权限检查 (IsInterfaceCodeAccessible)                                                │
│ 3. 调用具体处理函数                                                                     │
└─────────────────────────────────────────────────────────────────────────────────────────┘
                                  │
                                  ▼
┌─────────────────────────────────────────────────────────────────────────────────────────┐
│ RSRenderService::CreateConnection()                                                     │
│ 文件: render_service/main/render_server/rs_render_service.cpp                           │
│                                                                                         │
│ 实现:                                                                                   │
│ 1. 创建 RSClientToServiceConnection                                                    │
│ 2. 创建 RSClientToRenderConnection                                                     │
│ 3. 注册 Death Recipient                                                                 │
│ 4. 返回代理对象                                                                         │
└─────────────────────────────────────────────────────────────────────────────────────────┘
```

## 动画调用链

### RSAnimation 启动

```
┌─────────────────────────────────────────────────────────────────────────────────────────┐
│ JS/ArkTS: animation.start(targetNode)                                                  │
└─────────────────────────────────┬───────────────────────────────────────────────────────┘
                                  │
                                  ▼
┌─────────────────────────────────────────────────────────────────────────────────────────┐
│ RSAnimation::Start()                                                                    │
│ 文件: rosen/modules/render_service_client/core/animation/rs_animation.h                 │
└─────────────────────────────────┬───────────────────────────────────────────────────────┘
                                  │
                                  ▼
┌─────────────────────────────────────────────────────────────────────────────────────────┐
│ RSImplicitAnimator::Animate()                                                           │
│ 文件: rosen/modules/render_service_client/core/animation/rs_implicit_animator.h         │
│                                                                                         │
│ 职责:                                                                                  │
│ 1. 创建属性动画实例                                                                     │
│ 2. 配置动画参数                                                                         │
│ 3. 启动动画                                                                            │
└─────────────────────────────────────────────────────────────────────────────────────────┘
                                  │
                                  ▼
┌─────────────────────────────────────────────────────────────────────────────────────────┐
│ RSAnimationTimingCurve::CreateSpringCurve()                                            │
│ 文件: rs_animation_timing_curve.h                                                      │
│                                                                                         │
│ 弹簧参数: mass, stiffness, damping, velocity                                            │
└─────────────────────────────────────────────────────────────────────────────────────────┘
                                  │
                                  ▼ IPC Marshalling
┌─────────────────────────────────────────────────────────────────────────────────────────┐
│ RSRenderAnimation marshalling                                                           │
│ 文件: render_service_base/src/animation/                                                │
│                                                                                         │
│ 序列化:                                                                                │
│ - Animation 类型                                                                        │
│ - 目标属性 ID                                                                          │
│ - 时间曲线参数                                                                         │
│ - 动画值范围                                                                           │
└─────────────────────────────────────────────────────────────────────────────────────────┘
                                  │
                                  ▼
┌─────────────────────────────────────────────────────────────────────────────────────────┐
│ RSMainThread: Animation 处理                                                            │
│ 文件: render_service/core/pipeline/main_thread/                                          │
│                                                                                         │
│ 职责:                                                                                  │
│ 1. 反序列化动画数据                                                                     │
│ 2. 创建 RSRenderAnimation                                                              │
│ 3. 注册到 RSAnimationManager                                                           │
│ 4. 触发帧更新                                                                          │
└─────────────────────────────────────────────────────────────────────────────────────────┘
                                  │
                                  ▼
┌─────────────────────────────────────────────────────────────────────────────────────────┐
│ RSUniRenderThread: 动画帧执行                                                           │
│ 文件: render_service/core/pipeline/render_thread/                                        │
│                                                                                         │
│ 每帧:                                                                                  │
│ 1. 计算当前动画值                                                                      │
│ 2. 更新目标节点属性                                                                    │
│ 3. 标记脏区域                                                                          │
│ 4. 触发重绘                                                                            │
└─────────────────────────────────────────────────────────────────────────────────────────┘
```
