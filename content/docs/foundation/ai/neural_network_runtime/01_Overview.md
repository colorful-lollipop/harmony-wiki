# 01. 项目概览

## 目的

本文档介绍 Neural Network Runtime (NNRt) 的项目定位、边界、核心能力和运行环境。

## 适用范围

- AI 框架开发者
- 芯片厂商驱动开发者
- OpenHarmony 系统开发者

## 项目定位

### 在 OpenHarmony AI 栈中的位置

```
┌─────────────────────────────────────────────────────────────┐
│  Layer 4: 应用层                                             │
│  - AI 应用 (图像识别、语音识别等)                             │
├─────────────────────────────────────────────────────────────┤
│  Layer 3: 框架层                                             │
│  - MindSpore Lite / TensorFlow Lite                         │
├─────────────────────────────────────────────────────────────┤
│  Layer 2: 运行时层 ← Neural Network Runtime (本仓库)         │
│  - 模型管理、编译、执行                                       │
│  - 设备抽象、内存管理                                         │
├─────────────────────────────────────────────────────────────┤
│  Layer 1: 驱动层                                             │
│  - HDI Service (芯片驱动)                                    │
│  - NPU / DSP / GPU / CPU                                     │
├─────────────────────────────────────────────────────────────┤
│  Layer 0: 硬件层                                             │
│  - AI 加速芯片                                               │
└─────────────────────────────────────────────────────────────┘
```

### 职责边界

| 层级 | 职责 | 非职责 |
|------|------|--------|
| NNRt | 模型编译、执行调度、设备管理、内存管理 | 模型训练、算子实现 |
| HDI Service | 算子实现、硬件控制、性能优化 | 模型解析、跨设备调度 |
| AI 框架 | 模型解析、图优化、前端 API | 硬件适配、底层执行 |

## 核心能力

### 1. 模型构建

- 通过 API 逐步构建模型（添加张量、算子、设置输入输出）
- 从 LiteGraph 直接加载（内部接口）
- 从 MetaGraph 直接加载（内部接口）

### 2. 模型编译

- 在线编译：将算子图编译为设备可执行格式
- 离线加载：加载预编译的离线模型
- 缓存管理：保存和恢复编译缓存

### 3. 模型执行

- 同步执行：阻塞式推理
- 异步执行：非阻塞式推理（接口预留，当前未实现）
- 动态形状：支持动态输入输出形状

### 4. 设备管理

- 设备枚举：查询可用设备
- 设备选择：指定编译和执行设备
- 能力查询：查询设备支持的算子和特性

### 5. 内存管理

- 共享内存：与设备共享内存，零拷贝数据传输
- 张量内存：自动分配和管理张量内存
- 缓冲区复用：支持 fd 缓冲区复用

## 关键概念

### 1. Model (模型)

模型的内存表示，包含张量、算子和图结构。

**关键 API**:
- `OH_NNModel_Construct()` - 创建模型
- `OH_NNModel_AddTensorToModel()` - 添加张量
- `OH_NNModel_AddOperation()` - 添加算子
- `OH_NNModel_Finish()` - 完成构建

### 2. Compilation (编译)

编译配置和编译后的模型表示。

**关键 API**:
- `OH_NNCompilation_Construct()` - 创建编译配置
- `OH_NNCompilation_SetDevice()` - 设置目标设备
- `OH_NNCompilation_Build()` - 执行编译

### 3. Executor (执行器)

执行编译后的模型进行推理。

**关键 API**:
- `OH_NNExecutor_Construct()` - 创建执行器
- `OH_NNExecutor_RunSync()` - 同步执行
- `OH_NNExecutor_RunAsync()` - 异步执行（预留）

### 4. Tensor (张量)

多维数组，包含数据、形状、数据类型、格式。

**关键 API**:
- `OH_NNTensorDesc_Create()` - 创建张量描述符
- `OH_NNTensor_Create()` - 创建张量
- `OH_NNTensor_GetDataBuffer()` - 获取数据缓冲区

### 5. Backend (后端)

设备后端的抽象，封装了特定硬件的能力查询和对象创建。

### 6. HDI (Hardware Device Interface)

硬件设备接口，定义了 NNRt 与芯片驱动之间的标准通信协议。

## 版本演进

| 版本 | API 级别 | 主要特性 |
|------|----------|----------|
| 1.0 | 9 | 基础模型构建、编译、执行 |
