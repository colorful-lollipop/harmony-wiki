## 2. 数据流

### 2.1 语音注册数据流

```
┌──────────┐     ┌──────────┐     ┌──────────┐     ┌──────────┐     ┌──────────┐
│   JS     │────▶│  N-API   │────▶│ Manager  │────▶│  SA     │────▶│  Engine  │
│  应用    │     │  绑定    │     │  (CPP)  │     │ Service │     │  (注册)  │
└──────────┘     └──────────┘     └──────────┘     └──────────┘     └──────────┘
                                                                        │
                                                                        ▼
                                                                  ┌──────────┐
                                                                  │   DSP    │
                                                                  │  驱动    │
                                                                  └──────────┘
```

**流程说明**:
1. JS 应用调用 `createEnrollIntelligentVoiceEngine()` 创建引擎
2. N-API 层绑定 C++ 实现
3. Manager 调用 SA 获取引擎实例
4. SA 管理引擎生命周期
5. 引擎通过 HDI 与 DSP 驱动交互

### 2.2 语音唤醒数据流

```
┌──────────┐     ┌──────────┐     ┌──────────┐     ┌──────────┐     ┌──────────┐
│   DSP    │────▶│Trigger   │────▶│  SA     │────▶│ Engine   │────▶│   JS    │
│  驱动    │     │ Manager  │     │ Service │     │ (唤醒)   │     │  应用    │
└──────────┘     └──────────┘     └──────────┘     └──────────┘     └──────────┘
                         │
                         ▼
                   ┌──────────┐
                   │  事件    │
                   │  回调    │
                   └──────────┘
```

**流程说明**:
1. DSP 硬件检测到唤醒词
2. Trigger Manager 接收 DSP 事件
3. SA 分发唤醒事件
4. 唤醒引擎处理并验证
5. 通过回调通知 JS 应用

**证据来源**:
- `services/intell_voice_service/server/sa/intell_voice_service.cpp`: SA 服务实现
- `services/intell_voice_trigger/`: 触发器管理

## 3. 线程模型

### 3.1 线程结构

```
┌─────────────────────────────────────────────────────────────────────┐
│                        主线程 (Main Thread)                          │
│  ┌──────────────┐  ┌──────────────┐  ┌──────────────────────────┐ │
│  │   UI 线程    │  │  JS 线程     │  │  N-API 回调线程          │ │
│  └──────────────┘  └──────────────┘  └──────────────────────────┘ │
└─────────────────────────────────────────────────────────────────────┘
                              │
                              │ IPC
                              ▼
┌─────────────────────────────────────────────────────────────────────┐
│                     服务进程 (intell_voice_service)                  │
│  ┌────────────────┐  ┌────────────────┐  ┌──────────────────────┐ │
│  │  SA 主线程     │  │  FFRT 线程池  │  │  I/O 线程           │ │
│  │ (消息循环)     │  │  (异步任务)   │  │  (文件/网络)        │ │
│  └────────────────┘  └────────────────┘  └──────────────────────┘ │
└─────────────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────────────┐
│                       驱动进程 (DSP/HDI)                              │
│  ┌────────────────┐  ┌────────────────┐                            │
│  │  DSP 硬件线程  │  │  算法处理线程  │                            │
│  │  (低功耗监听)  │  │  (特征提取)   │                            │
│  └────────────────┘  └────────────────┘                            │
└─────────────────────────────────────────────────────────────────────┘
```

### 3.2 线程同步机制

| 机制 | 用途 | 代码位置 |
|------|------|---------|
| **FFRT** | 异步任务调度 | `intell_voice_service.gni`: `USE_FFRT` |
| **Mutex** | 线程锁 | `utils/` 工具类 |
| **Condition Variable** | 条件等待 | `intell_voice_manager.h`: `proxyConVar_` |
| **Message Queue** | 消息队列 | `utils/message_queue.cpp` |

**证据来源**:
- `intell_voice_service.gni`: `"USE_FFRT"` 配置
- `interfaces/inner_api/native/intell_voice_manager.h`: 线程同步变量

## 4. IPC 通信

### 4.1 IPC 架构

```
┌─────────────────────────────────────────────────────────────────┐
│                         调用者进程                                │
│  ┌──────────────┐  ┌──────────────┐  ┌──────────────────────┐ │
│  │   JS 应用    │  │  N-API Proxy │  │  IPC Proxy          │ │
│  └──────────────┘  └──────────────┘  └──────────────────────┘ │
└────────────────────────────┬────────────────────────────────────┘
                           │ IPC (Binder)
                           ▼
┌─────────────────────────────────────────────────────────────────┐
│                      服务进程 (intell_voice_service)              │
│  ┌──────────────┐  ┌──────────────┐  ┌──────────────────────┐ │
│  │  IPC Stub   │  │   Service    │  │  Engine Manager      │ │
│  │  (接口桩)    │  │   Logic      │  │                      │ │
│  └──────────────┘  └──────────────┘  └──────────────────────┘ │
└─────────────────────────────────────────────────────────────────┘
```
