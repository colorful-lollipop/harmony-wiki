# 关键调用链

> connectivity_cangjie_wrapper 入口到核心逻辑的调用链路

## BLE 扫描调用链

### 入口 → 扫描启动

```
┌─────────────────────────────────────────────────────────────────────────┐
│                     BLE 扫描调用链 (plantuml)                            │
├─────────────────────────────────────────────────────────────────────────┤
│                                                                         │
│  @startBleScanning(filters, options)                                   │
│           │                                                             │
│           ▼                                                             │
│  ┌─────────────────────────────────────────────────────────────┐       │
│  │  ble.cj:startBleScanning()                                   │       │
│  │  • 参数: Array<ScanFilter>, ?ScanOptions                      │       │
│  │  • 校验: 数组大小, options 字段                                │       │
│  └─────────────────────────────────────────────────────────────┘       │
│           │                                                             │
│           ▼                                                             │
│  ┌─────────────────────────────────────────────────────────────┐       │
│  │  safeMalloc<NativeScanFilter>(filtersSize)                   │       │
│  │  • 分配 native 内存                                          │       │
│  │  • 转换 Cangjie 对象到 Native 对象                            │       │
│  └─────────────────────────────────────────────────────────────┘       │
│           │                                                             │
│           ▼                                                             │
│  ┌─────────────────────────────────────────────────────────────┐       │
│  │  FfiBluetoothBleStartBleScan(cFilters, cOptions, &errorCode) │       │
│  │  • 调用底层蓝牙 FFI 接口                                       │       │
│  │  • 异步启动扫描                                               │       │
│  └─────────────────────────────────────────────────────────────┘       │
│           │                                                             │
│           ▼                                                             │
│  ┌─────────────────────────────────────────────────────────────┐       │
│  │  checkRet(errorCode)                                         │       │
│  │  • 检查 errorCode                                            │       │
│  │  • 失败时抛出 BusinessException                               │       │
│  └─────────────────────────────────────────────────────────────┘       │
│                                                                         │
└─────────────────────────────────────────────────────────────────────────┘
```

### 回调注册与触发

```
┌─────────────────────────────────────────────────────────────────────────┐
│                     BLE 回调调用链                                        │
├─────────────────────────────────────────────────────────────────────────┤
│                                                                         │
│  @on(BleDeviceFind, callback)                                           │
│           │                                                             │
│           ▼                                                             │
│  ┌─────────────────────────────────────────────────────────────┐       │
│  │  commonSubscribe1Arg(BleDeviceFind, callback)                │       │
│  │  • 检查是否已注册                                             │       │
│  │  • 创建 Callback1Param wrapper                                │       │
│  └─────────────────────────────────────────────────────────────┘       │
│           │                                                             │
│           ▼                                                             │
│  ┌─────────────────────────────────────────────────────────────┐       │
│  │  FfiBluetoothBleOn("BleDeviceFind", callbackId, &errorCode)  │       │
│  │  • 注册到底层蓝牙服务                                          │       │
│  └─────────────────────────────────────────────────────────────┘       │
│           │                                                             │
│           │  [底层蓝牙服务扫描到设备]                                     │
│           │                                                             │
│           ▼                                                             │
│  ┌─────────────────────────────────────────────────────────────┐       │
│  │  Native 回调 → Callback1Param wrapper                         │       │
│  │  • cArr2cjArr 转换数组                                        │       │
│  │  • 调用 Cangjie 回调函数                                      │       │
│  └─────────────────────────────────────────────────────────────┘       │
│           │                                                             │
│           ▼                                                             │
│  ┌─────────────────────────────────────────────────────────────┐       │
│  │  应用回调函数 (Callback1Argument<Array<ScanResult>>)          │       │
│  │  • 处理扫描结果                                               │       │
│  └─────────────────────────────────────────────────────────────┘       │
│                                                                         │
└─────────────────────────────────────────────────────────────────────────┘
```

## 错误处理调用链

```
┌─────────────────────────────────────────────────────────────────────────┐
│                     错误处理调用链                                        │
├─────────────────────────────────────────────────────────────────────────┤
│                                                                         │
│  API 调用                                                               │
│       │                                                                │
│       ▼                                                                │
│  ┌─────────────────────────────────────────────────────────────┐       │
│  │  FfiModuleApi(..., &errorCode)                               │       │
│  │  • 调用 FFI 函数                                             │       │
│  │  • 返回 errorCode                                            │       │
│  └─────────────────────────────────────────────────────────────┘       │
│       │                                                                │
│       ▼                                                                │
│  ┌─────────────────────────────────────────────────────────────┐       │
│  │  checkRet(errorCode)                                         │       │
│  │       │                                                      │       │
│  │       ▼                                                      │       │
│  │  if (errorCode == 0)                                         │       │
│  │  │    return 正常结果                                        │       │
│  │  else                                                        │       │
│  │       ▼                                                      │       │
│  │  throw BusinessException(code, getErrorMsg(code))            │       │
│  └─────────────────────────────────────────────────────────────┘       │
│                                                                         │
│  错误码映射:                                                            │
│  • 201 → "Permission denied"                                          │
│  • 801 → "Capability not supported"                                   │
│  • 2900001 → "Service stopped"                                        │
│  • 2900003 → "Bluetooth disabled"                                     │
│  • 2900099 → "Operation failed"                                       │
│                                                                         │
└─────────────────────────────────────────────────────────────────────────┘
```

## 模块间调用关系

### BLE 模块内部调用

```
ble.cj (主 API)
    │
    ├──► gatt_client_device.cj (GATT 客户端)
    │         └──► FfiBluetoothBleCreateGattClientDevice()
    │         └──► FfiBluetoothBleSetDeviceName()
    │         └──► ...
    │
    ├──► gatt_server.cj (GATT 服务端)
    │         └──► FfiBluetoothBleCreateGattServer()
    │         └──► FfiBluetoothBleAddService()
    │         └──► ...
    │
    ├──► native.cj (Native 绑定)
    │         └──► FfiBluetoothBleStartBleScan()
    │         └──► FfiBluetoothBleStopBleScan()
    │         └──► FfiBluetoothBleStartAdvertising()
    │         └──► FfiBluetoothBleOn()
    │
    └──► util.cj, gatt_util.cj (工具函数)
              └──► 数据转换
              └──► 内存管理
```

### WiFi 模块内部调用

```
wifi.cj (主 API)
    │
    ├──► FfiWifiIsWifiActive()
    ├──► FfiWifiGetScanInfoList()
    ├──► FfiWifiStartDiscoverDevices()
    ├──► FfiWifiStopDiscoverDevices()
    ├──► FfiWifiP2pConnect()
    ├──► FfiWifiP2pCancelConnect()
    ├──► FfiWifiWifiOn()      // 回调注册
    │
    └──► wifi_p2p_config.cj (配置)
    └──► wifi_scan_info.cj (结果)
```
