# T2Stack Wiki 文档

## 文档概述

本文档为 OpenHarmony t2stack 项目（极简网络协议栈）的工程 Wiki，旨在帮助开发者快速理解项目架构、模块职责、接口规范、构建配置以及安全风险。

## 覆盖范围

本文档覆盖 t2stack 项目的以下方面：

| 分类 | 覆盖内容 |
|------|----------|
| **项目定位** | 核心能力、运行环境、关键概念 |
| **架构说明** | 组件图、数据流、线程模型、关键时序 |
| **目录结构** | 模块划分、职责边界 |
| **接口文档** | C API 接口清单、参数说明、错误码 |
| **构建系统** | GN Targets、依赖关系、编译产物 |
| **运行时** | 产物安装路径、加载关系 |
| **安全评审** | 攻击面分析、风险点、修复建议 |
| **故障排查** | 常见问题、定位方法 |

## 未覆盖范围

- **测试代码**：单元测试、集成测试等测试相关内容不在本文档范围内
- **外部依赖**：仅记录 t2stack 直接依赖的组件，不包含 transitive 依赖的内部实现
- **运行时配置**：仅记录编译时配置，运行时行为配置请参考对应模块文档

## 文档更新方式

本文档由代码自动生成工具维护，**不应手动编辑**。当代码发生以下变化时，需要重新生成文档：

1. 新增/删除/重命名模块
2. 新增/删除/修改 C API 接口
3. 修改 BUILD.gn 构建配置
4. 新增安全相关特性或修复

### 手动更新规则

如需手动更新本文档，请遵守以下规则：

1. **仅修改描述性内容**：API 签名、参数类型、返回值等必须与代码保持一致
2. **标注证据来源**：关键结论必须标注代码证据（文件路径 + 行号）
3. **保持术语统一**：使用本文档已有的术语风格

## 术语表

| 术语 | 含义 |
|------|------|
| t2stack | 极简网络协议栈及其配套中间件 |
| Fillp | 流传输协议，提供音视频流传输能力 |
| DFile | 文件传输协议，提供设备间文件传输能力 |
| NStackX | 设备发现协议，提供局域网设备发现能力 |
| VTP | Virtual Transport Protocol，Fillp 底层传输协议 |
| CoAP | Constrained Application Protocol，设备发现使用的应用层协议 |
| Inner API | 内部模块间调用的 C 接口 |
| GN | Generate Ninja，OpenHarmony 构建系统 |
