# DSoftBus Wiki 文档

## 文档概述

本文档是 OpenHarmony DSoftBus 分布式软总线项目的工程 Wiki，旨在帮助开发者快速理解项目架构、接口规范、编译配置以及安全相关注意事项。

## 代码证据原则

本文档所有关键结论均基于以下代码证据：

- **文件路径**：必要时代码行号引用
- **符号名称**：函数、类、宏、target 名称
- **代码片段**：最小必要调用链或实现描述

无法通过代码确认的结论标注为 `TODO(需确认)`。
