# 文档导航 (Document Navigation)

**netmanager_ext** 是 OpenHarmony 网络管理扩展模块，提供以太网、网络共享、VPN、防火墙等网络能力。

---

## 推荐阅读路线

### 🚀 路线一：新人学习路线 (5分钟→30分钟)

适合刚接触项目的开发者，快速建立全局认知。

```
1. 项目概览 (5分钟)
   ↓ 理解项目定位和核心能力
2. 目录结构 (10分钟)
   ↓ 熟悉代码组织，快速定位文件
3. 架构与数据流 (15分钟)
   ↓ 理解模块间关系和调用链
4. 对外接口文档 (按需查阅)
   └─ 开发时参考具体 API
```

**目标**: 5分钟理解定位，15分钟找到代码，30分钟理解架构

---

### 🔐 路线二：安全研究路线 (10分钟→深度分析)

适合安全审计人员，快速识别攻击面。

```
1. 攻击面分析 (10分钟)
   ↓ 识别所有外部输入入口
2. 安全风险评估 (30分钟)
   ↓ 分析具体漏洞点和利用路径
3. 对外接口文档 (20分钟)
   ↓ 理解参数处理和权限检查
4. 架构与数据流 (可选)
   └─ 理解信任边界跨越点
```

**目标**: 10分钟识别攻击面，定位所有权限检查点和敏感操作
