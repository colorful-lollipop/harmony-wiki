# sensors_miscdevice_lite 关键调用链

## ⚠️ 重要声明

**本文档基于标准实现推断**，Lite 版本当前无代码实现。

实际调用链请参考主实现仓库：
- **主实现仓库**: https://github.com/openharmony/sensors_miscdevice

## 1. 振动控制调用链

### 1.1 startVibration 调用链

```
用户应用 (ArkTS)
    │
    ▼
┌─────────────────────────────────────────────────────────────┐
│ @kit.SensorServiceKit                                       │
│ vibrator.startVibration(effect, attribute)                 │
└─────────────────────────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────────────────────────┐
│ N-API 层 (interfaces/plugin/napi_vibrator.cpp)             │
│                                                             │
│ 1. napi_create_...() - 参数封装                             │
│ 2. VibratorManager::StartVibration() - 调用框架            │
└─────────────────────────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────────────────────────┐
│ Native Framework (frameworks/native/)                      │
│                                                             │
│ 1. 参数校验                                                 │
│ 2. 权限检查                                                 │
│ 3. 会话创建                                                 │
│ 4. IPC 调用（如果跨进程）                                   │
└─────────────────────────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────────────────────────┐
│ Service 层 (services/miscdevice_service/)                  │
│                                                             │
│ 1. 接收 IPC 请求                                            │
│ 2. 业务逻辑处理                                             │
│ 3. HDI 调用                                                │
└─────────────────────────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────────────────────────┐
│ HDI 接口                                                   │
│                                                             │
│ IVibratorInterface::StartVibration(effect)                 │
└─────────────────────────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────────────────────────┐
│ HDF Driver (drivers/peripheral/vibrator/)                  │
│                                                             │
│ 1. 驱动初始化                                               │
│ 2. 硬件操作                                                 │
│ 3. 中断/定时器配置                                          │
└─────────────────────────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────────────────────────┐
│ Hardware                                                   │
│                                                             │
│ 振动马达 (LRA/ERM)                                          │
└─────────────────────────────────────────────────────────────┘
```

### 1.2 stopVibration 调用链

```
用户应用 (ArkTS)
    │
    ▼
N-API: napi_vibrator.cpp
    │
    ▼
Native Framework: VibratorManager
    │
    ▼
Service: MiscDeviceService
    │
    ▼
HDI: IVibratorInterface::StopVibration(mode)
    │
    ▼
HDF Driver: vibrator_driver_stop()
    │
    ▼
Hardware: 振动马达停止
```

## 3. 权限校验调用链

```
用户应用 (调用 API)
    │
    ▼
┌─────────────────────────────────────────────────────────────┐
│ N-API 层                                                    │
│                                                             │
│ 1. 提取调用者 UID/PID                                       │
│ 2. 调用权限检查接口                                          │
└─────────────────────────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────────────────────────┐
│ 权限管理系统 (abilityAccessCtrl)                            │
│                                                             │
│ 1. 检查权限声明                                              │
│ 2. 检查权限授予状态                                          │
│ 3. 返回检查结果                                              │
└─────────────────────────────────────────────────────────────┘
    │
    ├────────────────────┐
    │                    │
    ▼                    ▼
┌──────────┐       ┌──────────┐
│ 权限通过 │       │ 权限拒绝  │
└──────────┘       └──────────┘
    │                    │
    ▼                    ▼
继续执行          返回错误码 14600103
```

## 5. 关键文件位置（推断）

### 5.1 核心文件

| 功能 | 文件路径（推断） | 说明 |
|------|-----------------|------|
| **N-API 振动** | `interfaces/plugin/napi_vibrator.cpp` | JS API 实现 |
| **N-API LED** | `interfaces/plugin/napi_led.cpp` | LED 控制 |
| **Native 接口** | `interfaces/native/` | Native API 定义 |
| **框架实现** | `frameworks/native/` | 客户端框架 |
| **服务实现** | `services/miscdevice_service/` | 服务端逻辑 |
| **SA 配置** | `sa_profile/` | System Ability |

### 5.2 依赖系统组件

| 组件 | 路径 | 用途 |
|------|------|------|
| **IPC/Binder** | `foundation/systemabilitymgr/` | 进程间通信 |
| **HDF** | `drivers/framework/` | 驱动框架 |
| **权限系统** | `foundation/ability/ability_runtime/` | 权限管理 |
