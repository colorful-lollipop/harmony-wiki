# 关键调用链

## A.1 订阅流程调用链

### on() → FFI 订阅 → 数据回调

```
用户代码
    │
    ▼
┌─────────────────────────────────────────────────────────────────────────┐
│ sensor.cj: on<T>()                                                     │
│ 输入: sensorType, callback, option                                     │
│ 1. 调用 SensorManager.isMatchType() 验证回调类型                       │
│ 2. 创建 Callback1Param<CSensorCallbackData>                           │
│ 3. 调用 FfiSensorSubscribeSensor()                                    │
│ 4. 调用 ON_SENSOR_MANAGER.getOrCreate().on() 注册回调                 │
└─────────────────────────────────────────────────────────────────────────┘
    │
    │ 成功返回
    ▼
┌─────────────────────────────────────────────────────────────────────────┐
│ ffi.cj: FfiSensorSubscribeSensor() (foreign)                          │
│ 参数: sensorId, interval, callbackId                                   │
│ 转发到 C++ FFI 实现                                                   │
└─────────────────────────────────────────────────────────────────────────┘
    │
    │ IPC 调用
    ▼
┌─────────────────────────────────────────────────────────────────────────┐
│ sensor_service (SA)                                                     │
│ 1. 权限校验                                                           │
│ 2. 建立数据通道                                                       │
│ 3. 开始推送传感器数据                                                  │
└─────────────────────────────────────────────────────────────────────────┘
    │
    │ 数据推送
    ▼
┌─────────────────────────────────────────────────────────────────────────┐
│ cj_sensor_ffi (C++)                                                    │
│ 1. 接收传感器数据                                                      │
│ 2. 封装为 CSensorCallbackData                                         │
│ 3. 调用 dataCallbackImpl()                                            │
└─────────────────────────────────────────────────────────────────────────┘
    │
    │ 回调调用
    ▼
┌─────────────────────────────────────────────────────────────────────────┐
│ sensor_manager.cj: dataCallbackImpl()                                  │
│ 1. 解析 CSensorCallbackData.sensorTypeId                             │
│ 2. 调用 convertToResponseOption() 转换为 Response                     │
│ 3. 从 ON_SENSOR_MANAGER 获取回调列表                                  │
│ 4. 调用 emitSensorCallback()                                          │
│ 5. 从 ONCE_SENSOR_MANAGER 获取并消费回调                              │
└─────────────────────────────────────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────────────────────────────────────┐
│ sensor_manager.cj: emitOneSensorTypeCallbacks()                        │
│ 根据 sensorTypeId 分发到对应类型                                       │
└─────────────────────────────────────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────────────────────────────────────┐
│ 用户回调函数                                                           │
│ 例如: on(Accelerometer) { timestamp, response => ... }                │
└─────────────────────────────────────────────────────────────────────────┘
```

## A.3 传感器列表查询流程

### getSensorList() → FFI 查询 → 返回数组

```
用户代码
    │
    ▼
┌─────────────────────────────────────────────────────────────────────────┐
│ sensor.cj: getSensorList()                                            │
│ 1. 创建 CSensorArray 对象                                             │
│ 2. 调用 FfiSensorGetAllSensors()                                       │
│ 3. 检查返回值                                                         │
│ 4. 调用 result.asArray() 转换                                         │
│ 5. 调用 result.free() 释放内存                                         │
└─────────────────────────────────────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────────────────────────────────────┐
│ ffi.cj: FfiSensorGetAllSensors() (foreign)                            │
│ 参数: CPointer<CSensorArray>                                           │
│ 填充传感器数组数据                                                    │
└─────────────────────────────────────────────────────────────────────────┘
    │
    │ IPC 调用
    ▼
┌─────────────────────────────────────────────────────────────────────────┐
│ sensor_service (SA)                                                     │
│ 1. 查询所有可用传感器                                                  │
│ 2. 填充传感器信息                                                      │
└─────────────────────────────────────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────────────────────────────────────┐
│ sensor.cj: CSensorArray.asArray()                                      │

└─────────────────────────────────────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────────────────────────────────────┐
│ Array<Sensor>                                                          │
│ 返回给用户                                                            │
└─────────────────────────────────────────────────────────────────────────┘
```

## A.4 once() 特殊流程

### 单次订阅 → 数据返回 → 自动取消

```
once() 调用
    │
    ▼
┌─────────────────────────────────────────────────────────────────────────┐
│ sensor.cj: once<T>()                                                   │
│ 1. 调用 SensorManager.isMatchType() 验证                              │
│ 2. 调用 ON_SENSOR_MANAGER.isSensorSubscribed()                        │
│    ├─ 已订阅: 直接注册 once 回调，返回                              │
│    └─ 未订阅: 发起 FFI 订阅                                          │
└─────────────────────────────────────────────────────────────────────────┘
    │
    │ 数据返回时
    ▼
┌─────────────────────────────────────────────────────────────────────────┐
│ sensor_manager.cj: dataCallbackImpl()                                  │
│ 1. 从 ONCE_SENSOR_MANAGER.consume() 获取并移除回调                    │
│ 2. 调用 emitSensorCallback()                                           │
│ 3. 触发 once 回调                                                      │
└─────────────────────────────────────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────────────────────────────────────┐
│ sensor_manager.cj: dataCallbackImpl()                                  │
│ 1. 检查 ON_SENSOR_MANAGER 是否还有回调                                 │
│ 2. 如果为空，调用 FfiSensorUnSubscribeSensor() 取消订阅               │
└─────────────────────────────────────────────────────────────────────────┘
```
