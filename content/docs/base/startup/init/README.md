## 安全研究特别说明

本文档包含专门为安全研究员设计的内容：

- **攻击面分析**：`05_AttackSurface.md` 详细列出了 init 模块的所有外部输入入口、敏感操作和信任边界
- **风险评估**：`06_SecurityReview.md` 提供了 8 个具体风险点的深度分析，包含代码证据、触发路径和修复建议

5. 新增安全风险或修复现有风险
