# OpenHarmony 升级包制作工具 Wiki

> Packaging Tools 项目的完整技术文档，帮助新人快速理解项目架构、使用方法和安全考量。

## 文档覆盖范围

本文档涵盖 OpenHarmony 升级子系统中的 **packaging_tools** 组件，包括以下核心内容：

- **项目概览**：定位、边界、核心能力、运行环境
- **架构说明**：组件图、数据流、线程模型、关键时序
- **模块职责**：各 Python 模块的功能边界和依赖关系
- **使用说明**：命令行参数、使用示例、常见问题
- **安全评审**：攻击面分析、信任边界、风险识别

## 文档未覆盖范围

以下内容不在本文档范围内：

- **测试相关内容**：单元测试、集成测试、模糊测试等
- **第三方依赖**：bsdiff、imgdiff、e2fsdroid 等外部工具的详细文档
- **上游仓库**：升级子系统其他组件的详细文档
- **版本历史**：项目演进历程和迁移指南

## 文档更新方式

本文档随代码仓库一起维护。当以下情况发生时，应更新本文档：

1. **新增模块**：在 `modules/` 目录新增 Python 模块时
2. **接口变更**：命令行参数或 Python API 发生变化时
3. **架构调整**：模块间依赖或数据流向发生改变时
4. **安全发现**：发现新的安全风险或修复现有问题时

### 更新责任

| 变更类型 | 责任方 | 审核要求 |
|---------|-------|---------|
| 代码变更 | 代码作者 | 自测通过 |
| 文档更新 | 代码作者 | 团队审核 |
| 架构变更 | 架构师 | 技术评审 |
