### 1.2 各层职责

| 层级 | 模块 | 职责 | 关键组件 |
|------|------|------|---------|
| **Layer 5** | 应用层 | 业务逻辑实现 | ArkTS/JS/C++ 应用代码 |
| **Layer 4** | API 绑定层 | 多语言接口暴露 | NAPI, NDK, ANI, Cangjie |
| **Layer 3** | 通用组件层 | 跨层数据结构和生命周期管理 | nativecommon |
| **Layer 2** | 核心引擎层 | WebView 生命周期 + 平台服务抽象 | ohos_nweb, ohos_adapter |
| **Layer 1** | Chromium 引擎层 | Web 内容渲染 | ArkWebCore.hap |

## 2. 数据流

### 2.1 页面加载数据流

```
┌──────────┐     ┌──────────────────┐     ┌──────────────────┐
│  应用层   │────▶│ WebviewController │────▶│ NWebHelper       │
│ (ArkTS)  │     │ (NAPI 层)         │     │ (核心引擎)        │
└──────────┘     └──────────────────┘     └────────┬─────────┘
                                                   │
                                                   ▼
┌──────────┐     ┌──────────────────┐     ┌──────────────────┐
│  Surface  │◀────│ NWebSurfaceAdapter│◀────│ ArkWebCore       │
│ (显示)    │     │ (Surface 管理)     │     │ (Chromium 加载)  │
└──────────┘     └──────────────────┘     └──────────────────┘
```

**详细流程**:

1. **应用调用** `controller.loadUrl("https://example.com")`
   - 文件: `interfaces/kits/napi/webviewcontroller/napi_webview_controller.cpp:LoadUrl()`

2. **N-API 层** 解包参数并调用 C++ 实现
   ```cpp
   std::string url;
   NapiParseUtils::ParseString(env, argv[0], url);
   webviewController->LoadUrl(url, httpHeaders);
   ```

3. **nativecommon 层** 透传到核心引擎
   - 文件: `interfaces/kits/nativecommon/webview_controller.cpp`

4. **ohos_nweb 层** 调用 Chromium 引擎
   - 文件: `ohos_nweb/src/nweb_helper.cpp`
   - 通过 `NWeb` 接口调用实际加载

5. **Chromium 引擎** 处理网络请求并渲染
   - 网络请求 → 网络栈 → DNS → TCP → TLS → HTTP
   - HTML 解析 → DOM 构建 → CSS 计算 → 布局 → 绘制

6. **渲染结果** 通过 Surface 显示
   - GPU 进程合成画面
   - 通过 `NWebSurfaceAdapter` 输出到系统 Surface

### 2.2 JavaScript Bridge 数据流

```
┌──────────────────┐         ┌──────────────────┐
│  Web 页面 JS     │◀───────▶│  V8 引擎         │
│  window.bridge   │         │  (Renderer 进程) │
└────────┬─────────┘         └────────┬─────────┘
         │                            │
         │ 1. JS 调用                  │ 2. V8 拦截
         │    window.bridge.method()   │    自定义函数
         ▼                            ▼
┌──────────────────────────────────────────────────┐
│         Mojo IPC (Renderer → Browser)            │
└────────┬──────────────────────────┬──────────────┘
         │                          │
         ▼ 3. 反序列化               ▼ 4. 查找注册对象
┌──────────────────┐         ┌──────────────────┐
│ ohos_nweb        │────────▶│ NAPI 回调        │
│ (消息路由)        │         │ (主进程)         │
└────────┬─────────┘         └────────┬─────────┘
         │                            │
         ▼ 5. 调用应用回调             ▼ 6. 执行应用代码
┌──────────────────┐         ┌──────────────────┐
│ WebviewController │         │ 应用回调函数      │
│ (registeredProxy) │         │ (ArkTS/C++)      │
└──────────────────┘         └──────────────────┘
```

**关键代码路径**:
- JS Bridge 注册: `napi_webview_controller.cpp:RegisterJavaScriptProxy()`
- 消息通道: `WebMessagePort` / `PostMessage`

### 2.3 IPC 通信数据流 (SA 8610)

```
┌─────────────────────────────────────────────────────────────┐
│                    Web 应用 (Renderer)                      │
│              chrome.runtime.sendNativeMessage()              │
└─────────────────────────┬───────────────────────────────────┘
                          │ NAPI
                          ▼
┌─────────────────────────────────────────────────────────────┐
│              WebNativeMessagingClient (lib)                 │
│              ConnectWebNativeMessagingExtension()            │
└─────────────────────────┬───────────────────────────────────┘
                          │ IPC (Binder)
                          ▼
┌─────────────────────────────────────────────────────────────┐
│         WebNativeMessagingService (SA 8610)                 │
│  ┌──────────────────────────────────────────────────────┐  │
│  │ 1. 校验 AccessToken                                    │  │
│  │ 2. 查找/创建 ExtensionIpcConnection                    │  │
│  │ 3. ConnectAbility() → 启动 Extension                    │  │
│  └──────────────────────────────────────────────────────┘  │
└─────────────────────────┬───────────────────────────────────┘
                          │ Ability Connection
                          ▼
┌─────────────────────────────────────────────────────────────┐
│           Native Extension (UI Extension)                   │
│              (WebNativeMessagingExtension)                  │
│              处理消息并返回响应                              │
└─────────────────────────────────────────────────────────────┘
```

**安全控制点**:
1. **AccessToken 校验** - 验证调用者身份
2. **BundleName 白名单** - 只允许特定 Extension
3. **权限检查** - `ohos.permission.WEB_NATIVE_MESSAGING`

## 3. 线程模型

### 3.1 进程架构

```
┌─────────────────────────────────────────────────────────────┐
│                    应用进程 (App Process)                    │
│  ┌──────────────────────────────────────────────────────┐  │
│  │  ArkTS 业务代码                                       │  │
│  │  • 主线程 (UI 线程)                                    │  │
│  │  • WebView 组件渲染                                    │  │
│  │  • N-API 回调执行                                      │  │
│  └──────────────────────────────────────────────────────┘  │
│  ┌──────────────────────────────────────────────────────┐  │
│  │  ohos_nweb (libnweb.so)                              │  │
│  │  • 主线程: NWebHelper 管理                            │  │
│  │  • IO 线程: 配置加载                                   │  │
│  │  • 回调线程: Surface 更新                              │  │
│  └──────────────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────────────────┘
          │
          │ IPC (Mojo/Binder)
          ▼
┌─────────────────────────────────────────────────────────────┐
│                    WebView 进程 (WebView Process)            │
│  ┌──────────────┐ ┌──────────────┐ ┌──────────────┐        │
│  │ Renderer     │ │ GPU          │ │ Utility      │        │
│  │ 进程         │ │ 进程         │ │ 进程         │        │
│  │ • Blink 渲染 │ │ • 图形合成   │ │ • 网络请求   │        │
│  │ • V8 JS 引擎 │ │ • OpenGL/Vulkan│ • 数据库存储 │        │
│  └──────────────┘ └──────────────┘ └──────────────┘        │
└─────────────────────────────────────────────────────────────┘
```

### 3.2 线程职责

| 进程 | 线程 | 职责 |
|------|------|------|
| **App** | 主线程 (UI) | ArkUI 渲染、用户交互、N-API 回调 |
| **App** | NWeb 线程 | WebView 生命周期管理、配置加载 |
| **Renderer** | 主线程 | HTML/CSS/JS 执行、DOM 操作 |
| **Renderer** | 合成线程 | 页面绘制、图层合成 |
| **Renderer** | IO 线程 | 资源加载 (JS/CSS/图片) |
| **GPU** | GPU 主线程 | 图形命令执行、Surface 输出 |
| **Utility** | 网络线程 | HTTP/HTTPS 请求处理 |
| **Utility** | 存储线程 | Cookie/LocalStorage/IndexedDB |

```
                │       (SetBundlePath)
                │

                │       │
```

### 5.1 适配器交互模式

```
┌─────────────────────────────────────────────────────────────┐

│                    NWebHelper::Instance()                   │
└─────────────────────────┬───────────────────────────────────┘
                          │
              ┌───────────┼───────────┐
              │           │           │
              ▼           ▼           ▼
      ┌───────────┐ ┌───────────┐ ┌───────────┐
      │ Graphic   │ │ Audio     │ │ Location  │
      │ Adapter   │ │ Adapter   │ │ Adapter   │
      │ 接口调用   │ │ 接口调用   │ │ 接口调用   │
```

## 6. 信任边界

### 6.1 安全域划分

```
┌─────────────────────────────────────────────────────────────────────┐
│  🔴 不可信域 (Untrusted)                                            │
│  ┌─────────────────────────────────────────────────────────────┐   │
│  │  Web 内容 (任意第三方网页)                                     │   │
│  │  • 恶意 JavaScript                                          │   │
│  │  • 钓鱼页面                                                  │   │
│  │  • 跨站脚本 (XSS)                                           │   │
│  └─────────────────────────────────────────────────────────────┘   │
└───────────────────────────┬─────────────────────────────────────────┘
                            │ ① Chromium 沙箱
                            ▼
┌─────────────────────────────────────────────────────────────────────┐
│  🟡 受限域 (Restricted)                                             │
│  ┌─────────────────────────────────────────────────────────────┐   │
│  │  Renderer 进程 (Chromium 沙箱内)                              │   │
│  │  • 只能访问沙箱内资源                                         │   │
│  │  • 无法直接访问系统服务                                        │   │
│  │  • 通过 IPC 与 Browser 进程通信                                │   │
│  └─────────────────────────────────────────────────────────────┘   │
└───────────────────────────┬─────────────────────────────────────────┘
                            │ ② Mojo IPC + Capability
                            ▼
┌─────────────────────────────────────────────────────────────────────┐
│  🟢 可信域 (Trusted)                                                │
│  ┌─────────────────────────────────────────────────────────────┐   │
│  │  Browser 进程 + ohos_nweb (libnweb.so)                       │   │
│  │  • 可以访问 ohos_adapter                                      │   │
│  │  • 可以调用系统服务                                           │   │
│  │  • 受 AccessToken 权限控制                                    │   │
│  └─────────────────────────────────────────────────────────────┘   │
└───────────────────────────┬─────────────────────────────────────────┘
                            │ ③ N-API / NDK
                            ▼
┌─────────────────────────────────────────────────────────────────────┐
│  🔵 应用域 (Application)                                            │
│  ┌─────────────────────────────────────────────────────────────┐   │
│  │  应用代码 (ArkTS/C++)                                        │   │
│  │  • 业务逻辑实现                                              │   │
│  │  • 通过 WebviewController 控制 WebView                       │   │
│  └─────────────────────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────────────────────┘
```

### 6.2 边界防护机制

| 边界 | 防护机制 | 攻击面 |
|------|---------|--------|
| ① Web ↔ Renderer | Chromium 沙箱 + Site Isolation | 沙箱逃逸 |
| ② Renderer ↔ Browser | Mojo IPC (Capability-based) | IPC 劫持 |
| ③ Browser ↔ App | N-API 类型检查 + 权限校验 | API 滥用 |
