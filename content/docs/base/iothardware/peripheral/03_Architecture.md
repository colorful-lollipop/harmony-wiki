## 模块职责

### 接口定义层 (interfaces/inner_api/)

**职责**:
- 定义标准 C 接口规范
- 提供数据类型和枚举定义
- 声明函数原型（不包含实现）

**特点**:
- 纯头文件，无 .c 实现
- 跨平台兼容
- 版本化管理（当前 v2.2）

### HAL 实现层 (hals/iot_hardware/wifiiot_lite)

**职责**:
- 实现接口定义层的所有函数
- 对接 Hi3861 芯片硬件
- 提供芯片特定的优化

**依赖**:
- Hi3861 SDK
- 芯片寄存器定义

```
┌─────────────────────────────────────────────────────────────┐
│  LiteOS-M 任务模型                                          │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│   main() 任务                                               │
│      │                                                      │
│      ├── IoTGpioInit()  ──► 同步执行                       │
│      ├── IoTI2cInit()   ──► 同步执行                       │
│      ├── IoTUartInit()  ──► 同步执行                       │
│      │                                                      │
│      ├── IoTGpioRegisterIsrFunc()  ──► 中断回调注册         │
│      │                                                      │
│      └── 主循环                                             │
│               │                                             │
│               ├── 数据处理                                  │
│               ├── IoTWatchDogKick()                         │
│               └── GPIO 中断回调 (异步触发)                   │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 中断处理

**GPIO 中断模型**:

```
┌─────────────────────────────────────────────────────────────┐
│  GPIO 中断处理流程                                          │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  1. 注册中断回调                                            │
│     IoTGpioRegisterIsrFunc(id, type, polarity, callback, arg)│
│                    │                                        │
│                    ▼                                        │
│  2. 硬件触发中断                                            │
│     (边沿/电平变化)                                          │
│                    │                                        │
│                    ▼                                        │
│  3. CPU 响应中断                                            │
│     保存上下文，调用 ISR                                     │
│                    │                                        │
│                    ▼                                        │
│  4. 执行回调函数                                            │
│     GpioIsrCallbackFunc(arg)                                │
│                    │                                        │
│                    ▼                                        │
│  5. 中断返回                                                │
│     恢复上下文，继续主程序                                    │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

                    ┌───────────────┐

            ┌───────────────┼───────────────┐
            │               │               │
            ▼               ▼               ▼

## 稳定性评估
