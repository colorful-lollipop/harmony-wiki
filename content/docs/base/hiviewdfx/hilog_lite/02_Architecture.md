# Hilog Lite 架构设计

## 整体架构

Hilog_lite 采用分层架构设计，核心层与系统无关，上层通过适配层支持不同的系统类型。

```
┌─────────────────────────────────────────────────────────────────┐
│                      Application Layer                          │
│  ┌─────────────┐  ┌─────────────┐  ┌─────────────────────────┐ │
│  │ C/C++ App   │  │ JS App      │  │ Shell Command (hilogcat)│ │
│  └──────┬──────┘  └──────┬──────┘  └───────────┬─────────────┘ │
└─────────┼────────────────┼──────────────────────┼──────────────┘
          │                │                      │
          ▼                ▼                      ▼
┌─────────────────────────────────────────────────────────────────┐
│                      API Layer (Kits)                           │
│  ┌─────────────────────────────────────────────────────────────┐ │
│  │  C API (hilog/log.h, hilog_lite/log.h)                    │ │
│  │  JS Binding (frameworks/js/builtin/)                      │ │
│  └─────────────────────────────────────────────────────────────┘ │
└─────────────────────────────────────────────────────────────────┘
                                  │
                                  ▼
┌─────────────────────────────────────────────────────────────────┐
│                   Framework Layer                               │
│  ┌─────────────────────┐  ┌───────────────────────────────────┐ │
│  │ Mini System        │  │ Small System (Featured)          │ │
│  │ (frameworks/mini/) │  │ (frameworks/featured/)           │ │
│  │  - hiview_log.c    │  │  - hiview_log.c                  │ │
│  │  - hiview_output_* │  │  - hilog.cpp (C++ wrapper)       │ │
│  │  - hiview_log_limit│  │  - HiLog class                   │ │
│  └─────────────────────┘  └───────────────────────────────────┘ │
└─────────────────────────────────────────────────────────────────┘
                                  │
                                  ▼
┌─────────────────────────────────────────────────────────────────┐
│                    Service Layer                                │
│  ┌─────────────────────┐  ┌───────────────────────────────────┐ │
│  │ hilogcat            │  │ apphilogcat                       │ │
│  │ (日志查看工具)      │  │ (应用日志落盘)                    │ │
│  └─────────────────────┘  └───────────────────────────────────┘ │
└─────────────────────────────────────────────────────────────────┘
                                  │
                    ┌─────────────┴─────────────┐
                    ▼                           ▼
┌─────────────────────────┐     ┌───────────────────────────────┐
│   Kernel Driver         │     │   UART/Console               │
│   (ioctl interface)     │     │   (串口输出)                  │
└─────────────────────────┘     └───────────────────────────────┘
```

## 组件职责

### 框架层组件

| 组件 | 路径 | 职责 |
|------|------|------|
| **Mini System** | `frameworks/mini/` | 轻量系统日志实现，标准 C 编写 |
| **Featured System** | `frameworks/featured/` | 小型系统日志实现，支持 C/C++ |
| **JS Binding** | `frameworks/js/` | JS/ACE Lite 应用的日志绑定 |

### 服务层组件

| 组件 | 路径 | 职责 |
|------|------|------|
| **hilogcat** | `services/hilogcat/` | 命令行日志查看工具 |
| **apphilogcat** | `services/apphilogcat/` | 应用日志持久化落盘服务 |

## 数据流

### 日志输出数据流

```
┌──────────┐     ┌──────────┐     ┌──────────┐     ┌──────────┐
│ Application│────▶│ API      │────▶│ Framework│────▶│ Output   │
│           │     │ (log.h)  │     │ Layer    │     │ Driver   │
└──────────┘     └──────────┘     └──────────┘     └────┬─────┘
                                                       │
                          ┌────────────────────────────┘
                          ▼
                   ┌─────────────┐
                   │ Kernel Ring │
                   │   Buffer    │
                   └──────┬──────┘
                          │
            ┌─────────────┼─────────────┐
            ▼             ▼             ▼
     ┌──────────┐  ┌──────────┐  ┌──────────┐
     │ hilogcat │  │apphilogcat│  │ Console  │
     │(查看工具)│  │  (落盘)   │  │ (串口)   │
     └──────────┘  └──────────┘  └──────────┘
```

### 关键数据流说明

1. **应用层 → 框架层**
   - 调用 `HILOG_*` 宏或 `HiLogPrint()` API
   - 参数校验（模块 ID、级别、格式字符串）
   - 日志内容格式化

2. **框架层 → 驱动层**
   - 通过 ioctl 调用写入内核驱动
   - 日志内容发送到 hilogtask 内核任务

3. **内核任务处理**
   - 存储到环形缓冲区（Ring Buffer）
   - 支持日志级别过滤

4. **服务消费**
   - hilogcat: 实时读取并输出到 stdout
   - apphilogcat: 定时读取并落盘到文件

## 线程模型

### 轻量系统线程模型

```
┌─────────────────────────────────────────────────────────────┐
│                      hilogtask (内核线程)                    │
│                                                              │
│   ┌─────────────────────────────────────────────────────┐   │
│   │                   Ring Buffer                      │   │
│   │    (可配置大小，默认值取决于 hilog_lite_file_size)  │   │
│   └─────────────────────────────────────────────────────┘   │
│          ▲                              │                  │
│          │                              ▼                  │
│   ┌─────────────┐             ┌───────────────────┐      │
│   │ Kernel Mode  │             │ User Mode         │      │
│   │ (驱动写入)   │             │ hilogcat/apphilogcat│    │
│   └─────────────┘             └───────────────────┘      │
└─────────────────────────────────────────────────────────────┘
```

### 线程安全机制

| 机制 | 实现位置 | 描述 |
|------|----------|------|
| 环形缓冲区 | 内核驱动 | 线程安全的日志存储 |
| 互斥保护 | `g_hiviewConfig` | 配置访问保护 |
| 原子操作 | `atomic_int` | 计数器原子操作 |

> 证据来源: frameworks/featured/hiview_log.c:42 (`atomic_int g_hiLogGetIdCallCount`)

## 日志格式

### 小型系统日志格式

```
MM-DD HH:MM:SS.mmm PID TID W 00201/MY_TAG: message
|    |         |    | | | | |    |       |
|    |         |    | | | | |    |       └── 消息内容
|    |         |    | | | | |    └── 标签
|    |         |    | | | | └── 级别 (W= WARN)
|    |         |    | | | └── PID
|    |         |    | | └── TID
|    |         |    | └── 毫秒
|    |         |    └── 秒
|    |         └── 分钟
|    └── 月份
└── 日期

示例:
05-06 15:01:06.870 1051 1051 W 00201/MY_TAG: Failed to visit <private>, reason:503.
```

> 证据来源: log.h:56-57

### 轻量系统日志格式

```
<private> / <public> 参数替换:
- %{private}d -> <private> (隐私参数)
- %{public}d -> 显示实际值

示例:
HILOG_INFO(HILOG_MODULE_APP, "Age is %{private}d", 10);
输出: Age is <private>
```

## 隐私保护机制

### 隐私标识

| 标识 | 作用 | 默认行为 |
|------|------|----------|
| `%{public}` | 公开参数 | 显示实际值 |
| `%{private}` | 隐私参数 | 显示 `<private>` |

### 使用示例

```c
// 小型系统
HILOG_INFO(LOG_APP, "Name: %{public}s, Password: %{private}s", name, password);
// 输出: Name: Alice, Password: <private>

// 参数默认行为
HILOG_INFO(LOG_APP, "Age is %d", 10);
// 输出: Age is <private>
```

> 证据来源: log.h:174-182

## 限流机制

### 限流配置

| 配置项 | 描述 | 默认值 |
|--------|------|--------|
| `hilog_lite_limit_level_default` | 默认限流级别 | 30 |
| `hilog_lite_disable_print_limit` | 禁用打印限流 | false |

### 限流检查点

```c
// hiview_log.c:69-77
static boolean CheckParameters(uint8 module, uint8 level)
{
    if ((level < g_hiviewConfig.level) || (level < HILOG_COMPILE_LEVEL) ||
        (module >= HILOG_MODULE_MAX) || (g_logModuleInfo[module].name == NULL)) {
        return FALSE;
    }
    return TRUE;
}
```

> 证据来源: hiview_log.c:69-77
