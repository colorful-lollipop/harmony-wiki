### 插件线程策略

| 插件类型 | 线程模型 | 说明 |
|----------|----------|------|
| 事件源插件 | 事件触发 | 被动接收系统事件 |
| 采集器插件 | 工作线程 | 独立线程采集性能数据 |
| 检测器插件 | 主线程/Worker | 在 Pipeline 中处理事件 |
| 存储插件 | 异步IO | 后台持久化 |

## 稳定性标注

### 稳定接口

| 接口类型 | 位置 | 稳定性 |
|----------|------|--------|
| N-API | `plugins/faultlogger/interfaces/js/napi/` | 稳定（官方 API） |
| Inner API (C++) | `plugins/faultlogger/interfaces/cpp/innerkits/` | 稳定 |
| System Ability | `adapter/service/server/` | 稳定 |
| N-API (日志库) | `interfaces/js/napi/` | 稳定（系统应用可用） |

### 不稳定接口

| 接口类型 | 位置 | 稳定性 |
|----------|------|--------|
| 插件接口 | `base/include/plugin.h` | 内部接口 |
| 统一采集器 | `framework/native/unified_collection/` | 内部框架 |
| 配置接口 | `core/bundle_config/` | 内部接口 |

> 注：稳定性基于接口位置和用途推断，具体稳定性等级需查看代码中的 `LIBHIVE_API` 等宏定义
