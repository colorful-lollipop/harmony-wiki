# HiDumper Wiki 文档

> **OpenHarmony DFX 子系统 - 统一系统信息收集工具**

## 文档覆盖范围

本文档为 OpenHarmony DFX 子系统 HiDumper 组件的工程文档，面向两类核心受众：

| 受众 | 文档需求 | 推荐路线 |
|------|---------|----------|
| **新人学习者** | 快速理解项目定位、架构、使用方法 | [新人学习路线](#新人学习路线) |
| **安全研究员** | 识别攻击面、信任边界、潜在漏洞 | [安全研究路线](#安全研究路线) |

### 覆盖内容

- 项目定位与核心能力
- 系统架构与组件关系
- Native API 接口说明（**注意：HiDumper 无 N-API**）
- 攻击面分析与信任边界
- 安全风险评估与修复建议
- GN 构建系统与编译产物
- 常见问题与调试指南

| **利用评估** | 评估可利用性和影响 | [安全风险评估](./06_SecurityReview.md) | 风险等级、触发路径、修复建议 |

## 更新方式

当代码发生以下变更时，需同步更新 Wiki：

| 变更类型 | 更新章节 | 触发条件 |
|---------|---------|---------|
| 新增/删除模块 | 架构图、API Reference、代码地图 | 新增 `.cpp`/`.h` 文件 |
| 修改 IPC 接口 | API Reference、架构、攻击面 | 修改 IDL 或 Stub/Proxy |
| 新增 GN target | 构建系统 | 修改 `BUILD.gn` |
| 安全相关修改 | 安全评审、攻击面 | 新增权限校验或修复漏洞 |
