### 6.2 动态库加载流程

```cpp
// memory_dumper.cpp:98
void* handle = dlopen(MEM_LIB.c_str(), RTLD_LAZY | RTLD_NODELETE);
if (handle == nullptr) {
    DUMPER_HILOGE(MODULE_COMMON, "dlopen %{public}s failed", MEM_LIB.c_str());
    return;
}
```

**风险分析**:
- 库路径硬编码，不可直接注入
- 但库文件本身可能被替换（若攻击者有系统权限）
- 使用 `RTLD_NODELETE` 标志，库不会被卸载

## 8. 攻击向量总结

### 8.1 攻击向量清单

| 向量 | 前置条件 | 攻击难度 | 潜在影响 | 优先级 |
|------|---------|---------|---------|--------|
| **CLI 参数注入** | 本地访问 | 低 | DoS/信息泄露 | P1 |
| **IPC 参数注入** | 已授权应用 | 中 | 权限提升 | P2 |
| **命令注入** | 配置篡改 | 高 | 代码执行 | **P0** |
| **路径遍历** | 本地访问 | 中 | 文件读取 | P1 |
| **FD 耗尽** | 无限制调用 | 低 | DoS | P2 |
| **配置注入** | 配置目录写权限 | 高 | 行为篡改 | P2 |

### 8.2 信任边界跨越点

| 跨越点 | 源区域 | 目标区域 | 安全控制 |
|--------|--------|---------|---------|
| CLI 参数 | 不可信 | 边界 | 长度/数量检查 |
| IPC 调用 | 不可信 | 边界 | Binder 机制 |
| 权限验证 | 边界 | 受信任 | `ohos.permission.DUMP` |
| 文件读取 | 受信任 | 内核 | 路径规范化 |
| 命令执行 | 受信任 | 内核 | 前缀限制 |
