## 风险点分析

### 风险 1: SurfaceId 参数解析整数溢出

| 属性 | 值 |
|------|------|
| **编号** | SEC-001 |
| **严重性** | 中 |
| **证据** | `face_auth_napi.cpp:136-138` |
| **触发条件** | 超长字符串/特殊格式 |
| **影响** | 解析失败，DoS |

**代码位置**:

```cpp
// face_auth_napi.cpp:136-138
std::istringstream surfaceIdStream(strSurfaceId);
uint64_t surfaceId;
surfaceIdStream >> surfaceId;
```

**风险描述**:
- 使用 `std::istringstream` 解析用户输入
- 未检查解析是否成功
- 特殊格式可能导致意外行为

**修复建议**:
```cpp
uint64_t surfaceId = 0;
if (!(surfaceIdStream >> surfaceId) || !surfaceIdStream.eof()) {
    IAM_LOGE("Invalid surfaceId format");
    napi_throw(env, GenerateBusinessError(env, RESULT_CODE_FAIL));
    return nullptr;
}
```

### 风险 2: 权限检查后未释放锁

| 属性 | 值 |
|------|------|
| **编号** | SEC-002 |
| **严重性** | 低 |
| **证据** | `face_auth_client_impl.cpp` |
| **触发条件** | 多线程并发调用 |
| **影响** | 资源竞争/死锁 |

**修复建议**: 确保所有代码路径正确释放互斥锁

---

### 风险 3: IBufferProducer 空指针传递

| 属性 | 值 |
|------|------|
| **编号** | SEC-003 |
| **严重性** | 中 |
| **证据** | `face_auth_napi.cpp:84-112` |
| **触发条件** | SurfaceId 为 0 |
| **影响** | 空指针传递到 IPC |

**代码位置**:

```cpp
bool GetBufferProducerBySurfaceId(uint64_t surfaceId, sptr<IBufferProducer> &bufferProducer)
{
    if (surfaceId == 0) {
        IAM_LOGI("surface id is 0, get buffer producer null");
        bufferProducer = nullptr;  // 空指针
        return true;              // 允许空值通过
    }
    // ...
    bufferProducer = previewSurface->GetProducer();
    // ...
}
```

**修复建议**: 明确空指针是否合法，如不合法则拒绝

### 风险 4: IPC 接口令牌验证

| 属性 | 值 |

| **严重性** | 低 |
| **证据** | `face_auth_proxy.cpp`, `face_auth_stub.cpp` |
| **保护机制** | 已实现 |

**现有保护**:

```cpp
// Proxy: 写入接口令牌
data.WriteInterfaceToken(FaceAuthProxy::GetDescriptor());

if (data.ReadInterfaceToken() != FaceAuthStub::GetDescriptor()) {
    return FACE_AUTH_ERROR;
}
```

## 已有的安全加固

### 编译器安全加固

| 特性 | 作用 |
|------|------|
| `integer_overflow` | 检测整数溢出 |
| `ubsan` | 未定义行为检测 |
| `boundary_sanitize` | 边界检查 |
| `cfi` | 控制流完整性 |
| `cfi_cross_dso` | 跨 DSO CFI 检查 |
| `pac_ret` | PACRET 返回地址保护 |
