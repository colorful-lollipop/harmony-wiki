# 项目概览

## 项目定位

**Face Authentication (face_auth)** 是 OpenHarmony 用户身份认证框架的一部分，提供人脸生物特征认证能力。

### 核心职责

```
┌─────────────────────────────────────────────────────────────┐
│                     face_auth 核心职责                       │
├─────────────────────────────────────────────────────────────┤
│  1. 人脸凭证管理：Enrollment (录入)、Deletion (删除)        │
│  2. 人脸认证：Authentication (身份验证)                      │
│  3. 协作框架集成：与 UserAuth Framework 交互                │
│  4. 设备厂商适配：HDI 接口适配层                            │
└─────────────────────────────────────────────────────────────┘
```

## 系统定位

```
┌─────────────────────────────────────────────────────────────┐
│                     OpenHarmony 系统层                       │
├─────────────────────────────────────────────────────────────┤
│  应用层                                                       │
│    ├── SystemUI (设置 -> 人脸录入/删除)                       │
│    └── 用户应用 (调用生物认证 API)                            │
├─────────────────────────────────────────────────────────────┤
│  框架层                                                       │
│    ├── useriam_user_auth_framework (协作认证框架)            │
│    ├── face_auth (人脸认证执行器) ← 本项目                    │
│    └── pin_auth (PIN 码认证)                                  │
├─────────────────────────────────────────────────────────────┤
│  硬件抽象层 (HDI)                                             │
│    └── 设备厂商实现 (TEE/安全芯片)                            │
└─────────────────────────────────────────────────────────────┘
```

## 核心能力

| 能力 | 说明 | API 入口 |
|------|------|----------|
| 人脸录入 | 采集用户人脸特征并存储 | FaceAuthManager |
| 人脸删除 | 删除已录入的人脸凭证 | UserAuth Framework |
| 人脸认证 | 验证用户人脸 | UserAuth Framework |
| 预览设置 | 设置人脸录入时的预览画面 | setSurfaceId |

## 运行环境

### 依赖组件

| 组件 | 用途 | 来源 |
|------|------|------|
| user_auth_framework | 协作认证框架 | useriam子系统 |
| drivers_interface_face_auth | HDI 接口定义 | drivers子系统 |
| ipc | 进程间通信 | samgr子系统 |
| napi | JS/TS 接口绑定 | aafwk子系统 |
| safwk | System Ability 框架 | samgr子系统 |

### 系统能力

```json
// bundle.json
"syscap": ["SystemCapability.UserIAM.UserAuth.FaceAuth"]
```

### 开关特性

```gn
// face_auth.gni
face_auth_enabled = true  // 模块总开关
```

## 关键概念

### 凭证与模板

- **Face Credential**: 用户人脸特征数据
- **Template**: 人脸特征模板（存储在 TEE 安全区域）

### 安全机制

| 机制 | 说明 |
|------|------|
| 权限控制 | 高危 API 仅系统应用可调用 |
| TEE 存储 | 人脸数据存储在可信执行环境 |
| HDI 隔离 | 敏感操作通过 HDI 调用设备厂商实现 |

### 调用模式

```
┌─────────────────────────────────────────┐
│           调用模式                        │
├─────────────────────────────────────────┤
│  同步调用：setSurfaceId (N-API → IPC)     │
│  异步回调：认证结果 (HDI → Framework)      │
└─────────────────────────────────────────┘
```
