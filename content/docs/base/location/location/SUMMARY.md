# 导航与阅读顺序

本文档为 OpenHarmony 位置服务组件的工程 Wiki，提供双路线导航以满足不同受众的需求。

---

## 🎯 双路线导航

### 路线一：新人快速入门

适合：新接触OpenHarmony位置服务的开发者、应用开发者

**阅读路径**:

1. **第一步：了解项目概览** (5分钟)
   - [📄 项目概览](index.md) - 项目定位、核心能力、关键概念

2. **第二步：理解系统架构** (15分钟)
   - [🏗️ 系统架构](01_Architecture.md) - 组件图、数据流、线程模型、时序图

3. **第三步：选择并学习API** (30分钟)
   - Native应用开发者 → [🔧 C/N-API 接口](02_C_NAPI.md)
   - JS/ETS应用开发者 → [📱 JS API 接口](03_JS_API.md)

4. **第四步：了解内部实现** (可选，30分钟)
   - [🔌 内部 API](04_Inner_API.md) - 模块接口、依赖关系

**总预计时间**: 1-2小时可掌握基本使用

---

### 路线二：安全研究路线

适合：安全研究员、渗透测试人员、安全架构师

**阅读路径**:

1. **第一步：项目概览与架构理解** (20分钟)
   - [📄 项目概览](index.md) - 了解项目定位和关键概念
   - [🏗️ 系统架构](01_Architecture.md) - 理解组件关系和数据流

2. **第二步：攻击面识别** (30分钟) ⭐ **核心**
   - [🎯 攻击面分析](05_AttackSurface.md) - 外部输入清单、敏感操作、信任边界

3. **第三步：深度安全分析** (1小时) ⭐ **核心**
   - [🔒 安全风险评审](07_SecurityReview.md) - 详细风险分析、利用路径、修复建议

**总预计时间**: 2-3小时完成安全评估
