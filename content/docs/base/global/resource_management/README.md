# Resource Management 组件 Wiki

## 文档覆盖范围

本文档集覆盖 OpenHarmony 资源管理组件 (global_resmgr_standard) 的完整技术文档，包括：

- **项目概述**: 组件定位、边界、核心能力、运行环境、关键概念
- **架构设计**: 目录结构、模块职责、组件图、数据流、线程模型、关键时序
- **接口文档**:
  - N-API (JavaScript Native API) - 65 个导出方法的完整清单
  - Inner API - 内部子系统接口
  - Native API - C 语言原生接口
- **构建系统**: GN targets、编译产物、依赖关系、平台适配
- **安全评审**: 攻击面分析、信任边界、可被利用点、修复建议
- **常见问题**: 构建、运行、调试问题与定位路径

## 文档适用人群

- **开发者**: 需要使用资源管理 API 开发应用的开发人员
- **系统开发者**: 需要理解资源管理组件架构和实现的系统开发人员
- **安全审计人员**: 需要评估资源管理组件安全性的审计人员
- **新人**: 初次接触 OpenHarmony 资源管理的学习者

本文档基于代码库自动生成和更新。

**更新时机**:
- 组件架构发生重大变更时
- 新增或删除重要的 API 时

1. 代码变更后，运行 Wiki 生成脚本

3. 补充必要的说明和示例
