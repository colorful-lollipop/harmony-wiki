# 常见问题与定位路径

## 目的

本文档总结 ASSET 服务的常见构建、运行、调试问题，并提供定位路径。

## 适用范围

- 涵盖内容：构建错误、运行时错误、调试方法
- 目标读者：开发者、集成工程师

---

## 构建问题

### 1. Rust 编译错误

#### 错误：`use of undeclared crate`

**原因**：Cargo.toml 中缺少依赖声明

**解决**：
```toml
# Cargo.toml
[dependencies]
# 添加缺失的 crate
serde = { version = "1.0", features = ["derive"] }
```

**证据**：`Cargo.toml`

#### 错误：`failed to resolve asset_definition`

**原因**：循环依赖或路径错误

**解决**：
1. 检查 BUILD.gn 依赖关系
2. 确保没有环依赖

**证据**：`services/core_service/BUILD.gn:18-35`

### 2. C/C++ 编译错误

#### 错误：`undefined reference to 'AssetAdd'`

**原因**：C 代码未包含正确的头文件

**解决**：
```c
// 确保包含正确的头文件
#include "asset_system_api.h"
#include "asset_system_type.h"
```

**证据**：`frameworks/c/system_api/src/asset_system_api.c:19-22`

#### 错误：`argument of type 'napi_env' is incompatible`

**原因**：N-API 函数签名错误

**解决**：
```cpp
// 检查 N-API 文档
napi_value NapiAdd(napi_env env, napi_callback_info info);
```

**证据**：`frameworks/js/napi/src/asset_napi_add.cpp:109`

### 3. GN 构建错误

#### 错误：`unknown target "asset_napi"`

**原因**：BUILD.gn 中 target 名称拼写错误

**解决**：
1. 检查 target 名称拼写
2. 确认 `support_jsapi` 为 true（对于 asset_napi）

**证据**：`BUILD.gn:26-28`

#### 错误：`dependency not found: asset_definition`

**原因**：依赖路径错误或 target 名称错误

**解决**：
```gn
# 使用绝对路径或正确的相对路径
deps = [
    "//base/security/asset/frameworks/definition:asset_definition",
]
```

**证据**：`services/core_service/BUILD.gn:18-35`

## 运行时问题

### 1. 服务无法启动

#### 症状：Asset Service (SA:8100) 未启动

**定位步骤**：
```bash
# 1. 检查 SA 是否注册
hdc shell sm dump | grep "asset_service"

# 2. 检查服务进程
hdc shell ps -A | grep asset_service

# 3. 检查服务日志
hdc shell hilog -x Asset | grep "on_start"
```

**常见原因**：
1. **HUKS 服务未启动**：检查 HUKS SA (3501) 状态
2. **SQLite 库缺失**：检查 libsqlite3.z.so 是否存在
3. **配置错误**：检查 `8100.json` 和 `asset_service.cfg`
4. **权限不足**：检查 `asset_service.cfg` 中的 SELinux 上下文

**证据**：`sa_profile/8100.json`、`etc/init/asset_service.cfg`

### 2. API 调用失败

#### 症状：应用调用 `OH_Asset_Add` 返回错误码 24000001（SERVICE_UNAVAILABLE）

**定位步骤**：
```bash
# 1. 检查服务状态
hdc shell sm dump | grep "8100"

# 2. 检查服务日志
hdc shell hilog -x Asset | tail -50

# 3. 重启服务（如果需要）
hdc shell sa reset 8100
```

**常见原因**：
1. **服务崩溃**：检查崩溃日志
2. **IPC 通信失败**：检查网络、IPC 框架
3. **资源耗尽**：检查内存、磁盘空间

**证据**：`services/core_service/src/lib.rs:16-100`（on_start_with_reason）

### 3. 加密操作失败

#### 症状：`EncryptData` / `DecryptData` 返回 24000009（CRYPTO_ERROR）

**定位步骤**：
```bash
# 1. 检查 HUKS 日志
hdc shell hilog -x HUKS | tail -50

# 2. 检查 HUKS 服务状态
hdc shell sm dump | grep "3501"
```

**常见原因**：
1. **密钥不存在**：检查密钥是否已删除
2. **算法不支持**：确认设备支持 AES-256-GCM
3. **认证失败**：检查用户认证状态

**证据**：`services/crypto_manager/src/huks_wrapper.c:5-100`

### 4. 数据库错误

#### 症状：`Insert` / `Query` 返回 24000008（DATABASE_ERROR）

**定位步骤**：
```bash
# 1. 检查数据库文件权限
hdc shell ls -l /data/service/el2/user_*

# 2. 检查数据库文件完整性
hdc shell sqlite3 /data/service/el2/user_*/asset.db "PRAGMA integrity_check"

# 3. 检查数据库大小
hdc shell du -sh /data/service/el2/user_*
```

**常见原因**：
1. **磁盘空间不足**：检查存储空间
2. **文件损坏**：数据库文件损坏
3. **权限错误**：无法写入数据库目录
4. **数据库锁定**：其他进程持有锁

**证据**：`services/db_operator/src/database.rs`

### 5. 权限拒绝

#### 症状：`CheckSystemHapPermission` 失败，返回 201（PERMISSION_DENIED）

**定位步骤**：
```bash
# 1. 检查应用权限配置
hdc shell bm dump --package-name <bundle_name> | grep permission

# 2. 检查应用类型
hdc shell bm dump --package-name <bundle_name> | grep type

# 3. 检查 AccessToken 状态
hdc shell hilog -x AccessToken | tail -30
```

**常见原因**：
1. **缺少权限**：应用未在 manifest.json 中声明必需权限
2. **非系统应用**：尝试调用 AsUser API 但不是系统应用
3. **Token ID 无效**：AccessToken 服务问题

**证据**：`services/db_operator/src/common/permission_check.rs:23-41`

## 调试方法

### 1. 日志系统

#### Hisysevent

**配置文件**：`hisysevent.yaml`

**事件类型**：
- `SECRET_STORE_INFO_COLLECTION`：统计事件（正常操作）
- `SECRET_STORE_OPERATION_FAILED`：故障事件（失败操作）

**查看日志**：
```bash
# 查看统计事件
hdc shell hilog -x Asset | grep SECRET_STORE_INFO_COLLECTION

# 查看故障事件
hdc shell hilog -x Asset | grep SECRET_STORE_OPERATION_FAILED
```

**证据**：`hisysevent.yaml`

#### Hilog

**日志级别**：
- `DEBUG`：详细调试信息
- `INFO`：常规信息
- `WARN`：警告信息
- `ERROR`：错误信息
- `FATAL`：致命错误

**查看日志**：
```bash
# 查看 Asset 服务日志
hdc shell hilog -x Asset | tail -100

# 查看 Crypto 模块日志
hdc shell hilog -x Asset | grep "Crypto"

# 查看 Database 模块日志
hdc shell hilog -x Asset | grep "DB"
```

**证据**：`frameworks/os_dependency/log/src/lib.rs`

### 2. 性能追踪

#### Hitrace

**启用追踪**：
```bash
# 编译时启用 HITRACE
export HITRACE_TAG=true

# 运行时追踪
hdc shell hitrace --tags Asset --time 30 <command>
```

**证据**：`services/core_service/src/trace_scope.rs`

### 3. 数据库调试

#### SQLite 调试

**查看数据库内容**：
```bash
# 连接到数据库
hdc shell sqlite3 /data/service/el2/user_*/asset.db

# 查看表结构
.tables

# 查看特定表结构
.schema assets

# 查询数据
SELECT * FROM assets WHERE user_id = 100;
```

**数据库迁移**：
```bash
# 检查数据库版本
PRAGMA user_version;

# 手动执行迁移（如果需要）
-- 详见 upgrade_operator.rs
```

**证据**：`services/db_operator/src/upgrade_operator.rs`

### 4. IPC 调试

#### Hdc shell 调试

**检查 SA 状态**：
```bash
hdc shell sm dump | grep asset_service
```

**发送 IPC 测试请求**：
```bash
# 需要专门的测试工具或修改代码添加测试端点
```

**证据**：`frameworks/ipc/src/lib.rs`

## 错误码参考

### 通用错误码

| 错误码 | 十六进制 | 描述 | 常见原因 |
|---------|---------|------|---------|
| 0 | 0x00000000 | SUCCESS | 操作成功 |
| 401 | 0x00000191 | INVALID_ARGUMENT | 参数错误 |
| 201 | 0x000000C9 | PERMISSION_DENIED | 权限拒绝 |
| 24000001 | 0x016EA601 | SERVICE_UNAVAILABLE | 服务不可用 |
| 24000002 | 0x016EA602 | NOT_FOUND | 资产不存在 |
| 24000004 | 0x016EA604 | ACCESS_DENIED | 访问被拒绝 |
| 24000009 | 0x016EA609 | CRYPTO_ERROR | 加密错误 |
| 24000008 | 0x016EA608 | DATABASE_ERROR | 数据库错误 |

**证据**：`interfaces/kits/c/inc/asset_type.h:175-257`

## 开发建议

### 1. 本地测试

**启用本地测试**：
```bash
# 编译时启用测试标志
./build.sh --product-name rk3568 --build-target asset_bin_test \
    --gn-args "enable_local_test=true"
```

**证据**：`config.gni:15`（`enable_local_test`）

### 2. 单元测试

**运行单元测试**：
```bash
# 运行测试
./build.sh --product-name rk3568 --build-target asset_bin_test
```

**测试目录**：
- `test/unittest/kits_ndk/` - NDK API 测试
- `test/unittest/module_test/` - 模块测试
- `test/unittest/inner_kits_rust/` - Rust SDK 测试

### 3. 集成测试

**手动测试**：
```typescript
// 使用测试应用验证功能
import asset from '@ohos.security.asset';

// 测试基本存储
await asset.add(attributes);

// 测试查询
const result = await asset.query(query);
```

### 4. 性能测试

**性能指标**：
- API 延迟：< 100ms（推荐）
- 服务启动时间：< 500ms
- 加密/解密延迟：< 50ms

**优化建议**：
- 减少不必要的权限检查
- 优化数据库索引
- 使用缓存（如果适用）
