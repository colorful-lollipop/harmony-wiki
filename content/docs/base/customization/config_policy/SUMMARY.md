## 新人学习路线（5 分钟 → 30 分钟快速上手）

### 阶段 1：快速理解（5 分钟）

1. [项目概述](./01_Overview.md) - 了解组件定位、核心能力和快速开始示例
   - 一句话定义：这个项目解决什么问题
   - 能力边界：能做什么、不能做什么
   - 运行环境：依赖的系统服务、权限要求

### 阶段 2：架构认知（15 分钟）

2. [目录结构与模块职责](./02_Directory_Structure.md) - 了解代码组织方式
   - 顶层目录职责说明
   - 核心文件定位
   - 代码导航图

3. [架构设计](./03_Architecture.md) - 理解组件内部架构
   - 组件图：模块划分与依赖关系
   - 数据流图：输入 → 处理 → 输出
   - 多层级配置优先级系统
   - FollowX 机制

### 阶段 3：API 使用（10 分钟）

4. [N-API 接口文档](./04_N-API_Reference.md) - JS/ArkTS 接口说明
   - 函数列表与参数说明
   - 同步/异步版本对比
   - 错误码与异常处理

5. [C++ 内部 API](./05_Cpp_Inner_API.md) - 内部模块接口
   - C API 函数签名
   - 数据结构定义
   - 内存管理规范

## 安全研究路线（攻击面 → 代码地图 → 风险评估）

### 阶段 1：攻击面分析（10 分钟）

1. [攻击面分析](./08_AttackSurface.md) - **安全研究优先阅读**
   - **外部输入清单**：N-API 参数（relPath, followMode, extra）、系统参数
   - **敏感操作清单**：路径拼接、系统参数读取、文件访问、参数扩展
   - **信任边界图**：用户输入 → N-API 边界 → 核心逻辑 → 系统依赖
   - **4 条攻击路径**：路径遍历、FollowX 规则注入、参数扩展注入、缓冲区溢出

### 阶段 2：代码地图（15 分钟）

2. [目录结构与模块职责](./02_Directory_Structure.md) - 快速定位关键代码
   - 核心实现文件位置
   - API 绑定层入口
   - 关键符号索引

3. [C++ 内部 API](./05_Cpp_Inner_API.md) - 理解内部接口
   - 核心函数调用链
   - 数据结构关系

### 阶段 3：深度风险评估（10 分钟）

4. [安全风险评审 - 可利用点分析](./07_Security_Review.md)
   - **7 类风险点**：每条包含证据、触发路径、影响评估、修复建议
   - **优先级排序**：P1（路径遍历）→ P2（缓冲区验证）→ P3（内存泄漏）
   - **修复建议**：具体代码级建议

5. [GN 构建配置](./06_GN_Build.md) - 理解编译产物和安全特性
   - Feature Flags（安全相关配置）
   - 编译选项（安全标志）
