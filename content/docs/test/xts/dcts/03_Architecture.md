# DCTS 架构设计

## 整体架构

### 架构分层

```
┌─────────────────────────────────────────────────────────┐
│                    测试应用层 (Test Apps)                │
│  ┌───────────┐ ┌───────────┐ ┌───────────┐ ┌─────────┐  │
│  │ ability   │ │  comm     │ │  dhmgr    │ │ media   │  │
│  │   test    │ │   test    │ │   test    │ │  test   │  │
│  └───────────┘ └───────────┘ └───────────┘ └─────────┘  │
├─────────────────────────────────────────────────────────┤
│                   测试框架层 (Test Framework)             │
│  ┌─────────────────────────────────────────────────┐    │
│  │           Hypium / HCPPTest / HCTest            │    │
│  │    (测试用例定义、执行、断言、报告生成)            │    │
│  └─────────────────────────────────────────────────┘    │
├─────────────────────────────────────────────────────────┤
│                   OpenHarmony 系统 API 层                │
│  ┌─────────┐ ┌─────────┐ ┌─────────┐ ┌─────────────┐   │
│  │ @ohos   │ │ @ohos   │ │ @ohos   │ │ @ohos.data  │   │
│  │ ability │ │ rpc     │ │ dms     │ │ *           │   │
│  └─────────┘ └─────────┘ └─────────┘ └─────────────┘   │
├─────────────────────────────────────────────────────────┤
│              OpenHarmony 分布式子系统                     │
│  ┌─────────┐ ┌─────────┐ ┌─────────┐ ┌─────────────┐   │
│  │ DMS     │ │ SoftBus │ │ IPC     │ │ Data       │   │
│  └─────────┘ └─────────┘ └─────────┘ └─────────────┘   │
└─────────────────────────────────────────────────────────┘
```

### 关键组件

| 组件 | 描述 | 位置 |
|------|------|------|
| **测试用例** | 验证特定 API 功能的测试代码 | `*/entry/src/ohosTest/` |
| **测试服务** | 提供测试辅助服务 | `*/entry/src/main/ets/serviceability/` |
| **测试工具** | 通用测试组件 | `testtools/` |
| **公共模块** | 共享内存等公共功能 | `common/` |

## 数据流

```mermaid
flowchart TD
    A[测试用例] --> B[测试框架 Hypium]

    G --> K[Binder Driver]
    H --> L[分布式数据库]
```

## 线程模型

### 测试执行线程

| 线程类型 | 描述 | 生命周期 |
|----------|------|----------|
| **主线程** | UI 线程，负责界面渲染 | 应用生命周期 |
| **测试线程** | 执行测试用例 | 单个测试用例 |
| **Worker 线程** | 后台任务 | 需要时创建 |

## 关键时序

### 测试用例执行时序

```mermaid
sequenceDiagram
    participant T as 测试框架
    participant C as 测试用例
    participant F as OpenHarmony API
    participant S as 子系统

    C->>T: beforeAll()
    Note over T: 测试套件初始化
    
    loop 每个测试用例
        C->>T: beforeEach()
        T->>F: 调用被测 API
        F->>S: 内部处理
        S-->>F: 返回结果
        F-->>T: API 返回
        T-->>C: 断言验证
        C->>T: 测试逻辑
        T-->>C: PASS/FAIL
        C->>T: afterEach()
    end
    
    C->>T: afterAll()
    Note over T: 测试套件清理
```

### 分布式测试时序

```mermaid
sequenceDiagram
    participant TA as 设备A 测试用例
    participant FA as 设备A FeatureAbility
    participant SB as 软总线
    participant FB as 设备B 被测服务
    participant TB as 设备B 测试用例

    TA->>FA: 发起分布式调用
    FA->>SB: 建立连接
    SB->>FB: 远程请求
    FB->>TB: 执行业务逻辑
    TB-->>FB: 返回结果
    FB-->>SB: RPC 返回
    SB-->>FA: 响应数据
    FA-->>TA: 返回调用结果
    TA->>TA: 断言验证
```
