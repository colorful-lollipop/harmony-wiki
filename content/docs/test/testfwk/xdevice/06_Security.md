# XDevice 安全风险评审

## 1. 概述

本文档基于代码审计，对 XDevice 测试框架进行安全风险评估。涵盖攻击面分析、信任边界、风险评估和改进建议。

---

## 2. 攻击面清单

### 2.1 输入入口

| 攻击面 | 来源 | 风险等级 |
|--------|------|---------|
| XML 配置文件 | user_config.xml | 高 |
| JSON 模块配置 | acts.json, ssts.json | 中 |
| 命令行参数 | run 命令参数 | 中 |
| 设备日志 | device log | 低 |
| NFS 服务器 | SSH 认证 | 高 |
| Git/SVN 仓库 | 凭据传输 | 高 |

### 2.2 外部接口

| 接口 | 协议 | 用途 | 风险等级 |
|------|------|------|---------|
| HDC | 自定义协议 | 设备通信 | 中 |
| 串口 | pySerial | Lite 设备 | 中 |
| SSH | Paramiko | NFS 传输 | 高 |
| HTTP | requests | 集群通信 | 高 |

## 4. 安全风险评估

### 4.1 高危风险 (6项)

#### 风险 1：密码明文/Base64 存储

| 属性 | 值 |
|------|-----|
| **风险 ID** | SEC-001 |
| **文件** | `config/user_config.xml` |
| **代码位置** | 第 58-59 行 |
| **问题** | 密码仅使用 Base64 编码存储，非加密 |
| **触发条件** | 攻击者获取配置文件 |
| **影响** | 密码泄露，可能导致未授权访问 |
| **证据** | `<password></password>` 明文存储 |

**修复建议**：
```xml
<!-- 建议使用加密存储或环境变量 -->
<password encrypted="true">BASE64_ENCODED</password>
```

---

#### 风险 2：Git/SVN 密码 URL 传输

| 属性 | 值 |
|------|-----|
| **风险 ID** | SEC-002 |
| **文件** | `src/xdevice/_core/cluster/runner.py` |
| **代码位置** | 第 63 行 |
| **问题** | 密码在 HTTP URL 中明文传输 |
| **触发条件** | 网络嗅探 |
| **影响** | 凭据泄露 |
| **证据** | `http://{}:{}@host/repo`.format(username, password) |

**代码证据**：
```python
# cluster/runner.py 第 63 行
password = base64.b64decode(project.password).decode()
git_url = f"http://{username}:{password}@host/repo"
```

**修复建议**：使用 HTTPS + Token 认证，禁用 HTTP 明文传输。

---

#### 风险 3：SSL 证书验证禁用

| 属性 | 值 |
|------|-----|
| **风险 ID** | SEC-003 |
| **文件** | `src/xdevice/_core/cluster/utils.py` |
| **代码位置** | 第 44 行, 第 165 行 |
| **问题** | HTTPS 请求禁用 SSL 证书验证 |
| **触发条件** | 中间人攻击 |
| **影响** | 流量可能被劫持 |
| **证据** | `requests.get(url, verify=False)` |

**修复建议**：启用证书验证或使用证书固定。

---

#### 风险 4：私钥文件权限过宽

| 属性 | 值 |
|------|-----|
| **风险 ID** | SEC-004 |
| **文件** | `src/xdevice/_core/report/encrypt.py` |
| **代码位置** | 第 151 行 |
| **问题** | 私钥文件使用 755 权限创建 |
| **触发条件** | 本地攻击者读取私钥 |
| **影响** | 报告解密密钥泄露 |
| **证据** | `os.chmod(key_file, stat.S_IRWXU)` (0o755) |

**修复建议**：改为 600 权限。

---

#### 风险 5：设备 SN 无验证机制

| 属性 | 值 |
|------|-----|
| **风险 ID** | SEC-005 |
| **文件** | `src/xdevice/_core/environment/device.py` |
| **代码位置** | 第 292-297 行 |
| **问题** | SN 可被任意设置，无验证 |
| **触发条件** | 伪造设备 SN |
| **影响** | 设备冒充，测试结果伪造 |
| **证据** | `def __set_serial__(self, device_sn=""): self.device_sn = device_sn` |

**修复建议**：实现 SN 签名验证机制。

---

#### 风险 6：RSA PKCS#1 v1.5 填充

| 属性 | 值 |
|------|-----|
| **风险 ID** | SEC-006 |
| **文件** | `src/xdevice/_core/report/encrypt.py` |
| **代码位置** | 第 61-94 行 |
| **问题** | 使用 PKCS#1 v1.5 填充，存在 Bleichenbacher 攻击风险 |
| **触发条件** | 密文篡改攻击 |
| **影响** | 可能解密敏感数据 |
| **证据** | `rsa.encrypt()` 默认使用 PKCS#1 v1.5 |

**修复建议**：升级为 OAEP 填充。

---

## 7. 安全最佳实践

### 7.1 密码存储

```python
# 建议：使用加密存储
from cryptography.fernet import Fernet

# 生成密钥
key = Fernet.generate_key()
cipher = Fernet(key)

# 加密密码
encrypted = cipher.encrypt(password.encode())

# 解密密码
decrypted = cipher.decrypt(encrypted).decode()
```

### 7.2 HTTPS 配置

```python
# 建议：启用证书验证
import requests

response = requests.get(url, verify='/path/to/cert.pem')
```

### 7.3 文件权限

```python
import os

# 建议：使用最小权限
os.chmod(private_key_file, 0o600)  # 仅所有者读写
os.chmod(config_file, 0o600)       # 配置文件同
```
