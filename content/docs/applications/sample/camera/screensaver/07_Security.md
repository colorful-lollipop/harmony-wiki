# 安全风险评审

## 1. 评审范围与方法

### 1.1 评审范围

本安全评审覆盖以下代码和配置：
- `screensaver/src/main/cpp/` - 所有 C++ 源代码
- `screensaver/src/main/config.json` - 应用配置
- `BUILD.gn` - 构建配置
- `cert/` - 签名证书

**不包含**：
- OpenHarmony 框架代码（第三方依赖）
- 测试代码和测试用例

### 1.2 评审方法

采用代码审计方式，结合威胁建模识别潜在风险：
- 输入源分析（用户输入、系统调用、外部数据）
- 信任边界划分
- 敏感操作识别
- 防护措施验证

## 4. 已识别风险

### 4.1 低风险项

#### 风险 1：图片路径硬编码

| 属性 | 值 |
|------|-----|
| **风险 ID** | SEC-001 |
| **风险类型** | 信息泄露 |
| **风险等级** | 低 |

**证据**：`ui_config.h:25-34`
```cpp
static const char* const IMG_DEFAULT_001_PATH =
    "/storage/app/run/com.huawei.screensaver/screensaver/assets/...";
```

**触发条件**：
- 攻击者获取设备文件系统权限

**影响**：
- 泄露应用安装路径信息

**修复建议**：
- ✅ 当前状态：路径基于系统规范，不可配置
- 如需增强：考虑路径混淆或动态生成

---

#### 风险 2：空指针检查不完整

| 属性 | 值 |
|------|-----|
| **风险 ID** | SEC-002 |
| **风险类型** | 空指针解引用 |
| **风险等级** | 低 |

**证据**：`event_listener.h:43-47`
```cpp
UIView *currentView = &view;
if (currentView == nullptr) {
    return false;
}
```

**问题**：
- `&view` 永远不会返回 nullptr（引用转指针）
- 空指针检查逻辑冗余

**触发条件**：
- 极低概率的内存损坏场景

**影响**：
- 潜在崩溃风险（理论层面）

**修复建议**：
```cpp
// 移除冗余检查，或使用更合理的防护
if (onClick_) {
    return onClick_(view, event);
}
return false;
```

**当前状态**：代码有防护，但逻辑可优化

---

#### 风险 3：缺少资源加载错误处理

| 属性 | 值 |
|------|-----|
| **风险 ID** | SEC-003 |
| **风险类型** | 资源访问错误 |
| **风险等级** | 低 |

**证据**：`screensaver_ability_slice.cpp:46-62`
```cpp
imageAnimator_ = new UIImageAnimatorView();
imageAnimator_->Resize(...);
imageAnimator_->SetImageAnimatorSrc(g_imageAnimatorInfo, ...);
// 未检查返回值
imageAnimator_->Start();
```

**触发条件**：
- 图片资源损坏或缺失
- 内存不足

**影响**：
- 屏保功能异常
- 无用户提示

**修复建议**：
- 添加资源加载状态检查
- 提供降级方案（显示默认图片）
- 记录错误日志

### 4.2 无风险项

以下安全考量经分析后确认为**无风险**：

| 检查项 | 结论 | 原因 |
|--------|------|------|
| 路径遍历 | ✅ 无风险 | 路径硬编码，无用户输入 |
| SQL 注入 | ✅ 无风险 | 未使用数据库操作 |
| 内存安全 | ✅ 无风险 | 使用智能指针/手动管理，析构函数完整 |
| 权限缺失 | ✅ 无风险 | 屏保作为系统应用，由系统调度 |
| 竞态条件 | ✅ 无风险 | 单线程模型，无多线程竞争 |
| 信息泄露 | ✅ 无风险 | 无敏感日志或调试输出 |

## 5. 安全加固建议

### 5.1 建议优先级

| 优先级 | 建议 | 工作量 |
|--------|------|--------|
| 中 | 优化 EventListener 空指针检查 | 低 |
| 中 | 添加资源加载错误处理 | 中 |
| 低 | 图片路径动态化（如需要） | 中 |

### 5.2 通用安全实践

1. **输入验证**：对所有外部输入进行验证
2. **资源释放**：确保所有资源在析构函数中释放
3. **错误处理**：提供有意义的错误日志和用户提示
4. **最小权限**：仅请求必要的系统能力
