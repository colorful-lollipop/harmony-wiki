### 1.2 攻击面分析

| 攻击面 | 类型 | 风险等级 | 说明 |
|--------|------|----------|------|
| **富文本编辑** | 输入验证 | 中 | WebView 加载外部内容 |
| **图片导入** | 文件操作 | 中 | 从媒体库或文件选择 |
| **跨设备流转** | 数据序列化 | 中 | 流转数据的完整性 |
| **数据库操作** | SQL 注入 | 低 | 参数化查询封装 |
| **文件路径** | 路径遍历 | 低 | 文件操作使用固定目录 |

## 2. 可被利用点分析

### 2.1 XSS 风险 (富文本编辑)

**风险点**: WebView 加载富文本内容

| 属性 | 值 |
|------|-----|
| **代码位置** | `features/src/main/ets/components/NoteContentComp.ets` |
| **风险类型** | 跨站脚本攻击 (XSS) |
| **触发方式** | 插入包含恶意脚本的 HTML 内容 |
| **影响范围** | 可能执行恶意脚本 |

**代码证据**:
```typescript
// WebView 组件加载内容
webview Web({
  controller: this.controller,
  src: this.contentUrl
})
```

**修复建议**:
- 对 HTML 内容进行 XSS 过滤
- 启用 WebView 的安全配置
- 限制可执行的 JavaScript

### 2.2 路径遍历风险

**风险点**: 图片路径处理

| 属性 | 值 |
|------|-----|
| **代码位置** | `MainAbility.ts:246-258` |
| **风险类型** | 路径遍历 |
| **触发方式** | 恶意构造的文件名 |
| **影响范围** | 写入非预期目录 |

**代码证据**:
```typescript
writeToDisFileDir(fileName: string) {
  let filesDir = this.context.filesDir;
  let srcPath = filesDir + "/" + fileName;
  let distributedFilesDir = this.context.distributedFilesDir;
  let desPath = distributedFilesDir + "/" + fileName;
  try {
    fileio.copyFileSync(srcPath, desPath);
  } catch (err) {
    LogUtil.error(TAG, "copyFile failed : " + err);
  }
}
```

**修复建议**:
- 验证 fileName 的合法性
- 使用 path.basename() 过滤路径
- 检查文件类型

### 2.3 跨设备数据篡改

**风险点**: 流转数据序列化

| 属性 | 值 |
|------|-----|
| **代码位置** | `MainAbility.ts:163-214` |
| **风险类型** | 数据篡改 |
| **触发方式** | 中间人攻击流转数据 |
| **影响范围** | 笔记数据完整性 |

**代码证据**:
```typescript
onContinue(wantParam: { [key: string]: any }) {
  let continueNote = AppStorage.get<string>('ContinueNote');
  wantParam["ContinueNote"] = continueNote;
  // 其他数据...
  return AbilityConstant.OnContinueResult.AGREE;
}
```

**修复建议**:
- 添加数据签名验证
- 使用安全通道传输
- 增加数据校验机制

### 2.4 日志信息泄露

**风险点**: 敏感信息日志输出

| 属性 | 值 |
|------|-----|
| **代码位置** | `LogUtil.*` (多处) |
| **风险类型** | 信息泄露 |
| **触发方式** | 查看应用日志 |
| **影响范围** | 用户笔记内容可能泄露 |

**代码证据**:
```typescript
LogUtil.info(TAG, "continueNote : " + continueNote);
LogUtil.info(TAG, "getSrcFromHtml, src[1] : " + src[1]);
```

**修复建议**:
- 敏感数据脱敏后再日志
- 建立日志分级机制
- 生产环境关闭详细日志

### 2.5 未授权数据库访问

**风险点**: 数据库操作权限

| 属性 | 值 |
|------|-----|
| **代码位置** | `RdbStoreUtil.ets` |
| **风险类型** | 越权访问 |
| **触发方式** | 直接访问数据库 |
| **影响范围** | 其他应用数据 |

**说明**: OpenHarmony 沙箱机制限制应用间数据库访问，当前实现安全

## 3. 安全机制评估

### 3.1 已有的安全机制

| 机制 | 实现 | 效果 |
|------|------|------|
| **应用沙箱** | 系统内置 | 隔离应用数据 |
| **权限控制** | 权限声明 | 控制敏感操作 |
| **数据库封装** | RdbStoreUtil | 防止 SQL 注入 |
| **文件路径限制** | filesDir | 防止越权访问 |

### 3.2 缺失的安全机制

| 机制 | 建议优先级 | 说明 |
|------|------------|------|
| **XSS 过滤** | 高 | 富文本内容需要过滤 |
| **输入验证** | 中 | 增强用户输入校验 |
| **日志脱敏** | 中 | 敏感数据脱敏 |
| **数据签名** | 低 | 流转数据完整性 |
