# 01. 项目边界

> 目的: 明确ScreenLock项目的职责范围、功能边界和外部依赖  
> 适用范围: 架构师、开发者、项目经理

---

## 1. 功能边界

### 1.1 职责范围内 ✅

| 功能类别 | 具体功能 | 实现模块 |
|----------|----------|----------|
| **锁屏界面** | 锁屏窗口创建与显示 | `features/screenlock`, `phone/ServiceExtAbility` |
| **解锁方式** | 滑动解锁、数字密码、混合密码、图案密码 | `product/phone/pages/*`, `features/screenlock/vm/*` |
| **状态展示** | 时间、日期、电量、信号、WiFi、通知 | `features/*component` |
| **快捷操作** | 关机、重启快捷入口 | `features/shortcutcomponent` |
| **壁纸显示** | 锁屏壁纸获取与渲染 | `features/wallpapercomponent` |
| **通知展示** | 系统通知在锁屏的显示与管理 | `features/noticeitem` |

### 1.2 职责范围外 ❌

| 功能类别 | 说明 | 责任方 |
|----------|------|--------|
| **锁屏策略决策** | 系统何时锁屏、解锁策略由系统服务控制 | `@ohos.screenLock` 系统服务 |
| **密码验证逻辑** | 密码校验由系统安全服务完成 | `@ohos.account.osAccount` |
| **生物识别底层** | 人脸/指纹识别的底层实现 | 系统生物识别服务 |
| **通知内容生成** | 通知内容的创建和分发 | 各应用或通知服务 |
| **壁纸设置** | 壁纸的选择和设置功能 | 系统设置应用 |
| **系统级权限管理** | 权限的授予和检查 | 系统权限管理服务 |

## 4. 接口边界

### 4.1 对外暴露

ScreenLock作为系统应用，**不对外暴露应用级API**，但对外产生以下影响：

| 接口类型 | 说明 | 影响范围 |
|----------|------|----------|
| **系统事件** | 发送锁屏/解锁事件给系统 | 系统服务 |
| **窗口显示** | 创建TYPE_KEYGUARD窗口覆盖其他应用 | 用户体验 |
| **通知拦截** | 显示系统通知 | 用户通知体验 |

### 4.2 对内使用

| 接口来源 | 接口类型 | 使用场景 |
|----------|----------|----------|
| `@ohos.screenLock` | 系统服务API | 锁屏状态同步 |
| `@ohos.account.osAccount` | 系统服务API | 用户认证 |
| `@ohos.notification` | 系统服务API | 通知订阅 |
| `common`模块 | 内部模块接口 | 通用能力复用 |

## 5. 数据边界

### 5.1 应用内数据

| 数据类型 | 存储位置 | 生命周期 |
|----------|----------|----------|
| 锁屏状态 | AppStorage / 内存 | 应用运行时 |
| 窗口信息 | WindowManager.mWindowInfos | 应用运行时 |
| 事件订阅 | EventBus._cbs | 应用运行时 |
| 用户属性 | 系统服务缓存 | 随系统 |

### 5.2 系统数据访问

| 数据类型 | 来源 | 访问方式 |
|----------|------|----------|
| 锁屏策略 | 系统服务 | `@ohos.screenLock` |
| 用户信息 | 系统服务 | `@ohos.account.osAccount` |
| 通知数据 | 系统服务 | `@ohos.notification` |
| 时间格式 | 系统设置 | `@ohos.settings` |
| WiFi状态 | 系统服务 | `@ohos.wifi` |

### 5.3 不存储的数据

- ❌ 用户密码（由系统安全服务管理）
- ❌ 生物识别数据（由系统安全服务管理）
- ❌ 通知历史（仅展示当前通知）

## 6. 安全边界

### 6.1 信任边界

```
用户空间 (不可信)
    │
    ▼
┌─────────────────────────────────────┐
│      ScreenLock 应用 (半可信)        │
│  - 显示锁屏界面                       │
│  - 传递用户输入给系统服务              │
│  - 不处理密码验证                     │
└─────────────────────────────────────┘
    │
    ▼
系统服务空间 (可信)
  - @ohos.screenLock
  - @ohos.account.osAccount
  - @ohos.notification
```

### 6.2 权限边界

| 权限类别 | 权限数量 | 说明 |
|----------|----------|------|
| system_grant | 17个 | 系统级权限，需要系统签名 |
| normal | 5个 | 普通权限，用户授权 |
| **总计** | **22个** | 涵盖账户、通知、网络、蓝牙等 |

详见 [对外API文档](04_External_API.md#权限清单)
