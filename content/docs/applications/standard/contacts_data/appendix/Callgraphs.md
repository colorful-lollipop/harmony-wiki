# contacts_data 关键调用链

> 本文档记录 contacts_data 子系统的关键调用链，用于理解数据流向和功能实现路径。

## 调用链概述

contacts_data 子系统的调用链可以从多个入口点开始，包括 JavaScript N-API 入口、C++ Inner API 入口和 System Ability 入口。本文档重点描述最常用的 N-API 调用链。

## 调用链总结

### 调用深度统计

| 操作类型 | 调用深度 | 主要耗时操作 |
|----------|----------|--------------|
| 添加联系人 | 6 层 | 数据库插入 |
| 查询联系人 | 6 层 | 数据库查询、索引检索 |
| 更新联系人 | 6 层 | 数据库更新 |
| 删除联系人 | 6 层 | 数据库删除 |
| DataAbility 插入 | 5 层 | IPC 传输、数据库插入 |
| DataAbility 查询 | 6 层 | IPC 传输、SQL 解析、数据库查询 |
