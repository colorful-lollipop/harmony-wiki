# App Samples Wiki

## 文档说明

本文档为 OpenHarmony `app_samples` 仓库的工程 Wiki，旨在帮助开发者快速理解项目结构、使用方法和开发规范。

### 覆盖范围

| 范围 | 说明 |
|-----|------|
| ✅ 项目定位与目录结构 | 仓库用途、组织方式 |
| ✅ 示例列表与功能说明 | 8 个 ArkTS 示例的用途和特点 |
| ✅ 构建系统 | hvigor 构建配置、SDK 版本要求 |
| ✅ 开发规范 | Stage 模型、ArkTS 编码规范 |
| ✅ 常见问题 | 构建、运行、调试问题汇总 |
| ⚠️ API 参考 | 各示例使用的 OpenHarmony SDK API |
| ❌ Native/N-API | 本仓库无 Native C++ 示例 |

### 文档更新

- **最后更新**: 2024年
- **更新方式**: 手动维护，随仓库示例变更同步更新
- **贡献方式**: 通过 GitHub Pull Request 提交修改
